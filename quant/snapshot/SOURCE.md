# 미리 받아 둔 실제 데이터

회사 인터넷에서 업비트나 alternative.me가 막힐 때 쓰는 사본입니다. 강사가 2026-10-21 01:03(한국 시각)에 아래 공개 API에서 받았습니다. 키나 로그인은 쓰지 않았습니다.

| 파일 | 내용 | 출처 |
| --- | --- | --- |
| `btc_daily.csv` | 비트코인 원화 일봉 799일(2024-08-12 ~ 2026-10-19). 날짜, 시가, 고가, 저가, 종가, 거래량(BTC), 거래대금(원) | 업비트 Open API 시세 캔들(일) `https://api.upbit.com/v1/candles/days?market=KRW-BTC` |
| `fear_greed.csv` | 같은 기간의 공포·탐욕 지수(0 극도의 공포 ~ 100 극도의 탐욕) 798일 | alternative.me Crypto Fear & Greed Index `https://api.alternative.me/fng/?limit=0` |

- 업비트 일봉의 날짜는 한국 시각 오전 9시에 시작하는 하루입니다. 받은 시각에 아직 끝나지 않은 2026-10-20 봉은 뺐습니다.
- 공포·탐욕 지수의 날짜는 UTC 하루라서, 업비트 일봉 날짜와 같은 날로 맞습니다.
- 공포·탐욕 지수에는 2024-10-26 값이 원래 없습니다. 실제 데이터에는 이렇게 빈 날이 있습니다.
- 공포·탐욕 지수는 alternative.me가 만든 지표이고, 쓸 때 출처를 밝혀 달라고 합니다.
- 수업 연습용 자료입니다. 투자 판단에 쓰지 않습니다.
