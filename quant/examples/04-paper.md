# ④ 가상 자동매매 · 실제 답

강사 PC에서 2026-10-21에 Claude Code 2.1.304, 모델 Sonnet 5.5로 실제로 보낸 결과입니다. 앞 단계와 같은 세션에 이어서 보냈습니다. 걸린 시간은 43초이고, 만든 파일은 `results/` 아래에 그대로 있습니다(`paper.py`, `paper/ledger.csv`).

## 보낸 말

```text
paper.py를 만들어 줘. 실행하면 업비트에서 비트코인 최근 일봉을, alternative.me에서 최근 공포·탐욕 지수를 받아 전략 B 규칙(25 아래면 사고 75 위면 팔기)으로 살지 팔지 쉴지 정하고, 가상 계좌(처음 1,000만 원)로 주문했다고 치고 paper/ledger.csv에 날짜, 판단, 가격, 수량, 현금, 평가금액을 한 줄 적어. 같은 날 두 번 실행하면 다시 적지 마. 실제 거래소 주문 API나 키는 절대 쓰지 마. 두 번 실행해서 결과를 보여 줘.
```

## Claude의 마지막 답(원문 그대로)

`paper.py`를 만들어 두 번 실행했습니다. 첫 실행은 `paper/ledger.csv`에 한 줄을 적었고, 두 번째 실행은 같은 날이라 다시 적지 않았습니다.

| 실행 | 출력 |
|---|---|
| 1회 | `2026-10-19 공포·탐욕 59 → 쉼 \| 가격 110,199,000 수량 0 현금 10,000,000 평가금액 10,000,000` |
| 2회 | `2026-10-19는 이미 기록됨, 다시 적지 않음` |

`paper/ledger.csv`에는 지금 다음 한 줄만 있습니다.

```
2026-10-19,쉼,110199000,0.00000000,10000000.00,10000000.00
```

공포·탐욕 지수가 59라서 25 미만도 75 초과도 아니어서 "쉼"으로 판단했고, 가상 계좌는 처음 1,000만 원 그대로입니다.

- **기준 날짜:** 아직 안 끝난 오늘 봉은 빼고, 가장 최근에 끝난 일봉의 날짜와 종가를 씁니다. 같은 날짜의 공포·탐욕 값을 못 받으면 기록하지 않고 멈춥니다.
- **체결 가정:** 판단한 그날 종가에 바로 체결됐다고 칩니다. 백테스트는 다음 날 종가에 체결해서 방식이 다릅니다. 기록은 하루가 끝난 뒤에 하므로 실제로는 그 종가에 주문할 수 없고, 실제 거래와 어긋날 수 있는 단순화입니다.
- **수수료와 중복 방지:** 수수료 0.05%를 적용했습니다. 이미 산 상태에서는 또 사지 않고, 들고 있지 않으면 팔지 않습니다. 같은 날짜가 장부에 있으면 다시 적지 않습니다.
- **수량 칸:** 주문 수량이 아니라 그날 거래 후 보유 수량입니다. 현금과 수량은 장부의 마지막 줄에서 이어받습니다.
- **안전:** 주문 API나 API 키는 쓰지 않습니다. 시세 조회(GET)만 합니다.
- **빠진 날:** 실행하지 않은 날은 채워 넣지 않습니다. 매일 한 번 실행해야 장부가 이어집니다.
