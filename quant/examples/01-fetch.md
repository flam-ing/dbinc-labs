# ① 데이터 모으기 · 실제 답

강사 PC에서 2026-10-21에 Claude Code 2.1.304, 모델 Sonnet 5.5로 실제로 보낸 결과입니다. 빈 폴더에서 새 세션으로 보냈습니다. 걸린 시간은 38초이고, 만든 파일은 `results/` 아래에 그대로 있습니다(`fetch.py`, `data/btc.csv`, `data/SOURCE.md`).

## 보낸 말

```text
업비트 공개 API(https://api.upbit.com/v1/candles/days, 키 없음)에서 비트코인(KRW-BTC) 일봉 2년치를, alternative.me 공포·탐욕 지수 API(https://api.alternative.me/fng/)에서 같은 기간 값을 받아 날짜로 합쳐 data/btc.csv로 저장하는 fetch.py를 만들고 한 번 실행해 줘. 칸은 날짜, 종가, 거래대금, 공포·탐욕 지수. 파이썬 기본 기능만 쓰고, 요청 사이에는 잠깐 쉬어. 아직 안 끝난 오늘 봉은 빼고, 받은 시각과 출처는 data/SOURCE.md에 적어 줘.
```

## Claude의 마지막 답(원문 그대로)

`fetch.py`를 만들어 한 번 실행했고, `data/btc.csv`에 729행이 저장됐습니다. 730일을 기대했는데 하루가 모자랍니다. 업비트는 730일이 다 왔고, 공포·탐욕 지수에 2024-10-26이 없어서 그날만 빠졌습니다. `SOURCE.md`에도 이 내용을 적어 뒀습니다.

- **기간:** 2024-10-20 ~ 2026-10-19입니다.
- **칸:** 날짜, 종가, 거래대금, 공포탐욕지수 순입니다. 종가와 거래대금은 원화입니다.
- **오늘 봉:** 아직 안 끝난 오늘(2026-10-20 UTC) 봉은 뺐습니다. 업비트 일봉은 09:00 KST에 시작하고 날짜는 UTC로 맞췄습니다.
- **파이썬:** 기본 라이브러리만 썼고, 요청마다 0.5초씩 쉽니다.
- **받은 시각과 출처:** 받은 시각(2026-10-20 16:07 UTC, 한국시간 10-21 01:07)과 출처 URL은 `data/SOURCE.md`에 적었습니다.

두 데이터는 날짜로 합치되, 한쪽에만 있는 날은 빼도록 했습니다.
