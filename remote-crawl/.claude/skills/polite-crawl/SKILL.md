# 원격 수집 예의 규칙

이 규칙은 "어떻게 하라"보다 "무엇을 하지 않는지"를 적어요. 어기게 될 것 같으면 멈추고 사람에게 물어요.

## 하지 않는 것

1. test-server(https://test-server-8az.pages.dev)와 내 PC(127.0.0.1, localhost) 말고 다른 주소에는 요청하지 않아요.
2. 같은 대상에 1분에 한 번보다 자주 묻지 않아요. MIN_GAP_SECONDS를 60보다 줄이지 않아요. 값은 1분에 한 번만 바뀌어요.
3. 여러 요청을 동시에 보내지 않고, 끝없이 반복해서 부르지 않아요. 여러 번 모을 때는 사람이 정한 횟수만큼만, 실행 사이를 1분 넘게 띄워요.
4. 관리자 화면과 사람 확인(Turnstile) 주소는 부르지 않아요. 관리자 화면의 스위치는 강사만 다뤄요.
5. User-Agent에 우리 이름을 밝혀요. 브라우저인 척하는 헤더(브라우저 이름, Sec-CH-UA 같은 것)를 지어 넣지 않아요.
6. 401, 403, 429를 받거나 "접속이 차단되었습니다"가 보이면 다시 두드리지 않고 멈춰요. data/incidents.md에 적고 사람에게 알려요.
7. 사람 확인 화면(Turnstile)을 자동으로 넘기려고 하지 않아요.
8. data/live-prices.csv를 손으로 고치지 않아요. 결과에 쓰는 숫자는 응답이나 data/ 파일에서만 가져와요.

## 값을 모을 때

- 먼저 python3 polite_fetch.py로 모아요. 이 예시는 robots.txt를 하루에 한 번 읽고, 1분 안에 다시 부르면 묻지 않고 저장해 둔 값(캐시)을 보여 줘요.
- WebFetch는 쓰지 않아요. 명령으로 직접 부를 때는 curl -A "우리 이름"처럼 이름을 밝혀요. 훅이 이 두 가지를 막아요.
- 새 길(예: v2 세션)이나 새 기능을 더할 때도 위 규칙과 이 예시의 간격, 캐시, 멈추기를 그대로 지켜요.
