## 보낸 말

```text
아래 이슈를 재현 순서대로 재현해 줘. 서버를 켜서 실제로 요청을 보내 보고, 기대와 실제를 한 줄씩 말해 줘. 아직 고치지는 마.

#1 [서버] 이름을 딱 40자로 쓰면 거절돼요

※ 교육용으로 일부러 넣은 버그예요.

## 재현 순서

1. `python3 app.py`로 서버를 켜고 http://127.0.0.1:8000 을 열어요.
2. 이름 칸에 `가`를 40번 쓰고(40자), 내용에 `안녕하세요`를 쓰고 **남기기**를 눌러요.

## 기대

저장돼요. 이름 칸은 40자까지 써지고, 안내에도 "40자 이내"라고 되어 있어요.

## 실제

"이름은 40자 이내로 입력해 주세요."가 떠요. 39자는 저장돼요.
```

## Claude의 답 (그대로)

이슈 #1은 재현됐습니다. 서버를 켜고 `POST /api/entries`로 이름 길이만 바꿔 보냈습니다. 브라우저 화면은 열지 않았고, 화면이 쓰는 API를 직접 호출했습니다.

| 이름 길이 | 응답 |
|---|---|
| 39자 | 201, 저장됨 |
| 40자 | 400, "이름은 40자 이내로 입력해 주세요." |
| 41자 | 400, 같은 메시지 |

- **기대:** `가`를 40번 쓴 이름이 저장됩니다. 안내가 "40자 이내"이기 때문입니다.
- **실제:** 40자는 400으로 거절되고, 39자까지만 저장됩니다.

원인은 `app.py:41`의 `if len(result[key]) >= maximum:`로 보입니다. 비교가 `>=`라서 정확히 `maximum`자인 값도 거절합니다. 같은 검사를 내용(500자)에도 쓰기 때문에, 내용도 500자에서 거절될 가능성이 큽니다. 내용 500자는 보내 보지 않았습니다.

서버는 껐고, `git status`도 깨끗합니다. 코드는 고치지 않았습니다.
