# 10. 버그 신고 초안 받기: 실제로 나온 답

실습 6의 문장 점선 칸에 오늘 본 버그 하나를 내 말로 넣어 보낸 실제 답이에요. 같은 문장을 두 사본에 보냈어요. 하나는 받은 그대로의 새 사본이고, 다른 하나는 네 이슈를 모두 고친 사본이에요.

| 항목 | 값 |
| --- | --- |
| 날짜 | 2026-10-23 |
| Claude Code | 2.1.309 |
| 모델 | Sonnet 5.5 |
| 모드 | Auto |
| 걸린 시간 | 새 사본 16초, 고친 사본 23초 |

## 보낸 말

```text
카페 포인트 마감을 돌리다가 박노을 님 두 번째 주문에도 생일 쿠폰이 나오는 것을 봤어. 버그 신고로 쓸 수 있게 재현 순서, 기대, 실제 세 칸으로 정리해 줘. 원인은 쓰지 마.
```

## 새 사본에서 받은 답 (그대로)

재현됐습니다. 임시 폴더에서 `run_cafe`로 돌렸고 `data/`는 건드리지 않았습니다.

**재현 순서**
1. 회원 명부에 박노을(M003, 생일 1999-10-28, 누적 23,000원, 포인트 800점, 일반 등급)이 있는 상태로 시작합니다.
2. 같은 날(2026-10-17, 생일 달) 박노을 님의 주문 두 건을 순서대로 넣습니다.
   - `2026-10-17,M003,9000,0`
   - `2026-10-17,M003,6000,0`
3. `python3 cafe.py`로 마감을 돌리고 영수증을 확인합니다. 테스트에서는 `run_cafe(["2026-10-17,M003,9000,0", "2026-10-17,M003,6000,0"])`로 같은 결과가 나옵니다.

**기대**
- 첫 주문(9,000원)에만 생일 쿠폰 -3,000원이 적용됩니다. 규칙은 생일 달 첫 주문이 5,000원 이상이면 3,000원을 깎아 주는 것입니다.
- 두 번째 주문(6,000원)에는 쿠폰이 없습니다. 결제 금액은 6,000원, 적립은 60점, 남은 포인트는 920점이어야 합니다.

**실제**
- 두 번째 주문에도 `생일 쿠폰: -3000 원`이 찍힙니다.
- 두 번째 영수증은 결제 금액 3,000원, 적립 30점, 남은 포인트 890점입니다.
- `out/members.csv`의 M003은 누적 32,000원, 포인트 890점으로 저장됩니다.

원인은 쓰지 않았습니다. 고치려면 이 입력으로 `tests/test_bugs.py`에 회귀 테스트를 먼저 추가하겠습니다. 이슈 번호와 제목을 알려 주세요.

## 네 이슈를 고친 사본에서 받은 답 (앞부분 그대로)

지금 `data/`의 데이터로는 재현되지 않아서, 버그 신고를 완성형으로 쓸 수 없습니다.

`python3 cafe.py`를 그대로 돌려 봤습니다. 박노을(M003, 생일 10-28)의 주문은 이렇게 나왔습니다.

| 순서 | 주문 금액 | 생일 쿠폰 | 결제 금액 |
|---|---|---|---|
| 첫 번째 (2026-10-17) | 9,000원 | -3,000원 | 6,000원 |
| 두 번째 (2026-10-17) | 6,000원 | 없음 | 6,000원 |

두 번째 주문에는 쿠폰이 붙지 않았습니다. 규칙(생일 달 첫 주문만 할인)대로입니다.

(뒤에는 어떤 조건에서 봤는지 묻는 질문 세 개가 이어지고, 세 칸 초안은 쓰지 않았어요. 전문은 `_reference/claude-runs/10-report-fixed.json`에 있어요.)

## 볼 곳

- 새 사본에서는 재현 순서, 기대, 실제 세 칸으로 정리하고 원인은 쓰지 않았어요.
- 실제 칸에 영수증 글자(`생일 쿠폰: -3000 원`)를 그대로 옮겼어요. 영수증은 깎는 금액과 쓴 포인트를 마이너스로 찍어요. 이것은 원래 보여 주는 방식이라 버그가 아니에요.
- 이미 고친 폴더에서 보내면 Claude가 재현되지 않는다고 하고 초안을 쓰지 않았어요. 고친 버그를 신고로 써 볼 때는 GitHub 양식에 내가 본 것을 직접 써요.
