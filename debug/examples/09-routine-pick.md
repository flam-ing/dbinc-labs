# 9. 루틴으로 맡길 일 골라 보기: 실제로 나온 답

실습 5의 문장 점선 칸에 "매일 아침 마감 보고 읽기"를 넣어 보낸 실제 답이에요.

| 항목 | 값 |
| --- | --- |
| 날짜 | 2026-10-23 |
| Claude Code | 2.1.309 |
| 모델 | Sonnet 5.5 |
| 모드 | Auto |
| 걸린 시간 | 16초 |

## 보낸 말

```text
내가 되풀이하는 일은 매일 아침 마감 보고 읽기야. 이 일을 루틴으로 맡기면 좋을지, AI 없이 알림이나 스크립트로 충분한지 판단해 줘. 루틴은 만들지 마.
```

## Claude의 답 (그대로)

**판단: 루틴(AI)은 필요 없습니다. 알림이나 스크립트로 충분합니다.**

**근거**
- 마감 보고(`out/report.txt`)는 `cafe.py`가 고정된 5줄로 씁니다. 주문 수, 매출, 적립 포인트, VIP 인원이 전부입니다. 매일 같은 형식이고 서술형 내용이 없어서, 읽을 때 해석이나 요약이 따로 필요하지 않습니다.
- 아침에 하는 일이 "숫자를 확인하는 것"이라면 결정적인 방식이 더 낫습니다. 같은 입력이면 항상 같은 결과가 나오고, 비용이 들지 않고, AI가 숫자를 잘못 옮길 위험도 없습니다.
- 마감 프로그램과 보고서 모두 로컬에서 표준 라이브러리만으로 돕니다. 여기에 AI를 얹을 이유가 없습니다.

**추천 구성**
1. `cafe.py` 마감 실행 뒤에 `out/report.txt`를 메신저나 메일로 보내는 한 줄을 붙입니다. 아침에 알림으로 바로 읽을 수 있습니다. (cron이나 macOS `launchd`로 마감 시각에 실행하면 됩니다.)
2. 숫자만 보는 게 아니라 이상 여부도 보고 싶다면, 스크립트에 단순 조건을 넣습니다. 예를 들어 "주문 0건", "매출이 평소보다 급감", "VIP 인원이 줄어듦"일 때만 제목에 ⚠️를 붙이는 식입니다.

**루틴이 의미 있어지는 경우**
- 보고에 사람이 쓴 메모나 이슈 글처럼 서술형 내용이 섞여서 읽고 요약해야 할 때
- 숫자가 이상할 때 `data/orders.csv`를 열어 원인을 추적하고 설명하는 일까지 맡기고 싶을 때
- 여러 날 보고를 비교해서 추세를 해석해 주길 원할 때

지금은 해당하지 않습니다. 나중에 필요해지면 그때 AI 해석 단계만 따로 붙이는 게 좋습니다.

루틴이나 알림은 만들지 않았고, 파일도 바꾸지 않았습니다. 원하시면 1번 알림 스크립트 초안을 따로 써 드릴게요. 어디로 받을지(메신저, 메일 등)만 알려 주세요.

## 볼 곳

- 숫자 다섯 줄을 읽는 일이라 AI 없이 알림이면 충분하다고 판단했어요.
- 글을 읽고 원인을 찾아야 할 때만 루틴이 쓸모 있다고 따로 적었어요.
