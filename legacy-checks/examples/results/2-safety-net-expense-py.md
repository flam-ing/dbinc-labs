# 견본 2: 안전망 만들기 (expense-py)

6교시 3부 실습 "내 레거시에 안전망"의 예시 문장을 실제로 보낸 결과예요.

- 폴더: `labs/legacy/expense-py`를 복사하고, 5교시에 만든 `CLAUDE.md`와 인수인계 보고서를 넣은 폴더예요. 5교시를 마친 학생 폴더와 같은 모양이에요.
- 모드: Accept edits, 새 세션. 원본을 실행하는 명령은 허락했어요.
- 걸린 시간: 1분 4초
- 만든 파일: `tools/golden.py`(비교 도구)와 `golden/` 아래 시나리오 10개(지금 결과 기록)

## 보낸 말

```text
리팩토링하기 전에 지금 동작을 기록해 두고 싶어. data/의 입력들로 원본을 실행해서 결과를 저장하고, 나중에 고친 코드의 결과와 같은지 비교하는 방법을 만들어 줘. 원본 코드는 고치지 마.
```

## 끝난 뒤 비교를 돌려 본 결과

```text
$ python3 tools/golden.py check
같음: 10개 시나리오 모두 golden/ 과 바이트 단위로 일치
```

room-java에서는 같은 문장으로 `scripts/golden.sh`(셸 스크립트)와 `golden/`이 생겼어요. 이름과 언어는 레거시마다 달라도 돼요. 저장하고, 다시 돌리고, 비교하는 세 가지가 있으면 돼요.

````markdown
현재 동작을 `golden/`에 기록해 뒀고, 고친 코드의 결과와 비교하는 스크립트 `tools/golden.py`도 만들었어요. `src/`는 건드리지 않았고, 스크립트는 배치를 별도 프로세스로 실행하기만 해요. 표준 라이브러리만 써요.

**사용법**
```

모두 같으면 종료 코드 0, 다르면 1이에요. 다를 때는 달라진 파일 목록과 diff가 나와요.

**기록하는 것**
- 시나리오마다 새 임시 출력 폴더에서 배치를 돌려요.
````
