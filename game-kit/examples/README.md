# 게임 키트 예시

1일차 3교시 [실습 1-1: 1인분 HTML 만들고 배포하기](../../../docs/day1-onepager.md)에서 막혔을 때 쓰는 파일이에요. 실습 문장은 [onepager/examples/prompts.md](../../onepager/examples/prompts.md)에 있어요.

| 파일 | 무엇 | 언제 |
| --- | --- | --- |
| [sample-game/index.html](sample-game/index.html) | 토끼가 당근을 피하는 견본 게임 | 실습 ①에서 5분이 넘도록 게임 파일이 안 생길 때 |
| [prompts.md](prompts.md) | 게임을 더 고쳐 볼 때 보내는 문장 | 수업 뒤 |
| [answers.md](answers.md) | 수업 전에 실제로 보내 본 답 | 내 답과 견줘 볼 때 |

견본 게임은 바탕화면 `my-game` 폴더에 넣고 이어 가요. 이 게임은 같은 폴더의 `poster.png`, `music.mp3`, `ending.mp4`를 찾아요. 파일이 없으면 포스터 자리에 제목 글자가 나와요.

미디어 파일 이름은 모두 소문자로 써요. `Poster.png`처럼 대문자가 섞이면 내 PC에서는 보여도 GitHub Pages에 올린 뒤에는 못 찾아요. 미리 만든 그림과 음악 세트는 [media/README.md](../media/README.md)에 있어요.
