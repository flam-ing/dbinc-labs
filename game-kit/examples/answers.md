# Claude가 실제로 한 답

[prompts.md](prompts.md)의 문장을 실제로 보냈을 때 Claude가 한 답이에요. 한 글자도 고치지 않았어요. 내 답이 이것과 똑같을 필요는 없어요. 비슷한 내용이 왔는지만 봐요.

2026-10-17에 Claude Code 2.1.301(모델 Opus 5.5)로 돌렸어요. 1~3은 채팅에 보낼 문장을 Claude Code에 보낸 것이라, 채팅에서는 "파일을 만들었어요" 대신 아티팩트 창이 열려요.

## 1. 게임 한 판

보낸 말: prompts.md 1절의 게임 프롬프트(피하기, 토끼, 당근, 내 아이디어 "점수가 오를수록 빨라져요"). 1분 50초 걸렸어요. 만든 게임은 [sample-game/index.html](sample-game/index.html)이에요.

````markdown
토끼가 떨어지는 당근을 피하는 게임을 `index.html` 파일 하나로 만들었어요. CSS와 JS도 모두 이 파일 안에 들어 있어요. 다만 아직 브라우저에서 실제로 실행해 보지는 못했어요. 문법 검사 명령도 승인되지 않아 돌리지 못했으니, 한 번 열어서 플레이해 봐 주세요.

**게임**
- 1초에 20점이 오르고, 300점(약 15초)이 되면 클리어예요. 화면 위에 진행 막대도 있어요.
- 말씀하신 대로 점수가 오를수록 빨라져요. 0점에서 300점으로 가면서 당근이 떨어지는 속도는 초당 110에서 210으로 빨라지고, 나오는 간격은 1.1초에서 0.65초로 짧아져요.
- 목숨은 5개이고, 부딪히면 1.5초 동안 깜빡이며 무적이에요. 다 잃으면 게임 오버 화면과 다시 하기 버튼이 나와요.
- 부딪힘 판정은 그림보다 작은 원으로 잡았어요. 토끼 그림 폭은 56px인데 판정 반지름은 16px이고, 당근도 몸통 가운데만 판정해요.
- 토끼, 당근, 구름, 땅, 하트는 모두 캔버스나 CSS 도형으로 그렸어요. 이모지, 바깥 글꼴, 외부 라이브러리는 쓰지 않았어요.

**조작**: 세 가지 모두 돼요.
- 키보드 ←, →
- 아래 ◀ ▶ 버튼: 누르고 있으면 계속 움직여요.
- 게임 화면 끌기: 손가락이나 마우스를 따라 토끼가 움직여요.

**화면**: 게임 화면 크기를 화면 폭과 높이에 맞춰 줄이도록 해서, 폭 390px 휴대폰에서도 가로 스크롤 없이 버튼까지 화면 안에 들어오게 했어요. 위쪽에는 점수와 하트 5개를 크게 보여 줘요.

**미디어 파일**: 경로는 `poster.png`, `music.mp3`, `ending.mp4` 그대로이고, fetch는 쓰지 않았어요.
- **poster.png**: 시작 화면에 크게 보여요. 파일이 없으면 `error` 이벤트를 받아 글자로 된 제목 화면을 대신 보여 줘요.
- **music.mp3**: 시작 버튼을 누른 뒤 반복 재생돼요. 아래 가운데 "음악 켬/끔" 버튼으로 끄고 켤 수 있어요. 파일이 없거나 재생이 막히면 `play()`의 catch로 조용히 건너뛰어요. 클리어하면 엔딩 영상과 겹치지 않게 음악을 멈추고, 다시 하기를 누르면 다시 재생돼요.
- **ending.mp4**: 클리어하면 화면 전체를 덮고 재생돼요. 끝나면 "클리어!"와 다시 하기 버튼이 나와요.
  - 소리 때문에 재생이 막히면 음소거로 한 번 더 시도해요.
  - 그래도 안 되거나 파일이 없으면 영상 없이 바로 다시 하기 버튼을 보여 줘요.

파일을 더블클릭해서 열어도 동작하도록 만들었어요. 난이도를 바꾸고 싶으면 스크립트 맨 위의 `FALL_MIN/FALL_MAX`와 `SPAWN_MIN/SPAWN_MAX` 값을 고치면 돼요.
````

## 2. 한 줄로 고치기: 레벨 세 단계

보낸 말: "레벨을 세 단계로 나눠 줘. 100점마다 레벨이 오르고, 화면 위에 지금 레벨을 크게 보여 줘. 다른 규칙은 그대로 둬." 28초 걸렸어요.

````markdown
`index.html`에 레벨을 세 단계로 넣었어요. 이번에도 브라우저에서 실제로 실행해 보지는 못했으니, 한 판 해 보면서 확인해 주세요.

- **레벨 나누기**: 0~99점은 레벨 1, 100~199점은 레벨 2, 200~299점은 레벨 3이에요. 300점이 되면 지금처럼 클리어예요.
- **레벨 표시**: 게임 화면 맨 위 진행 막대 바로 아래에 "레벨 1"을 크게 보여 줘요. 주황 글자에 흰 테두리를 둘러서 하늘 배경 위에서도 잘 보여요. 위쪽 점수·하트 줄은 휴대폰 폭에 이미 꽉 차서, 레벨은 게임 화면 안에 넣었어요. 그래서 화면 배치는 그대로예요.
- **레벨이 오를 때**: 화면 가운데에 "레벨 업!"이 1.5초 동안 크게 떴다가 서서히 사라져요.
- **다른 규칙**: 점수, 목숨, 무적 시간, 조작, 미디어 처리는 모두 그대로예요. 빨라지는 방식도 그대로 두어서, 레벨이 오르는 순간 갑자기 빨라지지 않고 점수에 따라 조금씩 빨라져요.

레벨이 오를 때 확 빨라지게 바꾸고 싶으면 말해 주세요. 레벨마다 당근 속도를 정해 두는 방식으로 바꿀 수 있어요.
````

## 3. 포스터 프롬프트 부탁

보낸 말: prompts.md 3절의 포스터 글. 4초 걸렸어요. 답은 그림 사이트에 붙여 넣을 영어 프롬프트 하나예요.

````markdown
```
Bright cute cartoon illustration, wide 16:9 landscape, flat colors with soft clean outlines, not a photo.
A fluffy white bunny with pink inner ears and rosy cheeks dashes sideways across green grass at the bottom, looking up with a brave, playful face.
Many bright orange carrots with green leafy tops fall from a light sky-blue sky with puffy white clouds, with speed lines that show they are falling fast.
Cheerful game poster mood, warm cream and orange accents, plenty of open sky at the top, no text, no letters, no logo, no watermark.
```
````

이 글을 Pollinations에 넣었더니 9초 만에 그림이 왔어요. 하얀 토끼와 풀밭, 하늘은 나왔는데 당근은 빠졌고, 오른쪽 아래에 사이트 이름 글자가 붙었어요. 바로 이어서 다시 누르니 한 번은 실패했고, 한 번은 2분 넘게 답이 없었어요. 무료 사이트는 이렇게 들쭉날쭉해요. 5분 넘게 막히면 미리 만든 파일을 받아요.

### 결과를 말하고 다시 부탁

보낸 말: "그림에 당근이 하나도 안 나왔어. 당근을 크게 여러 개 넣어서 프롬프트를 다시 써 줘." 같은 대화에 이어서 보냈고, 3초 걸렸어요. Claude는 당근을 맨 앞에 세워 프롬프트를 다시 썼어요.

````markdown
```
Bright cute cartoon illustration, wide 16:9 landscape, flat colors with soft clean outlines, not a photo, with many big orange carrots as the main focus.
Eight to ten LARGE bright orange carrots with green leafy tops fill the upper half of the light sky-blue sky, falling down at different angles with speed lines, each carrot clearly visible and big.
Below them, a small fluffy white bunny with pink inner ears and rosy cheeks dodges sideways on green grass at the bottom, looking up at the falling carrots.
Cheerful game poster mood, white puffy clouds, warm cream and orange accents, no text, no letters, no logo, no watermark.
```
````

이 글을 Pollinations에 넣었더니 10초 만에 큰 당근이 가득한 그림이 왔어요. 그런데 이번에는 토끼가 빠졌고 사진에 가까운 그림이 됐어요. 한 가지를 고치면 다른 것이 빠지기도 하니, 두세 장 만들어 가장 나은 것을 골라요.

## 4. Code 탭 첫 질문

보낸 말: "이 폴더에 뭐가 있어?" 폴더는 `my-game`(게임과 미리 만든 밝은 세트 세 파일)이고, Manual 모드였어요. 11초 걸렸고, Claude는 폴더 목록을 보고, `index.html` 앞부분을 읽고, 미디어 파일 이름이 나오는 줄을 찾았어요. 확인 카드는 뜨지 않았어요.

````markdown
이 폴더에는 **「토끼의 당근 피하기」**라는 브라우저 게임이 들어 있어요. 파일은 4개예요.

| 파일 | 크기 | 용도 |
|---|---|---|
| `index.html` | 약 19KB | 게임 본체. 화면, 스타일, 게임 코드가 모두 이 파일 하나에 들어 있어요 |
| `poster.png` | 약 700KB | 게임 포스터 이미지 |
| `music.mp3` | 약 640KB | 반복해서 재생되는 배경음악 |
| `ending.mp4` | 약 1.9MB | 엔딩 영상 |

`index.html`은 앞부분만 읽어 봤는데, 확인한 내용은 이래요.
- **화면 구성:** 위쪽에 점수와 하트 목숨이 표시되고, 그 아래 세로형(3:4) 캔버스에서 게임이 진행돼요.
- **모바일 대응:** 화면 폭이 최대 480px로 맞춰져 있고 터치 조작을 처리하도록 설정되어 있어요.
- **연결된 파일:** 나머지 세 파일은 모두 `index.html`이 불러와서 써요.

게임 규칙과 로직은 아직 자세히 보지 않았어요. 브라우저에서 `index.html`을 열면 바로 플레이할 수 있어요. 게임을 수정하거나 코드 동작을 설명해 드릴까요?
````

## 5. Code 탭 두 번째 질문

보낸 말: "이 게임의 점수 규칙을 설명해 줘. 아직 고치지 마." 14초 걸렸어요. 답 속 `index.html:242` 같은 표시는 그 파일의 줄 번호예요. [sample-game/index.html](sample-game/index.html)을 열어 같은 줄을 볼 수 있어요.

````markdown
이 게임에서 점수는 **버틴 시간**으로만 오르고, 당근을 피하거나 맞는 것은 점수와 관계가 없어요. 코드는 수정하지 않았어요.

## 점수 규칙

- **1초에 20점** (`index.html:242`)
  - 게임 중에는 매 프레임 `score += 20 × 경과시간`으로 점수가 올라가요 (`index.html:476`).
  - 소수점까지 계산되지만 화면에는 정수로만 보여요 (`index.html:348`).
- **300점이면 클리어** (`index.html:241`, `477`)
  - 맞지 않고 버티면 약 **15초** 만에 클리어돼요.
  - 클리어하면 점수가 정확히 300으로 맞춰지고, 음악이 멈추고 엔딩 영상이 나와요 (`index.html:383-390`).
- **당근에 맞으면 목숨이 줄어요** (`index.html:500-506`)
  - 목숨은 5개에서 시작하고, 한 번 맞을 때 1개씩 줄어요.
  - 맞아도 **점수는 깎이지 않아요.**
  - 맞은 뒤 1.5초 동안은 무적이에요. 이때 토끼가 깜빡이고, 무적 중에도 점수는 계속 올라요.
- **목숨이 0이 되면 게임 오버** (`index.html:377-381`)
  - 그때까지 모은 점수가 게임 오버 화면에 정수로 표시돼요.

## 점수에 따라 어려워지는 부분

점수가 0점에서 300점으로 올라가는 동안, 진행도(`score / 300`)에 비례해 난이도가 높아져요 (`index.html:449-484`).

| 항목 | 0점일 때 | 300점 직전 |
|---|---|---|
| 당근 떨어지는 속도 | 초당 110px | 초당 210px |
| 당근 나오는 간격 | 1.1초 | 0.65초 |

떨어지는 속도에는 당근마다 ±15% 정도의 무작위 차이가 붙어요. 화면 위쪽의 주황색 막대가 이 진행도를 보여 줘요.

## 알아 두면 좋은 동작

- **당근 개수와 무관:** 당근을 몇 개 피했는지는 점수에 들어가지 않아요. 시간만 버티면 점수가 올라요.
- **렉이 걸릴 때:** 한 프레임에 반영되는 시간이 최대 0.05초로 제한돼 있어요 (`index.html:673`). 화면이 버벅이면 점수도 실제 시간보다 천천히 올라요. 다른 탭에 갔다 오는 동안에도 점수가 한꺼번에 오르지 않아요.

점수 방식을 바꾸고 싶으시면 말씀해 주세요. 예를 들어 피한 당근 수로 점수를 주거나, 맞으면 점수를 깎는 식으로 바꿀 수 있어요.
````
