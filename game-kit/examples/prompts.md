# 게임을 더 고쳐 볼 때

3교시 수업 뒤에 내 게임을 더 고쳐 볼 때 보내는 문장이에요. 3교시 실습 문장은 [onepager/examples/prompts.md](../../onepager/examples/prompts.md)에 있어요. `<꺾쇠>` 안을 내 것으로 바꿔요.

## 수업 뒤에 해 볼 것

`my-game` 세션에 한 줄로 부탁해요. 끝에 "다른 규칙은 그대로 둬."를 붙이면 다른 곳까지 바뀌는 일이 줄어요.

```text
레벨을 <세 단계>로 나눠 줘. <100점>마다 레벨이 오르고, 화면 위에 지금 레벨을 크게 보여 줘. 다른 규칙은 그대로 둬.
```

실제로 보내 보니 28초 뒤에 "레벨 2", "레벨 업!"이 뜨는 게임이 왔어요. 답은 [answers.md](answers.md) 2절에 있어요.

이런 한 줄도 돼요.

- 더 쉽게 해 줘.
- 최고 점수를 기억해서 시작 화면에 보여 줘.
- 휴대폰에서 버튼을 두 배로 크게 해 줘.

그림 생성 사이트에 넣을 영어 문장을 Claude에게 부탁할 수도 있어요.

```text
이 게임의 시작 화면 포스터를 무료 그림 생성 사이트에서 만들려고 해.
이 게임의 주인공, 장애물, 색에 맞춰서 그림 생성용 영어 프롬프트를 4줄 안쪽으로 써 줘.
조건: 가로 16:9, 밝은 만화풍, 글자·로고·워터마크 없음, 사진 아님.
복사하기 좋게 코드 블록 하나에 프롬프트만 넣어 줘.
```

그림이 마음에 안 들면 본 대로 말하고 다시 부탁해요.

```text
그림에 <당근이 하나도 안 나왔어>. <당근을 크게 여러 개> 넣어서 프롬프트를 다시 써 줘.
```

실제로 보낸 답은 [answers.md](answers.md) 3절에 있어요. 무료 사이트는 두세 장 만들어 가장 나은 것을 골라요.
