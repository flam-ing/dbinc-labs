# DB Inc 교육 방명록 작업 지침

## 프로젝트 사실

- Python 표준 라이브러리 HTTP 서버와 SQLite, vanilla HTML/CSS/JavaScript를 사용하는 로컬 교육용 앱이다.
- 진입점은 app.py, 화면은 static/index.html, static/style.css, static/app.js다.
- 기본 실행은 `python3 app.py`, 검증은 `python3 smoke_test.py`다. 로컬 주소는 http://127.0.0.1:8000이다.
- DB는 data/guestbook.sqlite3에 저장된다. 기존 실습 기록을 지우지 않는다.

## 코딩 컨벤션

- GET /api/entries는 200 + {"entries": [...]}, POST는 201 + {"entry": {...}}를 유지한다.
- 이름 1~40자, 내용 1~500자 검증을 서버에서 수행한다. 오류는 설명이 있는 JSON으로 반환한다.
- 입력에는 연결된 label이 있어야 하며, 실패·저장 중·빈 목록 상태를 구분한다.
- UI의 기본은 따뜻한 흰 배경, 주황 강조, 읽을 수 있는 여백이다.
- 로컬 실행의 기본 수신 주소는 127.0.0.1로 유지한다.

## 금지 패턴

- 새로운 프레임워크나 외부 패키지를 추가하지 않는다.
- SQL에는 매개변수를 사용한다. 사용자 입력 문자열로 SQL을 조립하지 않는다.
- 사용자 입력은 DOM의 textContent로 표시한다. innerHTML로 삽입하지 않는다.
- 의미 없는 애니메이션을 추가하지 않는다.
- 요청과 관련 없는 파일은 수정하지 않는다. 기존 학습자 코드를 참조 구현으로 덮어쓰지 않는다.

## 작업 순서

- README와 수정할 파일을 먼저 읽고 현재 동작을 확인한다.
- 요청한 기능의 완료 기준과 바꿀 파일을 짧게 제시한 다음 고친다.

## 리뷰 기준

- 정상 등록, 빈 값·초과 길이, 목록 새로고침, 같은 DB로 서버 재시작을 확인한다.
- HTTP 검사는 `python3 smoke_test.py`로 실행하고 실패하면 원인을 해결한다.
- 화면 변경은 브라우저에서 직접 확인한다. 테스트 통과만으로 화면 확인을 대신하지 않는다.
- 완료 보고는 변경 파일, 실행한 검사와 결과, 아직 확인하지 못한 항목 순서로 적는다.
- 실행하지 않은 테스트나 모델 비교 결과를 통과했다고 쓰지 않는다.

이 파일은 작업 지침이다. 실행 권한이나 보안 경계를 대신하지 않으며 지침 준수를 보장하지 않는다.
