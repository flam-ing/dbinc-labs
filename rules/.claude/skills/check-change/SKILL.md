방명록 변경을 검토하세요. 추가 관점: $ARGUMENTS

1. README와 CLAUDE.md로 실행 방법·요구사항·검토 기준을 확인하세요.
2. Git이 있으면 status, diff, staged diff와 관련 새 파일을 확인하세요. Git이 없으면 한계를 밝히고 지정된 기준 사본과 비교하세요. 새 저장소를 만들지 마세요.
3. 서버 입력 검증, 매개변수 SQL, textContent, 오류 표시, 기존 API 계약을 검토하세요.
4. 제공된 `python3 smoke_test.py`를 실행하세요. 실행 불가이면 이유를 보고하고 설치나 환경 변경을 임의로 하지 마세요.
5. 가능한 경우 실제 브라우저에서 변경된 흐름을 확인하세요. 하지 못한 검사를 통과했다고 기록하지 마세요.
6. 발견한 문제와 파일 근거, 실제 검사 결과, 남은 미확인 항목을 보고하세요.

이 절차는 검토만 수행합니다. 작업 파일 수정, 실습 데이터 삭제, 커밋, 전송, 배포를 하지 마세요.
