대상 파일: $ARGUMENTS (비어 있으면 README.md)

이 README를 "이 저장소를 처음 받은 동료"가 읽는 안내문으로 다시 써요. 원본은 그대로 두고, 같은 폴더에 `README.people.md`를 새로 만들어요.

1. 대상 README와, README에 나오는 실행·검사 파일(예: app.py, smoke_test.py)을 읽어요.
2. 아래 다섯 절을 이 순서로 짧게 써요.
   - 이게 무엇인가요: 두세 문장. 누가 무엇을 하려고 쓰는지 적어요.
   - 켜는 법: 복사해서 바로 쓰는 명령. 명령마다 무엇이 보이면 성공인지 한 줄씩 적어요.
   - 확인하는 법: 검사 명령과, 성공했을 때 보이는 결과를 적어요.
   - 자주 막히는 곳: 증상, 원인, 해결 세 칸 표. 원본에 근거가 있는 것만 넣어요.
   - 더 알아보기: 원본의 나머지 내용이 어디에 있는지 알려 줘요.
3. 수업 진행, 교시, 강사에게 하는 말처럼 이 프로젝트를 쓰는 사람에게 필요 없는 내용은 빼요.
4. 명령, 경로, 포트, 숫자는 원본이나 코드에서 확인한 것만 써요. 확인하지 못한 명령에는 "확인 필요"라고 붙여요.
5. 문장은 polish-ko 스킬의 규칙(쉬운 해요체 완전한 문장)을 따라요.
6. 다 쓰면 원본에서 뺀 내용을 세 줄 이내로 알려 줘요.

README.md와 코드 파일은 고치지 않아요. 결과를 확인하려고 실행해도 되는 명령은 파일을 바꾸지 않는 검사 명령(`python3 smoke_test.py`)뿐이에요.
