# /check-change 실제 답

같은 요청으로 바뀐 B 사본에 `labs/rules/.claude`를 넣고 `/check-change 제목과 오류 안내 변경 뒤 입력 검증을 확인`을 보냈을 때 Claude가 한 답이에요(2026-10-17, Claude Code 2.1.302, Sonnet 5.5, Manual 모드, 23초). 아래 줄 밑은 Claude가 쓴 글자 그대로예요. 내 결과와 나란히 놓고 "파일을 고치지 않았는지", "검사를 실제로 돌렸는지", "확인하지 못한 항목을 따로 적었는지"를 비교해 봐요. 바뀐 내용은 사본마다 달라서 문제 목록은 내 것과 달라요.

## 검토 결과

제목과 오류 안내 변경 뒤에도 서버 입력 검증은 그대로 동작해요. 기존 API 약속도 깨지지 않았어요. 다만 브라우저 확인은 하지 못했어요.

### 변경 파일
`app.py`, `static/app.js`, `static/index.html`, `static/style.css`가 수정됐고, `.claude/`는 새 파일이에요. 이번 검토에서는 아무 파일도 고치지 않았어요.

### 확인한 내용
- **서버 검증** (`app.py`의 `validate_entry`)
  - 이름 40자, 내용 500자, 공백만 있는 값 거부는 그대로예요.
  - 오류 메시지에 현재 글자 수가 들어가고, 400 응답에 `field`가 추가됐어요.
  - `error` 키는 유지돼요.
  - `UnicodeDecodeError`는 `ValueError`의 하위 클래스라서 마지막 `except ValueError`에서 "JSON 형식을 확인해 주세요."로 처리돼요.
- **API 계약**: GET 200 `{"entries"}`와 POST 201 `{"entry"}`는 바뀌지 않았어요.
- **SQL과 DOM**
  - 이번 diff에서 SQL을 건드린 곳은 없고, 기존 매개변수 SQL이 그대로예요.
  - 오류 문구는 `textContent`로만 넣어요. `innerHTML`은 쓰지 않았어요.
- **접근성**
  - 오류 `<p>`는 `aria-describedby`로 입력과 연결돼요. 오류가 있으면 `aria-invalid`가 켜져요.
  - 기존 label은 그대로예요.
- **화면 문구**: `<title>`과 `<h1>`이 "DB Inc 실습 방명록"으로 바뀌었어요.

### 문제점 (모두 낮은 심각도)
1. **글자 수 계산이 클라이언트와 서버에서 달라요.** (`static/app.js`의 `checkInputs`)
   - JS의 `.length`는 UTF-16 단위로, Python의 `len()`은 코드포인트로 세어요.
   - 이모지처럼 보충 평면 문자가 많으면 서버는 받아 줄 입력을 화면이 먼저 막고, "지금은 N자예요"의 숫자도 서버와 달라요.
   - 예를 들어 이모지 30개는 서버 기준 30자라서 통과하지만, 화면에서는 60으로 계산돼 거부돼요.
   - HTML `maxlength`도 같은 UTF-16 기준이라, 원래 있던 한계예요.
   - 고치려면 `[...value.trim()].length`를 쓰면 돼요.
2. **`<title>`이 요청 범위와 맞는지는 제가 판단하지 못했어요.** "제목 변경"이 `<title>`과 `<h1>`을 모두 가리키는지 확인이 필요해요.

### 실행한 검사
- `python3 smoke_test.py`: 3개 테스트 모두 통과(OK)했어요. 저장, 검증 거부 후 미삽입, 정적 경로를 확인하고, 임시 포트와 임시 DB를 썼어요.

### 확인하지 못한 항목
- **브라우저 확인**: 이번 세션에서 브라우저를 띄우지 못해서 아래 항목은 직접 보지 못했어요. CLAUDE.md는 테스트 통과만으로 화면 확인을 대신하지 않도록 해요.
  - 빈 값과 초과 길이 입력 시 필드별 오류 표시, 포커스 이동
  - 서버 오류와 연결 실패 안내, 저장 중 상태
  - 목록 새로고침과 `hidden` 오류 문단의 표시
- **같은 DB로 서버 재시작**: smoke test가 임시 DB로 재시작 유지를 확인하는지는 코드로 보지 않았어요. 실제 `data/guestbook.sqlite3`로는 확인하지 않았어요.
- `.claude/` 안의 내용은 이번 검토 범위에서 읽지 않았어요.
