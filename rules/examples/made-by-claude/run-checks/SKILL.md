방명록 검사를 실행하고 결과만 짧게 보고하세요. 추가 관점: $ARGUMENTS

1. `python3 smoke_test.py`를 프로젝트 루트에서 실행하세요. 이 검사는 임시 포트와 임시 DB를 쓰므로 data/guestbook.sqlite3를 건드리지 않습니다.
2. 실행할 수 없으면 이유만 보고하세요. 패키지 설치나 환경 변경을 임의로 하지 마세요.
3. 실패하면 실패한 검사 이름과 핵심 오류 한두 줄만 적으세요. 원인을 추측해 고치지 마세요.
4. 아래 형식으로 짧게 보고하세요.
   - 결과: 통과 또는 실패 (통과·실패 검사 개수)
   - 실패 항목: 있을 때만
   - 확인하지 못한 항목: 브라우저 화면 확인은 이 스킬이 하지 않으므로 항상 적으세요.

이 스킬은 검사만 실행합니다. 파일 수정, 실습 데이터 삭제, 커밋, 전송, 배포를 하지 마세요. 코드 리뷰나 git diff 분석도 하지 않습니다(그것은 /check-change의 일입니다).
