방명록 검사를 실행하고 결과를 보고하세요. 추가 관점: $ARGUMENTS

1. `python3 smoke_test.py`를 실행하세요.
2. 통과한 검사 수와 실패한 검사 이름을 한국어로 짧게 보고하세요. 검사 이름은 출력에 나온 그대로 쓰세요.
3. 실패가 있으면 원인 후보를 한 줄로만 적으세요.

이 절차는 검사만 수행합니다. 작업 파일 수정, 패키지 설치, 커밋, 배포를 하지 마세요.
