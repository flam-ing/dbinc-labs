# 1교시 예시 문장 모음

1일차 1교시 실습에서 쓰는 예시 문장이에요. 코드 블록에 넣은 문장은 수업 전에 Claude에 실제로 보내 보고 통한 문장이에요. 웹 채팅 실습은 claude.ai 대신 도구를 끈 Claude에 같은 문장을 보내 확인했어요. 그래서 내 화면의 답은 문장이 조금 다를 수 있어요. 그대로 써도 되지만, 대괄호 `[ ]` 부분을 내 것으로 바꿔 써 보면 더 좋아요. 보낼 때 대괄호는 빼요.

실제로 나온 결과는 `results/` 폴더에 그대로 넣어 두었어요. 내 결과와 문장이 달라도 괜찮아요. 무엇을 했고 누가 옮겼는지만 비교해요.

> 회사 자료나 고객 데이터는 챗봇에 올리지 않아요. 오늘은 이 폴더의 가상 자료만 써요.

## 실습 1 · F12로 직접 (4분)

문장을 보내는 실습이 아니에요. 브라우저에서 아래 순서로 해요.

1. Chrome이나 Edge에서 `test-server-8az.pages.dev`를 열고 `F12`(macOS는 `Cmd+Option+I`)를 눌러요. **Network** 탭을 고르고 새로고침해요. 맨 위 줄이 `200`, `document`인지 봐요.
2. **Elements** 탭에서 화살표 아이콘으로 가격을 누르고, 가격 글자를 더블클릭해 `[0원]`으로 바꿔요.
3. 새로고침해서 가격이 돌아오는지 봐요. 새 탭에 `test-server-8az.pages.dev/api/price`를 열어 같은 가격이 데이터로만 오는지 봐요.

바꿀 곳: `[0원]` 대신 상품 이름을 바꿔 봐도 돼요.

## 실습 2 · 챗봇에 파일 일 맡기기 (5분)

claude.ai나 데스크톱 앱 **Chat** 탭에 보내요.

```text
내 PC에 있는 [orders.csv]에서 [금액 열의 합계]를 구해서, 같은 폴더에 [total.md] 파일로 저장해 줘. 다른 파일은 고치지 마.
```

그다음 입력창 왼쪽 아래 **+**에서 **Add files or photos**로 파일을 올리고 같은 문장을 다시 보내요. 올리기가 막히면 파일 내용을 글로 붙여 넣어요.

바꿔 볼 파일과 일이에요.

| 파일 | 시킬 일 예 |
| --- | --- |
| `../orders.csv` (가상 주문 5건) | 금액 열의 합계, 매장별 합계 |
| `expenses.csv` (가상 출장비 5건) | 부서별 합계를 `expense-total.md`로 |
| `meeting-notes.txt` (가상 회의 메모) | 할 일만 뽑아 `todo.md`로 |

실제로 돌려 보니: 합계 89,000원은 구해 줬지만 "웹 채팅이라 PC에 저장할 수 없다"며 `total.md` 내용과 저장 방법을 알려 줬어요(`results/chat-answer.md`). 복사해서 메모장에 붙이고 저장하는 일은 사람이 해요.

파일을 바꿔 보낸 예시예요. 대괄호 세 곳만 바꿨어요.

```text
내 PC에 있는 [expenses.csv]에서 [부서별 합계]를 구해서, 같은 폴더에 [expense-total.md] 파일로 저장해 줘. 다른 파일은 고치지 마.
```

실제로 돌려 보니: 영업1팀 271,600원(3건), 기획팀 38,900원(2건), 모두 310,500원을 구하고, 이번에도 `expense-total.md`에 넣을 내용과 저장 방법만 알려 줬어요(`results/expense-answer.md`).

`meeting-notes.txt`는 합계를 구할 파일이 아니라서, 시킬 일 칸을 문장에 맞게 바꿨어요.

```text
내 PC에 있는 [meeting-notes.txt]에서 [할 일만 뽑아서], 같은 폴더에 [todo.md] 파일로 저장해 줘. 다른 파일은 고치지 마.
```

실제로 돌려 보니: 할 일 세 개(주문 보고 메일, 판교점 녹차 재고 확인, 출장비 영수증 제출)를 체크 상자로 뽑고, 담당이 적히지 않은 주문 보고는 "담당 미정"으로 표시했어요. 다음 회의 일정은 할 일이 아니라서 "참고"로 따로 뺐어요. 이번에도 `todo.md`에 넣을 내용과 저장 방법만 알려 줬어요(`results/todo-answer.md`).

강사 화면의 Code 탭에는 이 문장을 보내요. 폴더를 이미 골랐으니 "내 PC에 있는"은 뺐어요.

```text
orders.csv에서 금액 합계를 구해서 total.md로 저장해 줘. 다른 파일은 고치지 마.
```

실제로 돌려 보니: `orders.csv`를 직접 읽고, 계산 명령을 실행해도 되는지 묻고, 같은 폴더에 `total.md`(14줄)를 만들었어요(`results/total.md`). 마지막에 "금액이 단가라면 223,000원"이라고 덧붙였는데, 이것은 틀린 계산이에요. 수량을 곱해 더하면 228,800원이에요. 에이전트의 결과도 사람이 확인해요.

## 실습 3 · 기록 남기고 이어 하기 (3분)

실습 2의 채팅에 이어서 보내요.

```text
지금까지 한 일을 다음 사람이 이어서 할 수 있게 [NOTES.md]로 정리해 줘. 결정한 것, 지금 상태, 다음 할 일 세 칸으로 짧게 써 줘. 다음 할 일은 [매장별 합계]야.
```

받은 내용을 메모장에 붙여 바탕화면 `dbinc-notes` 폴더에 `NOTES.md`로 저장해요(`results/NOTES.md`). 그다음 **새 채팅**을 열고 `NOTES.md`와 `orders.csv`를 함께 올리거나 붙여 넣은 뒤 보내요.

```text
아래 NOTES.md를 읽고 '다음 할 일'부터 마저 해 줘.
```

실제로 돌려 보니: 새 대화는 앞 대화를 모르는데도 NOTES.md만 읽고 매장별 합계(강남점 37,200원, 판교점 51,800원)부터 이어서 했어요(`results/continue-answer.md`).

바꿀 곳: 다음 할 일을 `[가장 많이 팔린 상품]`, `[날짜별 합계]`처럼 바꿔 봐요.

## 실습 4 · 규칙대로 검토 받기 (3분)

`rules.md`(규칙 다섯 줄)와 `draft-mail.txt`(메일 초안)를 함께 올리거나 붙여 넣고 보내요.

```text
아래 [rules.md]대로 [메일 초안]을 검토해 줘. 규칙마다 지켰는지 표로 보여 주고, 고친 초안을 줘.
```

실제로 돌려 보니: 규칙 1~4를 어긴 네 곳(결론이 다섯째 줄, 89000원, 요일 없음, 첨부 파일 이름 없음)을 모두 찾아 고쳤어요. 규칙에 없는 "강남점이 더 많이 팔았어요"는 고치지 않고 "사람 확인"으로 남겼어요(`results/rules-review.md`). 실제로는 판교점이 51,800원으로 더 많아요. 결론을 첫 줄에 두려고 인사말 "안녕하세요"를 뺀 일도 "사람 확인"에 적었어요. 파일 이름을 `규칙.md`로 붙여 보낸 다른 실행도 같은 모양으로 답했어요.

바꿀 곳: `rules.md`에 내 규칙 한 줄을 더하거나(예: "제목에 날짜를 넣어요"), 초안을 내가 최근에 쓴 짧은 글로 바꿔요. 회사 글이면 이름과 숫자를 지우고 써요.
