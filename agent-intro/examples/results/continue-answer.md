매장별 합계를 계산하고, 저장 위치는 NOTES의 결정("결과는 total.md에 저장, 다른 파일은 수정하지 않음")에 맞춰 **total.md에 추가**하는 것으로 정했어요.

## 매장별 금액 합계

| 매장 | 건수 | 금액 합계 |
|---|---|---|
| 강남점 | 3건 | 37,200원 (18,000 + 12,000 + 7,200) |
| 판교점 | 2건 | 51,800원 (25,800 + 26,000) |
| **전체** | **5건** | **89,000원** |

두 매장 합계(37,200 + 51,800)가 기존 전체 합계 89,000원과 일치해요.

## 저장 위치: total.md에 추가

별도 파일로 두지 않은 이유는 두 가지예요.
- 결과는 total.md에 저장하기로 이미 정해져 있어요.
- 전체 합계와 매장별 합계를 한 파일에서 함께 볼 수 있어요.

이전에 준비한 total.md가 실제로 저장됐는지 아직 확인되지 않았어요. 그래서 추가(`>>`) 대신 **전체 합계와 매장별 합계를 모두 담은 내용으로 total.md를 새로 쓰는 명령**을 준비했어요. 저장이 이미 됐든 안 됐든 결과가 같아요.

orders.csv가 있는 폴더에서 실행하세요.

```zsh
cat > total.md <<'EOF'
# 주문 금액 합계 (orders.csv)

- 전체 금액 합계: 89,000원 (5건)
- 기준: '금액' 열 값을 그대로 더함 (수량을 곱하지 않음)

## 매장별 금액 합계

| 매장 | 건수 | 금액 합계 |
|---|---|---|
| 강남점 | 3건 | 37,200원 |
| 판교점 | 2건 | 51,800원 |
| 합계 | 5건 | 89,000원 |
EOF
cat total.md
```

마지막 줄 `cat total.md`가 저장된 내용을 바로 보여 주니, 출력이 위와 같으면 저장된 거예요. 저는 웹 채팅에서 파일을 직접 저장할 수 없어서, 실제 저장 여부는 이 확인으로 판단해 주세요.

```markdown
- total.md 생성 명령은 준비됨. 실제 저장 여부는 `cat total.md`로 확인 필요

## 다음 할 일
- total.md 저장 확인
```
