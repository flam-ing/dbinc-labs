이 채팅 화면에서는 PC의 파일을 읽거나 저장할 수 없어서 todo.md를 직접 만들지 못했어요. 첨부해 주신 내용으로 할 일을 정리했으니, 아래 내용을 복사해서 meeting-notes.txt와 같은 폴더에 `todo.md`로 저장하시면 돼요. 다른 파일은 건드리지 않아요.

```markdown
# 할 일 (2026년 10월 13일 주간 회의)

- [ ] 10월 주문 보고 메일 보내기 (매주 월요일 오전) — 담당 미정
- [ ] 판교점 녹차 재고 숫자 확인 — 전산팀
- [ ] 출장비 영수증 사진 모아서 제출 (마감 10월 20일) — 영업1팀

## 참고
- 다음 회의: 10월 20일 화요일 10시
```

- 주문 보고는 회의 메모에 담당 팀이 적혀 있지 않아 "담당 미정"으로 표시했어요.
- 다음 회의 일정은 할 일이 아니라서 "참고"에 따로 넣었어요.

**파일 만드는 방법 (Mac)**
1. 텍스트 편집기에서 새 문서를 열어요.
2. 메뉴에서 **포맷 → 일반 텍스트로 만들기**를 선택해요.
3. 위 내용을 붙여넣고 meeting-notes.txt가 있는 폴더에 `todo.md`라는 이름으로 저장해요. 확장자를 바꿀지 물어보면 **".md 사용"**을 선택하세요.

Claude Code처럼 파일에 접근할 수 있는 환경에서 요청하시면 파일을 직접 저장해 드릴 수 있어요.
