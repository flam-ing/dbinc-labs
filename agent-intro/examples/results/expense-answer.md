저는 지금 웹 채팅에서 대화하고 있어서 PC의 파일을 직접 읽거나 쓸 수 없어요. 대신 첨부해 주신 데이터로 합계를 계산해서 `expense-total.md`에 넣을 내용을 만들었어요. 기존 파일은 건드리지 않았어요.

**expense-total.md**

```markdown
# 부서별 경비 합계

| 부서 | 건수 | 합계(원) |
|---|---:|---:|
| 영업1팀 | 3 | 271,600 |
| 기획팀 | 2 | 38,900 |
| **총계** | **5** | **310,500** |
```

**계산 내역**
- 영업1팀: 119,600 + 88,000 + 64,000 = 271,600
- 기획팀: 15,400 + 23,500 = 38,900

**저장 방법**
1. 메모장이나 텍스트 편집기를 열어요.
2. 위 코드 블록 안의 내용을 붙여 넣어요.
3. `expenses.csv`와 같은 폴더에 `expense-total.md`라는 이름으로 저장해요. 인코딩은 UTF-8로 선택해 주세요.

Claude Code처럼 파일 접근 권한이 있는 환경에서 요청하시면 파일을 직접 만들어 드릴 수 있어요.
