# 메일 초안 검토 결과

## 규칙별 점검

| 규칙 | 결과 | 근거 | 조치 |
|---|---|---|---|
| 1. 첫 줄에 결론 | ❌ 안 지킴 | 결론(합계 89000원)이 다섯째 줄에 있어요. | 합계 문장을 인사와 합쳐 첫 줄로 옮겼어요. |
| 2. 금액 쉼표와 "원" | ❌ 안 지킴 | "89000원"에 쉼표가 없어요. | "89,000원"으로 고쳤어요. |
| 3. 날짜에 요일 | ❌ 안 지킴 | "10/1", "10/3"에 요일이 없어요. | "10월 1일(목)", "10월 3일(토)"로 고쳤어요. 연도는 2026년으로 보고 계산했어요. |
| 4. 첨부 파일 이름 | ❌ 안 지킴 | "첨부 파일"이라고만 썼어요. | 파일 이름을 알 수 없어서 `[파일 이름]` 자리만 비워 두었어요. **사람 확인**이 필요해요. |
| 5. 규칙 밖은 사람 확인 | ✅ 지킴 | 규칙에 없는 내용은 고치지 않았어요. | 아래 "사람 확인" 목록에 따로 적었어요. |

## 고친 초안

```
제목: 10월 첫 주 주문 보고

팀장님, 10월 첫 주 주문 합계는 89,000원이에요.
10월 1일(목)부터 10월 3일(토)까지 강남점과 판교점 주문을 정리했어요.
강남점은 생수, 커피믹스, 건전지가 나갔고 판교점은 세제와 녹차가 나갔어요.
매장별로는 강남점이 더 많이 팔았어요.
자세한 내용은 첨부 파일 [파일 이름]을 확인해 주세요.
```

## 사람 확인

1. **첨부 파일 이름**: 실제 파일 이름을 `[파일 이름]` 자리에 넣어 주세요.
2. **연도와 요일**: 2026년으로 가정했어요. 다른 해라면 요일이 달라져요.
3. **"10월 첫 주"와 기간**: 정리한 기간은 10월 1일부터 3일까지 사흘이에요. 이 사흘을 "첫 주"로 불러도 되는지 확인해 주세요.
4. **"강남점이 더 많이 팔았어요"**: 근거가 되는 매장별 금액이나 수량이 없어요. 숫자를 넣을지 정해 주세요.
5. **인사말 위치**: 규칙 1을 지키려고 "안녕하세요"를 빼고 결론을 인사와 같은 줄에 두었어요. 인사말을 따로 살리고 싶으면 알려 주세요.
