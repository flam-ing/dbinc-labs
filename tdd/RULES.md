# 우리 회사 규칙: 개인정보 가리기

방명록에 사용자가 쓴 글은 저장하거나 화면에 보여 주기 전에 아래 규칙대로 개인정보를 가려요.

## 1. 휴대폰 번호

010, 011, 016, 017, 018, 019로 시작하는 번호예요. 하이픈으로 나눠 써도, 띄어 써도, 붙여 써도 모두 휴대폰 번호로 봐요. 가운데 자리를 같은 개수의 `*`로 바꿔요.

| 원래 글 | 가린 글 |
| --- | --- |
| `010-1234-5678` | `010-****-5678` |
| `01012345678` | `010****5678` |
| `010 1234 5678` | `010 **** 5678` |
| `011-123-4567` | `011-***-4567` |

## 2. 주민등록번호

`YYMMDD-NNNNNNN`처럼 하이픈이 있는 13자리 번호예요. 뒷자리 첫 숫자만 남기고 나머지를 `*`로 바꿔요.

| 원래 글 | 가린 글 |
| --- | --- |
| `900101-1234567` | `900101-1******` |

## 3. 그대로 두는 숫자

휴대폰 번호와 주민등록번호가 아닌 숫자는 바꾸지 않아요.

| 원래 글 | 가린 글 |
| --- | --- |
| 주문번호 `2024-1234-5678` | 주문번호 `2024-1234-5678` |
| 금액 `1,000,000원` | 금액 `1,000,000원` |
| 일반 전화 `02-123-4567` | 일반 전화 `02-123-4567` |

## 4. 여러 개가 들어 있을 때

한 글에 번호가 여러 개 있으면 모두 가려요. 번호가 아닌 나머지 글자는 그대로 둬요.

| 원래 글 | 가린 글 |
| --- | --- |
| `연락처 010-1234-5678, 주민번호 900101-1234567` | `연락처 010-****-5678, 주민번호 900101-1******` |

## 왜 이 규칙이 코드와 테스트여야 하나요

해외 예제나 범용 라이브러리에는 주민등록번호 규칙이 없어요. AI도 따로 알려 주지 않으면 이 규칙을 모르고 코드를 써요. 우리 회사는 금융 계열이라서 개인정보보호법에 따라 화면, 로그, DB 어디에도 원래 번호가 남으면 안 돼요. 그래서 이 규칙은 AI에게 하는 "부탁"으로 끝나면 안 되고, 코드 기능과 그 기능을 확인하는 테스트로 있어야 해요.
