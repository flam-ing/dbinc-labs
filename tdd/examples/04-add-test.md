# 4. `/add-test EntryController`: 실제로 나온 결과

전체 기록과 테스트 파일은 `_reference/claude-runs/07-skill-add-test.md`와 `files/EntryControllerTest.add-test.java`에 있어요.

## Claude의 답 (그대로)

> 통과 30개, 실패 0개예요. `EntryControllerTest`가 14개, `PrivacyMaskerTest`가 16개예요.
> 
> `EntryControllerTest.java`만 고쳤고, 대상 코드는 건드리지 않았어요.
> 
> - **경계값:** 빈 글, 한 글자 글, 1만 자 글, 글이 없을 때의 빈 목록을 넣었어요.
> - **`RULES.md` 사례:** 휴대폰 번호 4가지, 주민등록번호, 그대로 두는 숫자, 번호가 여러 개인 글을 넣었어요. 가린 글이 목록에도 가려진 채로 나오는지도 확인해요.

## 만든 테스트 이름 (기존 1개 포함)

```text
등록한_글이_목록에_나온다
글이_없으면_목록은_비어_있다
빈_글은_빈_채로_저장된다
한_글자_글은_그대로_저장된다
아주_긴_글은_그대로_저장된다
목록을_바꿔도_저장된_글은_변하지_않는다
하이픈이_있는_휴대폰_번호는_가운데가_가려진다
붙여_쓴_휴대폰_번호는_가운데가_가려진다
띄어_쓴_휴대폰_번호는_가운데가_가려진다
가운데가_세_자리인_휴대폰_번호는_별_세_개로_가려진다
주민등록번호는_뒷자리_첫_숫자만_남고_가려진다
휴대폰_번호가_아닌_숫자는_그대로_둔다
번호가_여러_개면_모두_가려진다
가려진_글이_목록에도_가려진_채로_나온다
```

## 테스트 하나 (그대로)

```java
	@Test
	void 아주_긴_글은_그대로_저장된다() {
		// 준비
		String message = "가".repeat(10_000);

		// 실행
		String saved = 등록하고_저장된_글(message);

		// 확인
		assertThat(saved).isEqualTo(message);
	}
```
