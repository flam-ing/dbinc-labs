# 3. CLAUDE.md가 있을 때와 없을 때: 실제로 나온 결과

같은 말("글을 저장할 때 서버 로그에 어떤 글이 들어왔는지 남겨 줘.")을 CLAUDE.md 없는 사본(A)과 있는 사본(B)에 두 번씩 보냈어요. 전체 기록은 `_reference/claude-runs/06-code-rules-ab.md`에 있어요.

| 사본 | Claude가 넣은 줄 | 테스트 중 실제로 찍힌 로그 |
| --- | --- | --- |
| A 1회 | `log.info("방명록 글 저장: name={}, message={}", saved.name(), saved.message());` | `방명록 글 저장: name=민지, message=연락처 010-****-5678, 주민번호 900101-1******` |
| A 2회 | `log.info("방명록 글 저장: name={}, message={}", saved.name(), saved.message());` | `방명록 글 저장: name=민지, message=연락처 010-****-5678, 주민번호 900101-1******` |
| B 1회 | `log.info("방명록 글 저장: {}", saved.message());` | `방명록 글 저장: 연락처 010-****-5678` |
| B 2회 | `log.info("방명록 글 저장: {}", saved.message());` | `방명록 글 저장: 연락처 010-****-5678, 주민번호 900101-1******` |

A도 번호는 가렸어요. `RULES.md`에 "로그에도 원래 번호가 남으면 안 된다"고 적혀 있어서예요. 차이는 이름이에요.

## B(CLAUDE.md 있음) Claude의 답 일부

> **글 원문 대신 가린 글을 남겨요.** 프로젝트 규칙이 "로그에 사용자 입력 원문을 찍지 않는다"이고, `RULES.md`도 로그에 원래 번호가 남으면 안 된다고 해요. 그래서 `PrivacyMasker.mask`를 거친 글만 찍어요. 예를 들어 `연락처 010-1234-5678`을 저장하면 로그에는 `연락처 010-****-5678`이 남아요. 어떤 글이 들어왔는지는 알 수 있지만 번호는 남지 않아요. 작성자 이름도 사용자 입력이라 로그에는 넣지 않았어요. 원문을 그대로 남겨야 한다면 규칙과 충돌하니, 그 경우엔 알려 주세요.

## A(CLAUDE.md 없음) Claude의 답 일부

> - **번호 가림:** 로그에는 번호를 가린 뒤의 글만 찍혀요. `RULES.md`에서 로그에도 원래 번호가 남으면 안 된다고 했기 때문이에요.
> - **`name` 필드:** 이름은 가리지 않고 그대로 찍어요. 이름에 번호가 들어올 수 있는지는 규칙에 없어서 따로 처리하지 않았어요.
> - **바뀐 곳:** `EntryController.java`의 `add`에서 저장 직후에 로그를 남겨요.
> - **테스트:** `EntryControllerTest.java`에 테스트 두 개를 먼저 썼어요.
>   - 글 내용이 로그에 남는지 확인해요.
>   - 휴대폰 번호와 주민번호를 보냈을 때 원래 번호가 로그에 없고 가린 글만 있는지 확인해요.
>   - 구현 전에는 두 테스트가 모두 실패했어요.
