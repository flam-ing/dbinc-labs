# 방명록 실습 프로젝트

## 프로젝트 사실
- 서버(api): `cd api && ./gradlew build`로 빌드해요. 테스트만 돌릴 때는 `./gradlew test`를 써요.
- 화면(web): `cd web && npm run build`로 빌드해요. 테스트만 돌릴 때는 `npm test`를 써요.
- 파이썬(py): `cd py && python3 -m unittest`로 테스트해요.
- 개인정보 가리기 규칙은 `RULES.md`에 있어요.

## 코드 규칙
- 사용자가 쓴 글은 저장, 출력, 로그 전에 `PrivacyMasker.mask`(웹은 `mask`)를 거쳐요.
- 로그에 사용자 입력 원문을 찍지 않아요.
- 새 의존성을 추가하지 않아요.
- 테스트 메서드 이름은 한글로 `무엇은_어떻게_된다` 모양으로 써요.

## 금지
- 테스트를 지우거나 기대값을 바꿔서 통과시키지 않아요.
