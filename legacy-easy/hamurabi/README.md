# HAMURABI (1968 · 1978)

50년도 넘은 진짜 오래된 프로그램이에요. 고대 수메르의 왕 함무라비가 되어 10년 동안 나라를 다스려요. 해마다 땅을 사고팔고, 백성에게 곡식을 나눠 주고, 씨를 뿌려요. 흉년, 쥐, 역병이 끼어들어요.

| 파일 | 내용 |
| --- | --- |
| `hammurabi.bas` | 1978년 BASIC 원본(119줄). 줄 번호와 GOTO로 흐름을 정해요 |
| `python/hamurabi.py` | 같은 게임을 요즘 파이썬으로 옮긴 판. 돌려 볼 때 써요 |
| `issues/` | 가상의 정책 변경 카드 두 장 |
| `SOURCE.md`, `LICENSE` | 출처와 라이선스(퍼블릭 도메인) |

## 돌려 보기

BASIC 원본은 요즘 PC에서 바로 돌리기 어려워요. 같은 규칙의 파이썬 판으로 돌려요.

    python3 python/hamurabi.py

숫자를 물어보면 입력해요. 첫해에는 땅 0, 곡식 2000, 씨뿌리기 900을 넣어 보면 돼요. Windows는 `python3` 대신 `py`를 써요.
