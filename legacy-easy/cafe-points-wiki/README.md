## 쓰는 곳

1일차 5교시([레거시 분석](../../../docs/day1-legacy.md)) 실습 6에서 써요. Claude에게 이 자료를 읽히고 코드와 다른 곳을 찾아요. 2일차 2교시([지식베이스, LLM 위키, 옵시디언](../../../docs/day1-kb.md)) 실습 2에서도 써요. `메신저-2021-03-마감-1초.md` 한 장을 `cafe-points` 폴더에 복사하고, Claude가 지식베이스의 관련 쪽을 고치게 해요. 남은 네 장은 수업 뒤에 같은 방법으로 넣어 볼 수 있어요.

## 놓는 곳

이 폴더를 통째로 내 카페 포인트 폴더(`~/legacy/cafe-points`) 안에 복사해요. 코드는 건드리지 않아요.

- Windows: 탐색기에서 `dbinc-ai-course\labs\legacy-easy\cafe-points-wiki` 폴더를 복사해서 `C:\Users\<내 이름>\legacy\cafe-points` 안에 붙여 넣어요.
- macOS: Finder에서 `dbinc-ai-course/labs/legacy-easy/cafe-points-wiki` 폴더를 복사해서 `~/legacy/cafe-points` 안에 붙여 넣어요. 끌어 놓을 때는 Option 키를 누른 채 놓아야 옮기지 않고 복사돼요.

다 되면 `cafe-points/cafe-points-wiki/` 아래에 이 README와 다섯 장이 보여요.
