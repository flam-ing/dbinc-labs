## 보낸 말

```text
CLAUDE.md, 코드, issues 폴더를 읽고 출처와 이유를 적은 쪽 다섯 개와 목차 README.md를 docs/kb/에 만들어 줘.
```

## 실제 답

`docs/kb/`에 쪽 다섯 개와 목차 `README.md`를 만들었어요. 파일을 쓴 뒤에 다시 열어 보거나 줄 번호를 대조하지는 않았어요. 코드는 건드리지 않았고 커밋도 하지 않았어요.

| 쪽 | 내용 |
| --- | --- |
| `01-마감-실행과-입출력.md` | 실행 방법, 입출력, 조용히 실패하는 저장 단계, 손대면 안 되는 코드 |
| `02-적립-규칙.md` | 적립률이 복제된 여섯 곳, CAFE-1, CAFE-5 |
| `03-등급과-VIP.md` | 문자열과 enum이 섞인 구조, CAFE-2, CAFE-4 |
| `04-생일-쿠폰.md` | 쿠폰 조건과 두 분기 구조, CAFE-3 |
| `05-키오스크와-관리자-비밀번호.md` | `web/` 화면, 파이썬과 중복되는 계산, 비밀번호 동기화 |

각 쪽 끝에 출처와 그렇게 정리한 이유를 적었어요. 목차에는 이슈 다섯 개를 한눈에 보는 표도 넣었어요.

코드와 이슈를 대조하다가 확인이 필요한 점을 찾았어요. 이 내용은 해당 쪽에도 적어 두었어요.
- **CAFE-2와 CAFE-4가 충돌해요.** 둘 다 2027-01-01에 적용되는데, VIP 기준을 CAFE-2는 20만 원으로, CAFE-4 표는 10만 원으로 적었어요. 사장님께 확인이 필요해요.
- **결제 금액이 음수가 될 수 있어 보여요.** 생일 쿠폰에 사용 포인트까지 겹치면 막는 코드를 못 찾았어요. 실행해 보지는 않았어요.
- **README와 코드가 달라요.** README는 "10만 원이 넘으면 VIP"라고 쓰지만 코드는 `>= 100000`(이상)이에요.
- **쿠폰 사용 기록이 저장되지 않아요.** 그래서 "달에 한 번" 제한은 한 번의 마감 안에서만 지켜져요.

`time.sleep(1)`을 지우지 말라는 이유는 어느 파일에도 없어서, 쪽에도 이유를 모른다고 적었어요.
