# 2일차 2교시에서 보내는 말

1교시와 같은 카페 포인트 폴더(`~/legacy/cafe-points`)를 Code 탭에서 **+ New session**으로 새로 열고 차례로 보내요. 모델은 Sonnet, 모드는 Accept edits예요. 세 문장은 같은 대화에서 보내요. 명령 카드가 뜨면 거절해요. Claude가 파일 도구로 다시 해요. 교안은 [지식베이스, LLM 위키, 옵시디언](../../../docs/day1-kb.md)이에요.

이 파일은 내 레거시 폴더에 복사하지 않아요. 따로 열어 두고 복사해서 써요.

## 실습 1: 지식베이스 만들기 (6분)

```text
CLAUDE.md, 코드, issues 폴더를 읽고 출처와 이유를 적은 쪽 다섯 개와 목차 README.md를 docs/kb/에 만들어 줘.
```

실제 답은 [23-kb.md](23-kb.md)예요. 2분 2초 걸렸고, 목차 `README.md`와 쪽 다섯 개가 생겼어요. 쪽마다 끝에 출처와 이유가 있어요. `time.sleep(1)`의 이유는 "어느 파일에도 없어서 모른다"고 적었어요.

일찍 끝나면 온톨로지 한 장을 만들어 봐요. 이 짧은 문장 그대로는 보내 보지 않았어요. 강사가 준비 때 보낸 긴 문장과 답은 [50-ontology.md](50-ontology.md)에 있어요.

```text
개체와 관계를 docs/kb/ontology.md에 표로 정리해 줘.
```

## 실습 2: 새 자료 넣기 (6분)

탐색기(맥은 Finder)에서 `labs/legacy-easy/cafe-points-wiki/메신저-2021-03-마감-1초.md`를 내 `cafe-points` 폴더에 복사해요. 그다음 실습 1과 같은 대화에서 보내요.

```text
<메신저-2021-03-마감-1초.md>를 kb에 반영하고 관련 쪽끼리 링크한 뒤 바뀐 내용을 docs/kb/log.md에 적어 줘.
```

`<꺾쇠>` 안은 넣을 파일 이름이에요. 꺾쇠는 빼고 보내요. 실제 답은 [24-wiki.md](24-wiki.md)예요. 41초 걸렸어요. 1초 쉬는 이유가 들어갔고, `log.md`에 바뀐 쪽 세 개가 적혔어요. CLAUDE.md와 어긋난다고도 알려 줬어요.

일찍 끝나면 그 어긋남을 고쳐 달라고 해요. 이 문장은 보내 보지 않았어요.

```text
CLAUDE.md의 sleep 설명도 kb에 맞게 고쳐 줘.
```

## 실습 3: 옵시디언으로 열기 (5분)

먼저 쪽끼리 링크를 이어요.

```text
docs/kb/의 쪽끼리 관련 있는 곳을 [[위키 링크]]로 이어 줘.
```

실제 답은 [25-links.md](25-links.md)예요. 54초 걸렸어요. 그다음 옵시디언에서 Open folder as vault로 `docs/kb` 폴더를 열고 그래프 보기를 켜요.

다 되면 커밋을 부탁해요. 옵시디언이 만든 `.obsidian` 폴더는 빼요.

```text
docs/kb/를 커밋해 줘. .obsidian 폴더는 빼 줘.
```

## kb에 묻기: kb가 있을 때와 없을 때의 답

실습 2를 마친 폴더에서 새 대화로 보내 봐요. 고치지 않고 묻기만 하니 모드는 Manual이에요. 강사가 준비 때 kb가 없는 폴더와 있는 폴더에 보낸 두 답은 [51-ask-before-after.md](51-ask-before-after.md)에 있어요.

```text
time.sleep(1)은 지워도 돼요? 왜 있는지 출처와 함께 알려 줘. 고치지는 마.
```

## 레거시 코드 고칠 때 kb 쓰기

수업 뒤에 코드를 고칠 때 써요. 앞의 두 문장은 보내 보지 않았어요. `<꺾쇠>` 안은 바꿀 규칙이에요.

```text
docs/kb를 보고 <적립률>을 바꿀 때 같이 고칠 곳을 알려 줘. 아직 고치지 마.
```

```text
바꾼 코드에 맞게 kb 쪽과 log.md도 고쳐 줘.
```

```text
CLAUDE.md에 "업무 규칙과 그 이유는 docs/kb/README.md부터 읽어." 한 줄을 더해 줘.
```

## 재미로 해 보기: 카톡 대화

수업이 끝나고 재미로 해 봐요. 카톡 단톡방 대화를 글 파일로 내보내서 같은 방법으로 지식베이스를 만들어 볼 수 있어요. 회사 대화나 개인 정보가 있는 대화는 쓰지 않아요. 연습용 가상 대화는 `labs/legacy-easy/kakao-sample/`에 있어요.

```text
<카톡_카페포인트팀.txt> 카톡 대화를 읽고 docs/kb-kakao/에 지식베이스를 만들어 줘.
```

`<꺾쇠>` 안은 복사한 파일 이름이에요. 꺾쇠는 빼고 보내요. 강사가 비슷한 문장을 보낸 답은 [21-kakao-kb.md](21-kakao-kb.md)와 [22-kakao-update.md](22-kakao-update.md)에 있어요. 이 문장 그대로는 보내 보지 않았어요.
