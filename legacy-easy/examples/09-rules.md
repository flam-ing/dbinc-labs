## 보낸 말

```text
CLAUDE.md에 '코드 규칙' 절을 새로 만들어서 아래 규칙을 넣어 줘. 다른 절은 그대로 둬.
- 파이썬 이름은 영어로 써요. 함수와 변수는 snake_case, 상수는 UPPER_SNAKE_CASE, 클래스는 CapWords예요(PEP 8, Google Python 스타일 가이드).
- 안 쓰는 코드는 남기지 않아요. 주석 처리한 옛 코드, 아무도 부르지 않는 함수, 디버그 print는 지워요. 옛 코드는 git 기록에 있어요.
- 비밀번호 같은 비밀값은 코드에 쓰지 않아요.
- 오류를 except: pass로 삼키지 않아요.
- 등급은 grades.py의 Grade enum으로만 다뤄요.
- 적립률, VIP 기준, 쿠폰 금액 같은 정책 숫자는 설정 한 곳에만 둬요.
- 화면 코드는 TypeScript(.tsx, .ts)로 통일하고, 컴포넌트 안에서 다른 컴포넌트를 만들지 않아요.
- 리팩터링은 동작을 바꾸지 않아요. 고치기 전과 뒤의 결과를 비교하고, 단계마다 커밋해요.
```

## 실제 답

`CLAUDE.md` 맨 끝에 `## 코드 규칙` 절을 새로 만들고, 말씀하신 규칙 8개를 그대로 넣었습니다. 기존 절은 건드리지 않았고, diff는 11줄 추가뿐입니다. 커밋은 하지 않았습니다.

코드 식별자(`except: pass`, `grades.py`, `Grade`, `.tsx`, `.ts`)에는 백틱을 붙였습니다.

기존 CLAUDE.md의 "구조와 주의점"에는 지금 코드가 이 규칙과 어긋나는 부분이 적혀 있습니다. 예를 들면 하드코딩된 비밀번호, `try/except: pass`, 문자열 등급 비교, 복제된 정책 숫자, 죽은 코드가 그렇습니다. 이 부분은 말씀하신 대로 손대지 않았습니다.

## 참고

규칙을 넣은 뒤의 CLAUDE.md 전체는 [claude-md-rules.md](claude-md-rules.md)에 있어요. Claude가 이 단계에서는 커밋하지 않았고, 다음 안전망 단계에서 CLAUDE.md 변경을 같이 커밋했어요.
