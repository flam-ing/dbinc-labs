# 카톡 대화 예시

카페 사장님, 점장, 알바가 나눈 카톡 대화 두 개예요. 수업 실습에서는 쓰지 않아요. 2일차 2교시가 끝나고 재미로 해 볼 때 써요.

> 모두 수업용으로 지어낸 대화예요. 가게, 사람, 날짜, 대화는 실제가 아니에요.

| 파일 | 무엇이 들어 있나 |
| --- | --- |
| `카톡_카페포인트팀.txt` | `time.sleep(1)`을 넣은 이유, VIP 기준과 적립률, 생일 쿠폰, 1,000점부터 쓰는 이유 |
| `카톡_카페포인트팀_새대화.txt` | 이틀 뒤 대화예요. 적립률과 VIP 기준을 바꾸기로 해요. 만든 지식베이스를 고쳐 볼 때 써요 |

## 해 보는 법

1. 파일 하나를 `~/legacy/cafe-points` 안에 복사해요.
2. Code 탭에서 아래 문장을 보내요. `<꺾쇠>` 안은 복사한 파일 이름이에요. 꺾쇠는 빼고 보내요. 수업에서 만든 `docs/kb/`와 섞이지 않게 `docs/kb-kakao/`에 만들어요.

```text
<카톡_카페포인트팀.txt> 카톡 대화를 읽고 docs/kb-kakao/에 지식베이스를 만들어 줘.
```

강사가 비슷한 문장을 보낸 답은 [`21-kakao-kb.md`](../examples/21-kakao-kb.md)와 [`22-kakao-update.md`](../examples/22-kakao-update.md)에 있어요.

## 내 단톡방 대화로 해 보기

내 단톡방 대화를 글 파일로 내보내서 같은 방법으로 해 볼 수 있어요.

- PC: 채팅방 메뉴에서 "대화 내용", "대화 내보내기"를 눌러요. 저장된 `.txt` 파일을 폴더에 넣어요.
- 휴대폰: 채팅방 설정에서 "대화 내용 내보내기", "텍스트만"을 골라요. 받은 파일을 PC로 옮겨요.

> **주의** 회사 대화나 개인 정보가 있는 대화는 쓰지 않아요. 보낸 내용은 모델 서버로 가요. 친구와 나눈 가벼운 대화처럼 남에게 보여도 괜찮은 것만 써요.
