# 하네스에 더할 우리 팀 규칙 고르기

2일차 4교시 "스킬과 내 규칙" 실습에서 쓰는 예시 목록이에요. 하나를 골라 그대로 쓰거나 우리 팀 말로 바꿔요. 수업에서는 스킬에 한 줄(부탁)까지 하고, 훅으로 강제하는 것은 부록 C의 선택 심화예요.

- **부탁(스킬)**: `.claude/skills/price-watch-rules/SKILL.md`의 "하지 않는 것" 끝에 13번으로 한 줄 더해요. Claude가 읽고 따르지만 놓칠 수도 있어요.
- **강제(훅)**: 꼭 막아야 하는 Bash 명령이면 `.claude/hooks/guard.py`의 `EXTRA_BLOCKS`에 한 줄 더해요. 그 글자가 든 명령은 실행 전에 막혀요(종료 코드 2).

## 예시 목록

| 13번 규칙(스킬에 쓰는 말) | 훅으로도 막을 때 `EXTRA_BLOCKS`에 넣을 줄 |
| --- | --- |
| 13. 운영 DB에는 연결하지 않아요. | `("psql ", "하네스: 운영 DB에는 연결하지 않아요. (price-watch-rules 13번)"),` |
| 13. 파일을 지울 때는 먼저 사람에게 물어요. | `("rm -rf", "하네스: 파일을 통째로 지우기 전에 사람에게 물어요. (price-watch-rules 13번)"),` |
| 13. pip로 새 패키지를 설치하지 않아요. 표준 라이브러리만 써요. | `("pip install", "하네스: 새 패키지는 설치하지 않아요. 표준 라이브러리만 써요. (price-watch-rules 13번)"),` |
| 13. 브랜치를 강제로 덮어쓰지 않아요. | `("--force", "하네스: 강제로 덮어쓰지 않아요. (price-watch-rules 13번)"),` |
| 13. 회사 메신저나 메일로 결과를 보내지 않아요. 보내는 일은 사람이 해요. | 훅 없이 부탁으로 둬요. 보내는 방법이 여러 가지라서 글자 하나로 막기 어려워요 |

12번(git push 하지 않기)은 이미 예시 줄이 들어 있어요. 맨 앞의 `#` 하나만 지우면 강제로 바뀌어요.

```python
EXTRA_BLOCKS = [
    ("git push", "하네스: git push는 사람이 확인하고 직접 해요. (price-watch-rules 12번)"),
]
```

## 시험하기

Terminal 창에서 막고 싶은 명령을 훅에 넣어 봐요. `<git push origin main>`을 내가 막은 명령으로 바꿔요.

```bash
echo '{"tool_name":"Bash","tool_input":{"command":"<git push origin main>"},"cwd":"."}' | python3 .claude/hooks/guard.py; echo $?
```

이유와 함께 `2`가 나오면 강제가 됐어요. `0`이 나오면 줄 앞의 `#`이 남아 있거나 찾을 글자가 명령에 없어요. `SyntaxError`가 나오면 괄호, 따옴표, 끝의 쉼표가 예시 줄과 같은지 봐요.

실제로 해 본 결과(2026-10-17)예요.

```text
하네스: git push는 사람이 확인하고 직접 해요. (price-watch-rules 12번)
2
```

## 주의

훅은 명령 글자에 그 말이 들어 있는지만 봐요. `"psql "`처럼 짧은 글자는 다른 명령도 막을 수 있고, 다르게 쓴 명령은 지나갈 수 있어요. 그래서 훅은 "실수를 한 번 더 막는 장치"이고, 끝난 뒤에는 바뀐 내용을 사람이 한 번 더 봐요.
