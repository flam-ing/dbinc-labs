# 가격 추적 위키

연습몰(교육용 가상 쇼핑몰) 가격 추적에서 알게 된 것을 모으는 곳이에요. 사람과 Claude가 같이 읽고 써요.
Claude는 일을 시작할 때 이 파일을 먼저 읽어요. 그래서 처음부터 코드를 다 뒤지지 않아도 돼요.

## 파일

| 파일 | 내용 | 누가 쓰나요 |
| --- | --- | --- |
| `../prices.csv` | 날마다 모은 판매가와 정가 | collect.py만 덧붙여요 |
| `../news.jsonl` | 모은 소식 | collect.py만 덧붙여요 |
| `../runs.jsonl` | 수집할 때마다 남는 실행 기록(성공, 실패, 요청 수) | collect.py만 덧붙여요 |
| `products/<상품코드>.md` | 상품별 페이지. 숫자는 스크립트가, 메모는 사람과 Claude가 써요 | curate.py, curator |
| `selector-changes.md` | 페이지 구조가 바뀐 날과 고친 방법 | collector |
| `incidents.md` | 장애와 대응, 데이터 문제 | collector, curator |
| `quality.md` | 데이터 점검 결과 | curate.py가 통째로 다시 써요 |

## 코드로 알 수 있는 지식과 코드에 없는 지식

코드를 읽으면 알 수 있는 것은 위키에 길게 옮기지 않고 어디를 보면 되는지만 적어요.
코드에 없는 것은 사람이 잊어버리기 전에 위키에 꼭 적어요.

| 코드로 알 수 있는 지식 | 코드에 없는 지식 |
| --- | --- |
| collect.py가 어떤 파서를 어떤 순서로 쓰는지(`PARSERS`) | 왜 그 순서인지, 각 파서가 어느 날 구조부터 쓰였는지 |
| prices.csv의 열 이름과 저장 형식(`PRICE_FIELDS`) | 어느 날 가격이 크게 바뀐 것이 오류가 아니라 행사였다는 것 |
| 요청 간격 1초(`DELAY_SECONDS`) | 왜 1초인지: 연습몰 robots.txt의 Crawl-delay와 이용약관 3항 |
| 429를 받으면 Retry-After만큼 기다리는 코드 | 어느 주소에서 언제 429가 나왔고, 기다리면 풀렸는지 |
| 테스트가 확인하는 것(tests/) | 행사 상품은 정가와 판매가가 둘 다 나와서 첫 숫자를 읽으면 틀린다는 경험 |

## 고치는 흐름

1. 매일 수집이 끝나면 `python3 tools/curate.py`가 상품 페이지의 숫자와 quality.md를 다시 써요.
2. 구조가 바뀌어 파서를 고치면 selector-changes.md에 한 항목을 더해요.
3. 가격이 크게 바뀐 날은 상품 페이지 메모에 관련 소식 id와 함께 적어요. 관계는 추정이라고 밝혀요.
4. 코드를 바꿨는데 위키 설명과 달라졌으면, 바뀐 부분만 위키에서 고쳐요.
