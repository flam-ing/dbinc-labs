# 하루치 가격 추적

price-watch-rules 스킬의 규칙을 먼저 따라요.

1. `python3 collect.py`를 실행해요.
   - 종료 코드 0이면 2단계로 가요.
   - 종료 코드 2(구조 변경 의심)면 collector 서브에이전트에게 맡겨요. 출력 전체와 스냅숏 경로를 같이 넘겨요.
   - 그 밖의 실패(연결 실패, 429가 계속됨)면 고치지 말고 출력 그대로 보고하고 멈춰요.
2. `python3 tools/curate.py`를 실행해요.
3. `python3 tools/report.py`를 실행해요.
4. 다섯 줄 안으로 보고해요: 날짜, 저장한 행 수, 실패와 대응, 리포트 경로, 확인하지 않은 것. 숫자는 위 명령의 출력에서만 가져와요.

수집이 성공한 평범한 날에는 서브에이전트를 부르지 않고 짧게 끝내요. 그래야 매일 쓰는 토큰이 적어요.
