# 가격 추적 작업 규칙

이 규칙은 "어떻게 하라"보다 "무엇을 하지 않는지"를 적어요. 어기게 될 것 같으면 멈추고 사람에게 물어요.

## 하지 않는 것

1. 연습몰(http://127.0.0.1:8766) 말고 다른 주소에는 요청하지 않아요. 실제 쇼핑몰, 검색 엔진, 다른 사이트를 열지 않아요.
2. 요청 사이 간격을 1초보다 짧게 하지 않고, 여러 요청을 동시에 보내지 않아요. 원인을 찾을 때는 저장된 스냅숏(.runtime/snapshots/)부터 읽어요.
3. /admin 주소를 직접 부르지 않아요. 연습몰 날짜는 사람이 시킬 때만 python3 tools/sim_day.py나 python3 tools/run_days.py로 바꿔요.
4. kb/prices.csv, kb/news.jsonl, kb/runs.jsonl을 손으로 고치지 않아요. 잘못 들어간 행은 kb/wiki/incidents.md에 적고 사람에게 알려요.
5. 이미 있는 테스트를 고치거나 지우지 않아요. 새 구조는 새 테스트 파일로 더해요.
6. 예전 파서를 지우지 않아요. 새 파서를 PARSERS 맨 앞에 더해요.
7. 파서를 고쳤으면 kb/wiki/selector-changes.md에 기록하기 전에는 끝났다고 하지 않아요.
8. 리포트, 요약, 위키에 쓰는 숫자는 스크립트 출력이나 kb/ 파일에서만 가져와요. 짐작하거나 머리로 계산한 숫자를 쓰지 않아요.
9. 예측을 단정하지 않아요. 방법(7일 평균, 14일 추세선)과 되돌아보기 오차율을 같이 적어요.
10. 소식과 가격이 같이 움직였다고 원인이라고 쓰지 않아요. "관계는 추정이에요"라고 적어요.
11. 로그인이 필요한 페이지와 개인정보는 다루지 않아요.
12. git push를 하지 않아요. 커밋은 사람이 하라고 할 때만 해요.

## 같은 실패가 되풀이되면

같은 오류로 두 번 고쳐도 실패하면 더 고치지 말고, 지금까지 본 것(스냅숏 경로, 오류 메시지, 시도한 것)을 정리해서 사람에게 넘겨요.
