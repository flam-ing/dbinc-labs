# 고른 스타일 적용하기 · 실제 답

강사 PC에서 2026-10-21에 Claude Code 2.1.304, 모델 Sonnet 5.5로 실제로 보낸 결과입니다. 앞 단계와 같은 세션에 이어서 보냈습니다. 걸린 시간은 43초이고, 만든 파일은 `results/` 아래에 그대로 있습니다(`report/index.html`(CSS만 바뀜)).

## 보낸 말

```text
골라 준 Y2K 스타일을 report/index.html에 적용해 줘. 글, 숫자, 표, 그래프 값은 그대로 두고 색, 글꼴, 카드와 버튼 모양 같은 겉모습만 바꿔. 글자가 배경과 잘 구분되게 하고, 휴대폰 폭에서도 깨지지 않게 해 줘. 바꾼 점을 짧게 정리해 줘.
```

## Claude의 마지막 답(원문 그대로)

`report/index.html`에 Y2K 겉모습을 적용했습니다. 고친 곳은 `<style>` 안의 CSS뿐입니다. `</style>` 아래의 본문과 스크립트는 원본과 한 줄도 다르지 않다는 것을 비교해서 확인했습니다. 글, 숫자, 표, 그래프 값은 그대로입니다.

**바꾼 점**
- **색**: 바탕은 연한 라일락에 분홍·하늘 빛 번짐을 넣었습니다. 글자는 짙은 보라 잉크색, 막대는 보라, 포인트는 분홍과 하늘색입니다.
- **글꼴**: Trebuchet MS와 Verdana를 먼저 쓰고, 한글은 기존 시스템 글꼴로 이어집니다. 외부 글꼴은 불러오지 않습니다.
- **제목**: h1에 분홍 그림자를 넣었습니다. 각 구역 제목(h2)은 은빛 분홍·보라·하늘 그라데이션 알약 모양입니다.
- **카드와 상자**: 요약 카드, 그래프 상자, 듣고 보기 상자는 둥근 모서리(22px)에 흰 테두리와 반짝이는 윗면 광택을 넣었습니다. 표지 그림, 영상, 체크 그림 테두리도 맞췄습니다.
- **버튼**: "표로 보기"를 광택 있는 분홍 알약 버튼으로 바꾸고, 키보드로 선택하면 하늘색 테두리가 보이게 했습니다.
- **표**: 머리글에 연한 분홍·보라 그라데이션을 넣고 짝수 줄을 살짝 다른 색으로 했습니다. 상태 배지는 색 그대로 굵게, 테두리만 추가했습니다.
- **그래프**: 막대 색은 보라로, 테두리는 분홍으로 바꿨습니다. 크기, 위치, 값은 그대로입니다.
- **꼬리말**: 구분선은 분홍 점선입니다.

**글자와 배경 구분**
- 계산한 명암비는 다음과 같습니다. 일반 글자 기준 4.5 이상이 필요합니다.

| 글자 | 배경 | 명암비 |
|---|---|---|
| 본문 | 바탕 | 14.4 |
| 보조 글자 | 바탕 | 8.3 |
| 흐린 글자 | 카드 | 6.9 |
| 카드 숫자 | 카드 | 6.0 |
| 버튼 글자 | 분홍 | 9.1 |
| 정상 배지 | 배경 | 6.0 |

- 모두 기준을 넘었습니다. 장식은 모두 배경 쪽에 두었고 글자 위에는 겹치지 않습니다.

**휴대폰 폭**
- 레이아웃, 간격, 720px 이하 규칙은 건드리지 않았습니다.
- 표는 좁으면 옆으로 스크롤됩니다. 목록은 긴 글이 줄바꿈됩니다.
- 브라우저로 실제 화면을 띄워 확인하지는 못했습니다. 기존 구조를 유지하고 CSS 값만 바꿔서 깨질 가능성은 낮다고 보지만, 실제 폰에서 한 번 열어 보시길 권합니다.
