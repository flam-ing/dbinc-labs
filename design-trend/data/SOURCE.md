# 데이터 출처

| 파일 | 내용 | 진짜인가 |
| --- | --- | --- |
| `our_designs.csv` | 가상의 우리 회사가 2024-01 ~ 2026-09에 낸 배너·랜딩·앱 푸시·SNS 카드 시안 131건. 시안 번호, 달, 채널, 스타일, 주 색, 글꼴, 노출 수, 클릭 수 | **수업용으로 지어낸 데이터입니다.** 실제 회사 자료가 아닙니다 |
| `trends_wikipedia_monthly.csv` | 디자인 용어 13개의 영어 위키백과 문서 월별 조회수(사람이 본 것만, 2021-01 ~ 2026-09) | 실제 데이터입니다. Wikimedia REST API `https://wikimedia.org/api/rest_v1/metrics/pageviews/per-article/en.wikipedia/all-access/user/<문서>/monthly/2021010100/2026093000` |

- 위키백과 조회수는 강사가 2026-10-21 01:05(한국 시각)에 받았습니다. 키는 없고, 요청에 연락처가 든 User-Agent 머리글을 붙이라고 합니다.
- 문서가 늦게 만들어졌거나 이름이 바뀐 용어는 앞쪽 달이 없거나 갑자기 튑니다. 예를 들어 `Liquid Glass`는 2025-06부터, `Y2K aesthetic`은 2024-09부터 있습니다.
- 조회수는 사람들이 그 말을 얼마나 찾아봤는지를 보여 줄 뿐입니다. 실제로 그 스타일을 얼마나 쓰는지, 좋아하는지를 재는 값은 아닙니다.
- 지어낸 데이터의 스타일 이름: `flat`(플랫), `material`(머티리얼), `neumorph`(뉴모피즘), `pixel-retro`(픽셀 레트로), `swiss`(스위스 스타일), `y2k`(Y2K), `glass`(유리 질감), `skeuo`(스큐어모피즘, 실물 질감).
