# 모델과 하네스 실습 자료

2일차 번외(11:30–12:00, 13:00–13:30, 60분)의 실습 세 개에 쓰는 자료예요. 진행은 [번외) 모델·하네스·에이전트 진행안](../../docs/bonus-harness-runbook.md)을 따라요.

| 폴더·파일 | 무엇 | 실습 |
| --- | --- | --- |
| `compare/changes.md` | 오늘 배포할 변경 내역 다섯 건이에요. 교육용 가상 자료예요. 서로 부딪히는 변경이 두 군데 숨어 있어요 | 실습 1 같은 질문 두 모델에 보내기(6분) |
| `~/legacy/cafe-points` (없으면 `../rules`) | 오전 3교시에 쓴 폴더예요. 이 폴더에 있는 하네스 부품을 찾아요 | 실습 2 내 폴더의 하네스 부품 찾기(6분) |
| `compare/` (같은 폴더) | 바깥 하네스 OMP의 README를 Claude에게 읽혀요. 폴더 안의 파일은 쓰지 않아요 | 실습 3 다른 하네스 README 읽기(6분) |
| `examples/` | 보낼 문장과 실제 결과 견본 | 실습 1~3 |

`compare/`는 받은 폴더에서 바로 열어도 돼요. 세 실습 모두 파일을 고치지 않아요. 실습 3은 github.com을 읽어야 해요. 회사망에서 막히면 강사 화면으로 같이 봐요.

보낼 문장은 [examples/prompts.md](examples/prompts.md)에 있어요.

`design/agent-design.md`와 `examples/agent-design-example.md`, `made-by-claude/04`·`05`는 예전 판의 "내 업무 에이전트 설계서" 실습 자료예요. 지금 수업에서는 쓰지 않지만 지우지 않고 남겨 두었어요.
