# 모델, 하네스, 에이전트 실습 자료

2일차 번외(11:30–12:00, 13:00–13:30, 60분)의 실습 네 개에 쓰는 자료예요. 진행은 [번외) 모델·하네스·에이전트 진행안](../../docs/bonus-harness-runbook.md)을 따라요.

| 폴더·파일 | 무엇 | 실습 |
| --- | --- | --- |
| `compare/changes.md` | 오늘 배포할 변경 내역 다섯 건이에요. 교육용 가상 자료예요. 서로 부딪히는 변경이 두 군데 숨어 있어요 | 실습 1 같은 질문 두 모델에 보내기(6분) |
| `~/legacy/cafe-points` (없으면 `../rules`) | 오전 3교시에 쓴 폴더예요. 이 폴더에 있는 하네스 부품을 찾아요 | 실습 2 내 폴더의 하네스 부품 찾기(6분) |
| `design/agent-design.md` | 업무 에이전트 설계서 빈 양식이에요. 입력, 도구, 판단, 완료, 운영 다섯 칸이에요 | 실습 3 내 업무 에이전트 한 장 쓰기(8분), 실습 4 질문에 답해 설계서 고치기(4분) |
| `examples/` | 보낼 문장, 채운 예시, 실제 결과 견본 | 실습 1~4 |

`compare/`와 `design/`은 받은 폴더에서 바로 열어도 돼요. 실습 1과 2는 파일을 고치지 않아요. 실습 3에서는 `my-agent.md` 하나만 새로 생기고, 실습 4에서 그 파일을 고쳐요. 다시 하려면 `my-agent.md`를 지우거나 이름을 바꿔요.

보낼 문장은 [examples/prompts.md](examples/prompts.md)에 있어요.
