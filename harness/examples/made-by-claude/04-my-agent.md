# 내 업무 에이전트 설계서

한 장으로 써요. 칸마다 한두 줄이면 충분해요. 모르는 칸은 지어내지 말고 "확인 필요"라고 적어요.

## 0. 맡길 일

- 일 이름: 지난주 고객 문의 메일을 종류별로 세고, 급한 것 세 건을 골라 팀장에게 보고
- 지금은 누가, 얼마나 자주, 몇 분 걸려요: 내가, 매주 월요일 아침에, 걸리는 시간은 확인 필요

## 1. 입력 · 무엇을 받아서 시작해요?

- 받는 것: 지난주에 들어온 고객 문의 메일
- 어디에 있어요: 확인 필요 (메일 서비스·받은편지함/폴더·공유 메일함 여부)

## 2. 도구 · 무엇을 읽고, 무엇을 써요?

- 읽기: 지난주 고객 문의 메일 (읽는 방법은 확인 필요)
- 쓰기: 팀장에게 보내는 보고 (형식·전달 수단은 확인 필요)
- 하면 안 되는 것: 확인 필요

## 3. 판단 · 모델이 정해야 하는 곳은 어디예요?

- 모델이 정할 것: 문의 종류 분류(종류 목록은 확인 필요), 급한 세 건 고르기(급하다의 기준은 확인 필요)
- 코드로 정할 것(합계, 정렬처럼 답이 하나인 일): 종류별 건수 합계, "지난주" 날짜 범위로 메일 걸러내기

## 4. 완료 · 무엇을 보면 끝났다고 해요?

- 결과물: 종류별 건수 + 급한 세 건을 담아 팀장에게 전달한 보고 (분량·양식은 확인 필요)
- 확인 방법: 확인 필요
- 사람이 승인할 곳: 확인 필요 (팀장에게 보내기 전에 내가 검토하는지)

## 5. 운영 · 누가, 어디서, 언제 돌려요?

- 언제(트리거): 매주 월요일 아침 (정확한 시각은 확인 필요)
- 어디서(내 PC, 회사 서버, 클라우드): 확인 필요
- 실패하면: 확인 필요

## 나에게 물어볼 질문

1. 고객 문의 메일은 어디에 모여 있어요? (어떤 메일 서비스, 어느 폴더나 공유 메일함인지, 에이전트가 읽어도 되는지)
2. "종류"는 어떤 것들이 있고, "급하다"는 무엇을 보고 정해요? (예: 종류 목록, 급한 것을 고르는 기준이나 지난번에 급하다고 본 사례)
3. 팀장에게는 어떤 방식으로 보고하고, 보내기 전에 내가 먼저 확인해야 해요? (메일·메신저·문서 중 무엇인지, 승인 필요 여부)
