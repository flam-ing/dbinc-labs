# 하네스 스튜디오 · 네 판의 결과

실습 3 "켜고 끄며 보기"의 끝났을 때 모습이에요. 2026-10-17에 `demos/harness-studio/`를 브라우저로 열고 스위치만 바꿔 **예시 실행**을 네 번 누른 결과를 그대로 옮겼어요. 작업 공간은 "서비스 운영팀", 요청 칸은 처음 글 그대로예요.

이 페이지는 정해진 규칙으로 보고서 모양을 바꾸는 **구조 시연**이에요. 실제 모델이 쓴 글이 아니라서 몇 번을 눌러도 같은 결과가 나와요. 모델 이름(Claude, GPT, Grok)을 바꿔도 결과는 같아요.

| 1 | 끔 | 끔 | 끔 | 번호 목록과 제목만 있어요 |
