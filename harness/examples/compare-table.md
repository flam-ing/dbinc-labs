# 같은 요청, 두 모델 · 비교표

실습 1에서 써요. 같은 폴더(`labs/harness/compare`)에서 새 세션을 두 번 열고, 모델이나 effort만 바꿔서 같은 문장을 보내요. 답이 나오면 아래 빈 표를 채워요.

## 빈 표

| 칸 | 답 A | 답 B |
| --- | --- | --- |
| 모델 · effort | | |
| 걸린 시간(초) | | |
| 숨은 위험(2개 중 몇 개) | | |
| 줄마다 변경 ID가 있나 | | |
| 말투(해요체, 합니다체) | | |
| 내가 쓸 답(이유 한 줄) | | |

- 걸린 시간은 보낸 순간부터 답이 다 나올 때까지 휴대폰 초시계로 재요. 앱에는 시간이 따로 나오지 않아요.
- 숨은 위험은 답을 다 받은 뒤에 [정답 확인](#숨은-위험-정답-확인)을 열어서 세어요. 미리 보면 비교가 안 돼요.
- 짝에게 두 답을 모델 이름을 가리고 보여 주고, 더 나은 쪽을 고르게 해 봐요. Arena가 표를 모으는 방법과 같아요.

## 실제로 돌려 본 예

2026-10-17에 강사 PC에서 `claude -p`로 한 번씩 돌린 결과예요. 원문은 [made-by-claude/01-sonnet.md](made-by-claude/01-sonnet.md)와 [made-by-claude/02-opus.md](made-by-claude/02-opus.md)에 있어요.

| 칸 | 답 A | 답 B |
| --- | --- | --- |
| 모델 · effort | Sonnet 5.5 · High | Opus 5.5 · High |
| 걸린 시간(초) | 10.5 | 12.8 |
| 숨은 위험(2개 중 몇 개) | 2 | 2 |
| 줄마다 변경 ID가 있나 | 있음(다섯 줄 모두) | 있음(다섯 줄 모두) |
| 말투(해요체, 합니다체) | 합니다체 | 해요체 |
| API 값으로 환산한 금액 | $0.043 | $0.082 |
| 내가 쓸 답(이유 한 줄) | 둘 다 위험을 찾았으니, 자주 돌릴 일이면 값이 절반인 A | 요청 키를 서버 여러 대가 함께 보는지까지 짚어서, 한 번 깊게 볼 일이면 B |

이번 요청에서는 두 모델 모두 숨은 위험 둘을 찾았어요. 차이는 말투, 덧붙인 확인 항목, 그리고 값이었어요. 한 번 돌린 결과라서 다시 돌리면 달라질 수 있어요. 구독 요금제 안에서 쓰면 이 금액을 따로 내지는 않지만, 사용량은 그만큼 더 빨리 차요.

## 숨은 위험 정답 확인

답을 다 받은 뒤에 열어요.

1. **결제완료 필터가 0건이 돼요.** UI-104는 `"PAID"`(대문자)와 비교하는데, API-212가 응답을 `"paid"`(소문자)로 바꿨어요. 근거 ID는 UI-104와 API-212예요.
2. **야간 매출 리포트가 0원이 될 수 있어요.** BATCH-07은 `status = 'PAID'`인 주문만 더하는데, API-212로 상태 값이 소문자가 되면(저장 값까지 바뀌면) 맞는 주문이 없어요. 근거 ID는 BATCH-07과 API-212예요.

나머지(큰 테이블 인덱스 생성, 409 응답 처리, 리포트 시각 변경)도 배포 전에 볼 만한 항목이에요. 다만 변경 하나만 읽어도 보이는 항목이라 "숨은 위험"으로 세지 않아요.
