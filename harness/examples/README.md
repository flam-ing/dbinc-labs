# 번외 예시 · 모델과 하네스

번외 실습 세 개의 예시 문장과 실제로 돌려 본 결과 견본이에요. 발표의 "실제 결과" 장면과 강사 메모는 이 폴더의 파일에서 가져왔어요. Claude가 한 말과 쓴 파일은 고치지 않았어요.

| 파일 | 무엇 | 실습 |
| --- | --- | --- |
| [prompts.md](prompts.md) | 실습에서 보낼 문장과 실제 결과 요약 | 1~3 |
| [made-by-claude/01-sonnet.md](made-by-claude/01-sonnet.md), [02-opus.md](made-by-claude/02-opus.md) | 같은 질문을 Sonnet 5.5와 Opus 5.5에 보낸 두 답 | 1 |
| [compare-table.md](compare-table.md) | 두 답을 비교하는 표와 숨은 위험 정답이에요 | 1을 더 자세히 볼 때 |
| [harness-parts.md](harness-parts.md), [made-by-claude/03-parts.md](made-by-claude/03-parts.md) | 내 폴더의 하네스 부품 지도와 실제로 찾은 예 | 2 |

`made-by-claude/` 01~03은 2026-10-17에 Claude Code 2.1.301로, 06은 2026-10-23에 Claude Code 2.1.309로 `claude -p` 한 번 실행으로 돌린 결과예요. 수업의 Code 탭에서는 승인 카드가 뜨거나 답이 조금 다를 수 있어요. 걸린 시간과 금액은 그때 한 번의 기록이에요.

지금 수업에서 쓰지 않는 파일도 남겨 두었어요. [agent-design-example.md](agent-design-example.md), [made-by-claude/04-my-agent.md](made-by-claude/04-my-agent.md), [made-by-claude/05-my-agent-answered.md](made-by-claude/05-my-agent-answered.md)는 예전 판의 설계서 실습 기록이고, `studio-results.md`는 하네스 스튜디오 시연의 기록이에요.
