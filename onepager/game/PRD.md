# 토끼 당근 피하기 PRD

이 PRD는 [MEMO.md](MEMO.md)의 메모를 정리한 예시예요. 수업에서는 Claude Code가 질문하고 내가 답하면서 이런 문서를 만들어요. 이 PRD대로 다듬은 결과물이 [완성 샘플](index.html)이에요.

PRD(Product Requirements Document, 제품 요구사항 문서)는 "무엇을 만들지"를 적은 문서예요. "어떻게 만들지"는 Claude가 계획으로 제안하고, 나는 그 계획을 읽고 승인해요.

## 1. 만들 것

- 2절에서 프롬프트 한 번으로 만든 토끼 당근 피하기 게임을 친구에게 주소로 보낼 수 있게 다듬어요. 지금 있는 `index.html`을 고쳐요.
- 하는 사람은 나와 친구들이에요. 컴퓨터와 휴대폰에서 해요.
- 파일은 `index.html` 한 장과 `media/` 폴더예요. CSS와 JS는 `index.html` 안에 넣어요. 빌드 도구와 npm 패키지는 쓰지 않아요.
- 내 PC에서는 `python3 -m http.server 8080 --bind 127.0.0.1`로 서버를 켜고 http://127.0.0.1:8080/ 에서 열어요.

## 2. 화면

1. 머리줄: 게임 이름, 남은 목숨 5칸, 점수(예: 140 / 300점), 음악 끄기·켜기 버튼
2. 시작 화면: 포스터 그림이 게임 칸을 가득 채우고, 아래에 게임 이름, 조작 안내 한 줄, 시작 버튼
3. 게임 칸: 하늘과 언덕 배경, 화면 맨 아래의 토끼, 위에서 떨어지는 당근
4. 게임 오버 화면: "게임 오버", 이번 점수, 다시 하기 버튼
5. 클리어 화면: "축하해요! 클리어", 엔딩 영상, 다시 하기 버튼
6. 게임 칸 아래: 왼쪽·오른쪽 버튼 두 개
7. 맨 아래: 미디어 상태 줄

폭 390px 휴대폰 화면에서도 페이지 전체에 가로 스크롤이 생기지 않고, 아래 버튼 두 개가 화면 안에 보여요.

## 3. 데이터(게임 규칙)

규칙은 `<script>` 맨 위의 `RULES` 객체 하나에 모아요. 화면의 숫자는 모두 이 객체에서 읽어요.

| 규칙 | 값 |
| --- | --- |
| 점수 | 1초에 20점 |
| 클리어 | 300점 |
| 목숨 | 5개 |
| 부딪힌 뒤 무적 | 1.5초, 그동안 토끼가 깜빡여요 |
| 당근 | 0.9초마다 하나, 피하기 쉽게 천천히 떨어져요. 부딪힘 판정은 그림보다 작게 잡아요 |
| 조작 | 키보드 ←→, 아래 버튼을 누르고 있기, 게임 칸에서 손가락이나 마우스로 끌기 |

## 4. 미디어 파일 계약

코드는 아래 세 경로만 찾아요. 생성 도구가 붙인 파일 이름이 무엇이든, 저장할 때 이 이름으로 바꿔 넣어요.

| 파일 | 쓰는 곳 | 권장 | 없을 때 |
| --- | --- | --- | --- |
| `media/poster.png` | 시작 화면 포스터 | 16:9 가로 그림, 글자 없이 | 포스터 없이 게임 이름과 시작 버튼만 보여요 |
| `media/music.mp3` | 배경 음악 | 15초 안팎, 처음과 끝이 이어지는 반복용 | 음악 버튼에 "음악 없음"이 보이고 조용히 진행해요 |
| `media/ending.mp4` | 클리어 영상 | 5초 안팎, 1280×720 이하, H.264 | 클리어 글자와 다시 하기 버튼만 보여요 |

- 경로는 `<script>` 맨 위의 상수 `MEDIA`에만 둬요.
- 파일이 없거나 재생이 막혀도 게임은 멈추지 않아요. 콘솔에 잡히지 않은 예외(Uncaught 오류)를 남기지 않아요.
- 음악은 시작 버튼을 누른 뒤에 나와요(브라우저 자동재생 정책). 반복 재생하고, 끄기 버튼으로 멈춰요.
- 파일 이름은 소문자, 숫자, `-`만 써요. 경로는 `/`로 시작하지 않는 상대 경로로 써요.
- 맨 아래 상태 줄은 파일마다 있는지 보여 줘요. 세 파일이 다 있으면 "포스터 있음 · 음악 있음 · 영상 있음"이에요. 이 줄의 id는 `media-status`예요.

## 5. 하지 않을 것

- 외부 리소스를 불러오지 않아요. 인터넷 이미지, 웹 폰트, 라이브러리, 분석 스크립트를 쓰지 않아요.
- 이모지를 쓰지 않아요. 토끼와 당근은 캔버스 도형으로 그려요.
- 효과음, 순위표, 로그인, 서버 저장은 만들지 않아요.

## 6. 완료 기준

- [ ] 8080 서버로 열면 시작 화면에 포스터가 보이고, 시작 버튼을 누르면 음악이 나와요.
- [ ] 키보드 ←→로 토끼가 움직이고, 15초쯤 버티면 300점이 되어 클리어 화면에서 엔딩 영상이 나와요.
- [ ] 당근에 부딪히면 목숨이 한 칸 줄고 토끼가 1.5초 동안 깜빡여요. 다섯 번 부딪히면 게임 오버 화면이 나와요.
- [ ] 맨 아래 상태 줄이 "포스터 있음 · 음악 있음 · 영상 있음"이고, DevTools Console에 빨간 Uncaught 줄이 없어요.
- [ ] `media/` 폴더 이름을 잠시 바꿔도 게임이 끝까지 되고, 상태 줄이 "없음"으로 바뀌어요.
- [ ] DevTools 기기 모드로 폭 390px에서 봐도 가로 스크롤이 없고 아래 버튼 두 개가 보여요.
- [ ] 검사 스크립트 `check.py`가 오류 0개로 끝나요.
