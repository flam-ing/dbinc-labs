# 게임 갈래 아이디어 메모 예시

PRD를 만들기 전에 쓰는 메모 예시예요. 수업에서는 쓰지 않아요. 프롬프트 한 번으로 받은 토끼 게임(`index.html`)을 친구에게 보여 줄 수 있게 키우고 싶다는 메모예요. 문장이 거칠고 빠진 것이 있어도 괜찮아요. 빠진 것은 Claude Code가 질문해서 채워 줘요. 이 메모를 정리한 결과가 [PRD.md](PRD.md)예요.

## 메모

```text
index.html은 2절에서 프롬프트 한 번으로 만든 토끼 당근 피하기 게임이에요.
이 게임을 친구들에게 주소로 보내서 같이 해 보고 싶어요.
시작 화면에 포스터 그림이 크게 나오고, 시작 버튼을 누르면 배경 음악이 나오면 좋겠어요.
300점을 모으면 축하 영상이 나오고, 다시 하기 버튼이 있으면 좋겠어요.
음악을 끄는 버튼도 있으면 좋겠어요.
휴대폰에서도 버튼이나 손가락으로 할 수 있어야 해요.
그림, 음악, 영상 파일 이름은 media/poster.png, media/music.mp3, media/ending.mp4예요.
```

## 이 메모에 빠진 것

메모만 주고 "고쳐 줘"라고 하면 Claude가 아래 내용을 짐작으로 채워요. 짐작이 내 생각과 다르면 다시 고쳐야 해요. 그래서 고치기 전에 Claude에게 질문을 받아 PRD로 정리해요.

| 빠진 것 | 질문 예 | 이 PRD에서 정한 답 |
| --- | --- | --- |
| 규칙 | 점수, 목숨, 속도는 지금 게임 그대로인가요? | 1초에 20점, 300점이면 클리어, 목숨 5개, 부딪히면 1.5초 무적 |
| 화면 | 시작, 게임 오버, 클리어 화면에는 무엇이 보이나요? | 시작은 포스터와 시작 버튼, 게임 오버는 점수와 다시 하기, 클리어는 영상과 다시 하기 |
| 미디어 | 파일이 없으면 어떻게 하나요? 음악은 언제 나오나요? | 없으면 그 기능만 건너뛰기, 음악은 시작 버튼을 누른 뒤부터 |
| 조작 | 휴대폰에서는 어떻게 움직이나요? | 화면 아래 왼쪽·오른쪽 버튼과 손가락 끌기 |
| 하지 않을 것 | 효과음, 순위표, 로그인도 넣을까요? | 넣지 않아요 |
| 완료 기준 | 다 됐는지 무엇으로 확인하나요? | 300점 클리어, 상태 줄, 콘솔, 폭 390px, 검사 스크립트 |

## Claude에게 줄 요청

작업 폴더에 2절의 게임을 `index.html`로, 이 메모를 `MEMO.md`로 넣고, Claude Code를 Manual 모드(`claude --permission-mode default`)로 켠 다음 아래처럼 요청해요. 보고서 갈래와 같은 요청이에요. 메모 첫 줄에 이미 있는 게임이라고 적혀 있어서 Claude가 그 게임을 키우는 PRD를 써요.

```text
MEMO.md는 내가 만들고 싶은 HTML 한 장에 대한 메모야.
AskUserQuestion 도구로 나에게 질문해서 빠진 것을 채우고, PRD.md를 써줘.
PRD.md에는 만들 것, 화면, 데이터, 미디어 파일 계약, 하지 않을 것, 완료 기준을 넣어줘.
완료 기준은 내가 직접 확인할 수 있는 문장으로 써줘. 코드는 아직 만들지 마.
```
