# 샘플 운영팀 주간 보고서 PRD

이 PRD는 [MEMO.md](MEMO.md)의 메모를 정리한 예시예요. 수업에서는 Claude Code가 질문하고 내가 답하면서 이런 문서를 만들어요. 이 PRD대로 만든 결과물이 [완성 샘플](sample/index.html)이에요. 팀 이름, 서비스 이름, 숫자는 모두 수업을 위해 만든 가상 데이터예요.

PRD(Product Requirements Document, 제품 요구사항 문서)는 "무엇을 만들지"를 적은 문서예요. "어떻게 만들지"는 Claude가 계획으로 제안하고, 나는 그 계획을 읽고 승인해요.

## 1. 만들 것

- 샘플 운영팀의 한 주 운영 숫자를 한 화면에서 보는 주간 보고서예요. 월요일 아침에 내가 열어 보고, 팀장에게 주소를 보내요.
- 보는 사람은 나와 팀장이에요. 휴대폰에서도 열어요.
- 파일은 `index.html` 한 장과 `media/` 폴더예요. CSS와 JS는 `index.html` 안에 넣어요. 빌드 도구와 npm 패키지는 쓰지 않아요.
- 내 PC에서는 `python3 -m http.server 8080 --bind 127.0.0.1`로 서버를 켜고 http://127.0.0.1:8080/ 에서 열어요.

## 2. 화면

위에서 아래로 이 순서로 보여요.

1. 머리글: 표지 그림, 제목 "샘플 운영팀 주간 보고서", 기간 "2026년 41주 · 10월 5일(월)–10월 11일(일)"
2. 요약 카드 4개: 총 요청 수, 평균 오류율, 배포 횟수, 장애 건수
3. 요일별 요청 수 막대 차트: 인라인 SVG로 그려요. 막대에 마우스를 올리면 요일, 요청 수, 오류율이 보여요. 차트 아래 "표로 보기"를 펼치면 같은 숫자가 표로 나와요.
4. 서비스별 표: 서비스, 요청 수, 오류율, 배포, 상태, 메모
5. 듣고 보기: 음성 요약 재생 막대와 그 원고, 하이라이트 영상
6. 이번 주 한 일과 다음 주 할 일: 목록 두 개와 그림 한 장
7. 바닥글: "모든 숫자는 수업용 가상 데이터예요."와 미디어 상태 줄

폭 390px 휴대폰 화면에서도 페이지 전체에 가로 스크롤이 생기지 않아요. 요약 카드는 좁은 화면에서 두 개씩 두 줄로 내려가요. 칸이 많은 표는 표 안에서만 옆으로 밀어서 봐요.

## 3. 데이터

- 데이터는 `<script>` 맨 위의 `REPORT` 객체 하나에 모아요. 화면의 숫자는 모두 이 객체에서 읽거나 계산해요.
- 합계와 평균은 코드가 계산해요. 평균 오류율은 요일별 오류율을 요청 수로 가중한 평균이에요.

요일별 숫자예요.

| 요일 | 요청 수 | 오류율(%) |
| --- | --- | --- |
| 월 | 286,400 | 0.31 |
| 화 | 301,200 | 0.28 |
| 수 | 295,800 | 0.35 |
| 목 | 318,900 | 0.82 |
| 금 | 290,100 | 0.40 |
| 토 | 172,300 | 0.22 |
| 일 | 168,700 | 0.25 |

서비스별 숫자예요.

| 서비스 | 요청 수 | 오류율(%) | 배포 | 상태 | 메모 |
| --- | --- | --- | --- | --- | --- |
| billing(결제) | 548,200 | 0.21 | 4 | 정상 | |
| catalog(상품 목록) | 826,700 | 0.58 | 5 | 주의 | 목요일 배포 뒤 오류율이 올라 40분 만에 되돌림 |
| identity(로그인) | 458,500 | 0.31 | 3 | 정상 | |

- 장애는 1건이에요(catalog 목요일).
- 이번 주 한 일: catalog 검색 캐시 적용, billing 결제 로그 보관 기간 정리, 목요일 장애 회고 작성
- 다음 주 할 일: billing 응답 시간 줄이기, catalog 배포 전 점검 목록 만들기

## 4. 미디어 파일 계약

코드는 아래 네 경로만 찾아요. 생성 도구가 붙인 파일 이름이 무엇이든, 저장할 때 이 이름으로 바꿔 넣어요.

| 파일 | 쓰는 곳 | 권장 | 없을 때 |
| --- | --- | --- | --- |
| `media/cover.svg` | 머리글 표지 그림 | 가로로 긴 그림, 글자 없이 | 그림을 숨기고 제목만 보여요 |
| `media/checklist.png` | 이번 주 한 일 옆 그림 | 가로 480px 안팎 | 그림을 숨기고 목록만 보여요 |
| `media/summary.m4a` | 음성 요약 | 30초 이하, AAC | "음성 파일이 없어요"를 보여요 |
| `media/highlight.mp4` | 하이라이트 영상 | 640×360, 10초 이하, H.264 | "영상 파일이 없어요"를 보여요 |

- 경로는 `<script>` 맨 위의 상수 `MEDIA`에만 둬요.
- 파일이 없거나 재생이 막혀도 페이지는 멈추지 않아요. 콘솔에 잡히지 않은 예외(Uncaught 오류)를 남기지 않아요.
- 음성은 내가 재생 버튼을 눌러야 나와요. 영상은 소리 없이 자동으로 반복 재생해요(브라우저 자동재생 정책).
- 파일 이름은 소문자, 숫자, `-`만 써요. 경로는 `/`로 시작하지 않는 상대 경로로 써요.
- 미디어는 합쳐서 2MB 이하로 해요.
- 바닥글의 상태 줄은 파일마다 있는지 보여 줘요. 네 파일이 다 있으면 "표지 있음 · 그림 있음 · 음성 있음 · 영상 있음"이에요.

## 5. 하지 않을 것

- 외부 리소스를 불러오지 않아요. CDN, 웹 폰트, 차트 라이브러리, 인터넷 이미지, 분석 스크립트를 모두 쓰지 않아요.
- 서버 통신, 로그인, 입력 폼은 만들지 않아요.
- 실제 회사 이름, 사람 이름, 사내 시스템 주소를 넣지 않아요.

## 6. 완료 기준

- [ ] 8080 서버로 열면 요약 카드가 1,833,400건, 0.40%, 12회, 1건으로 보여요.
- [ ] 바닥글 상태 줄이 "표지 있음 · 그림 있음 · 음성 있음 · 영상 있음"이고, DevTools Console에 빨간 줄이 없어요.
- [ ] `media/` 폴더 이름을 잠시 바꿔도 페이지가 끝까지 보이고, 상태 줄이 "없음"으로 바뀌어요.
- [ ] DevTools 기기 모드로 폭 390px에서 봐도 페이지 전체에 가로 스크롤이 없어요.
- [ ] 검사 스크립트 `check.py`가 오류 0개로 끝나요.
