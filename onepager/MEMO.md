# 아이디어 메모 예시

PRD를 만들기 전에 쓰는 메모 예시예요. 수업에서는 쓰지 않아요. 5분 동안 생각나는 대로 적었어요. 문장이 거칠고 빠진 것이 있어도 괜찮아요. 빠진 것은 Claude Code가 질문해서 채워 줘요. 이 메모를 정리한 결과가 [PRD.md](PRD.md)예요.

팀 이름, 서비스 이름, 숫자는 모두 수업을 위해 만든 가상 데이터예요.

## 메모

```text
매주 월요일 아침에 팀 주간 보고를 쓰는데, 엑셀에서 숫자를 옮겨 적는 게 귀찮아요.
요청 수, 오류율, 배포 횟수, 장애 건수만 한눈에 보면 돼요.
서비스는 billing, catalog, identity 세 개예요.
요일별 차트가 하나 있고, 서비스별 표가 있으면 좋겠어요.
팀장님이 이동 중에 들을 수 있게 30초 안쪽 음성 요약이 있으면 좋겠어요.
짧은 하이라이트 영상도 있으면 재밌을 것 같아요.
나 혼자 만들고 주소만 보내요. 로그인은 필요 없어요.
```

## 이 메모에 빠진 것

메모만 주고 "만들어 줘"라고 하면 Claude가 아래 내용을 짐작으로 채워요. 짐작이 내 생각과 다르면 다시 고쳐야 해요. 그래서 만들기 전에 Claude에게 질문을 받아 PRD로 정리해요.

| 빠진 것 | 질문 예 | 이 PRD에서 정한 답 |
| --- | --- | --- |
| 기간 | 어느 주의 보고서인가요? | 2026년 41주(10월 5일~11일) |
| 화면 순서 | 무엇을 맨 위에 둘까요? | 표지, 요약 카드 4개, 차트, 표, 미디어, 한 일 순서 |
| 데이터 | 숫자는 어디에 두나요? 평균 오류율은 어떻게 계산하나요? | `index.html` 안의 객체 하나, 요청 수로 가중한 평균 |
| 미디어 | 파일 이름과 형식은요? 파일이 없으면 어떻게 하나요? | `media/` 아래 네 파일, 없으면 그 칸만 "없어요"로 표시 |
| 하지 않을 것 | 차트 라이브러리를 써도 되나요? | 외부 리소스 없이 인라인 SVG로 |
| 완료 기준 | 다 됐는지 무엇으로 확인하나요? | 요약 숫자, 상태 줄, 콘솔, 폭 390px, 검사 스크립트 |

## Claude에게 줄 요청

빈 폴더에 메모를 `MEMO.md`로 저장하고, Claude Code를 Manual 모드(`claude --permission-mode default`)로 켠 다음 아래처럼 요청해요. AskUserQuestion은 Claude가 선택지를 띄워 나에게 묻는 도구예요.

```text
MEMO.md는 내가 만들고 싶은 HTML 한 장에 대한 메모야.
AskUserQuestion 도구로 나에게 질문해서 빠진 것을 채우고, PRD.md를 써줘.
PRD.md에는 만들 것, 화면, 데이터, 미디어 파일 계약, 하지 않을 것, 완료 기준을 넣어줘.
완료 기준은 내가 직접 확인할 수 있는 문장으로 써줘. 코드는 아직 만들지 마.
```
