# 3교시 실습 순서와 문장

1일차 3교시 실습 네 번의 순서와 보내는 문장이에요. `<꺾쇠>` 안만 내 것으로 바꿔도 돼요. 꺾쇠 기호는 보내지 않아요. 긴 게임 프롬프트와 미디어 프롬프트는 [교안](../../../docs/day1-onepager.md)에 있어요.

> 오늘 올리는 저장소와 페이지는 누구나 볼 수 있어요. 회사 이름, 고객 이름, 동료 이름, 사내 시스템 주소는 넣지 않아요.

## 실습 ① 내 게임 한 판 (10분)

1. 바탕화면에 `my-game` 폴더를 만들어요. 이름은 영어로, 띄어쓰기 없이 써요.
2. Code 탭에서 **+ New session**을 누르고 **Select folder**로 `my-game`을 골라요. 모드는 **Auto**로 두고, 없으면 **Accept edits**로 해요.
3. 교안 1절의 게임 프롬프트를 복사해서 보내요. 발표의 고르기 장면에서 복사해도 같아요.
4. `index.html`을 열어 한 판 하고, 고칠 곳은 같은 세션에 한 줄로 보내요. 강사가 실제로 보낸 문장이에요.

```text
레벨을 <세 단계>로 나눠 줘. <100점>마다 레벨이 오르고, 화면 위에 지금 레벨을 크게 보여 줘. 다른 규칙은 그대로 둬.
```

5분이 넘도록 파일이 안 생기면 [견본 게임](../../game-kit/examples/sample-game/index.html)을 받아 `my-game`에 넣어요. 실제 결과는 [code-tab/answers.md](code-tab/answers.md) 1절에 있어요.

## 실습 ② 모션 하나, 미디어 하나 (12분)

같은 세션에 모션그래픽 문장을 보내요. 강사가 실제로 보낸 문장이에요.

```text
이 게임을 소개하는 <10초>짜리 모션그래픽을 intro.html로 만들어 줘. 게임 제목이 튀어나오고, 주인공 <토끼>가 화면을 가로질러 달리고, <당근>이 떨어지고, 마지막에 '지금 플레이' 글자가 깜빡이게 해 줘. 새 프로그램은 설치하지 말고 HTML, CSS, 자바스크립트만 써 줘. 다 하면 무엇을 만들었는지 알려 줘.
```

그다음 그림, 음악, 영상 가운데 하나를 만들어요. 사이트에 넣을 영어 프롬프트는 교안 2절의 'Claude에게' 글로 Claude에게 부탁해요. 사이트가 막히면 미리 만든 세트 [밝은](../../game-kit/media-bright.zip), [우주](../../game-kit/media-space.zip), [숲](../../game-kit/media-forest.zip) 중 하나를 받아요.

받은 파일은 `poster.png`, `music.mp3`, `ending.mp4`처럼 소문자 이름으로 `my-game`에 넣어요. 게임에 안 나오면 이렇게 보내요. 이 문장은 리허설 때 확인해요.

```text
@poster.png 이 그림을 시작 화면 포스터로 써 줘.
```

## 실습 ③ 보고서 한 장 (5분)

`dbinc-notes`를 고른 세션에 보내요. 강사가 실제로 보낸 문장이에요.

```text
orders.csv를 읽고 <주간 판매 보고서>를 report.html 한 장으로 만들어 줘. 맨 위에 요약 카드 세 개(총 매출, 주문 수, 가장 많이 팔린 상품), 그 아래 상품별 매출 막대그래프와 주문 표를 넣어 줘. 숫자는 파일에 있는 것만 쓰고, 새 프로그램은 설치하지 마. 더블클릭으로 열 수 있게 해 주고, 다 하면 계산한 숫자를 알려 줘.
```

`report.html`을 열어 총 매출이 89,000원인지 봐요.

## 실습 ④ 배포 · QR (10분)

먼저 GitHub CLI로 로그인해요. Windows는 PowerShell에서 `winget install --id GitHub.cli`로 설치하고, 새 터미널 창에서 `gh auth login`을 쳐요. `gh auth status`에 `Logged in`이 보이면 돼요.

`my-game` 세션에 보내요. 저장소 이름은 영어 소문자와 `-`만 써요. 이 문장은 리허설 때 확인해요.

```text
GitHub CLI로 이 폴더를 공개 저장소 <my-game>의 main 브랜치로 올리고 Pages로 띄워 줘. 작성자는 이 폴더에만 <수강생>, <student@example.com>으로 해 줘. 주소도 알려 줘.
```

Claude가 커밋, 저장소 만들기, Pages 켜기 명령을 차례로 물어요. 무엇을 하는 명령인지 읽고 허락해요. 작성자 이름과 메일은 지어낸 것을 써요. 회사 메일은 쓰지 않아요.

주소는 `https://<아이디>.github.io/my-game/` 모양이에요. 보통 1분쯤 뒤에 열려요. 발표의 QR 칸에 주소를 붙여 넣고 휴대폰 카메라로 찍어서 열어요. Pages가 안 켜지면 저장소의 **Settings** → **Pages**에서 **Deploy from a branch**, `main`, `/ (root)`를 고르고 **Save**를 눌러요.

## 수업 뒤에 해 볼 것

Plan 모드로 바꾸고 게임을 하나 더 고쳐 봐요. 강사가 실제로 보낸 문장이에요. 받은 계획은 [result-3/plan.md](result-3/plan.md), 바뀐 줄은 [result-3/best-score.diff](result-3/best-score.diff), 화면은 [shots/3-new-best.png](shots/3-new-best.png)에 있어요. 이 실행에는 `deploy/` 폴더가 따로 있어서 계획에 파일이 두 개 나와요.

```text
게임 오버 화면과 클리어 화면에 최고 점수를 함께 보여 줘. 새로고침해도 최고 점수가 남아야 해.
최고 점수는 이 브라우저에만 저장하고, 새 기록이면 '새 기록'이라고 글자로 적어 줘.
점수 계산, 속도, 목숨 규칙과 미디어 파일은 바꾸지 마. 바꿔야 할 것 같으면 먼저 물어봐.
다 고친 뒤 브라우저로 열어 확인하고, 바꾼 파일과 줄 수를 알려 줘.
```

다 보면 바뀐 내용을 올려요. 이 문장은 리허설 때 확인해요.

```text
바뀐 내용을 커밋하고 GitHub에 올려 줘. 메시지는 무엇이 달라졌는지 보이게 써 줘.
```
