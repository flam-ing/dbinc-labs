# 2교시 실습 자료 · 설치하고 둘러보기

1일차 2교시 [개발 환경 구축과 첫 실행](../../docs/day1-setup.md)에서 쓰는 자료예요. 이 시간에는 따로 받을 실습 파일이 거의 없어요. 1교시에 만든 바탕화면 `dbinc-notes` 폴더에 [`orders.csv`](../agent-intro/orders.csv)를 복사해서 Code 탭과 터미널로 첫 요청을 보내요. 마지막 실습에서는 3교시 배포에 쓸 GitHub CLI(`gh`)를 설치하고 로그인해요.

| 파일 | 무엇 |
| --- | --- |
| [`examples/prompts.md`](examples/prompts.md) | 실습마다 보내는 말 |
| [`examples/answers.md`](examples/answers.md) | 그 말을 실제로 보냈을 때의 답 |
| [`examples/store-total.md`](examples/store-total.md) | Accept edits로 보냈을 때 Claude가 만든 파일 |

`dbinc-notes` 폴더가 없으면 바탕화면에 새로 만들고 `orders.csv`만 넣어도 돼요. 그때는 첫 답에 `NOTES.md`와 `agent-compare.md`가 나오지 않아요.

`_reference/claude-runs/`는 강사가 실제로 돌려 본 원문 기록이에요. 강사용이라 학생용 ZIP과 교안 사이트에는 들어 있지 않아요.
