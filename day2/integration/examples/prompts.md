# 2일차 5교시에 보내는 문장

[사내 시스템 연동](../../../../docs/day2-integration.md)의 따라 하기 세 개와 실습 두 개, 선택 실습에서 보내는 문장이에요. 데스크톱 앱 Code 탭으로 해요. 문장은 그대로 보내도 되고 내 말로 바꿔도 돼요.

Code 탭에서 강의 자료의 회의실 예약 폴더를 열어요. Windows는 `C:\Users\<내 이름>\dbinc-ai-course\labs\roombook`, macOS는 `~/dbinc-ai-course/labs/roombook`이에요. 서버는 PowerShell 창을 따로 열어 켜 둬요. 켜는 법과 연습 계정은 [회의실 예약 안내](../../../roombook/README.md)에 있어요.

```powershell
cd ~\dbinc-ai-course\labs\roombook
py app.py
```

macOS에서는 `py` 대신 `python3`으로 쳐요.

## 따라 하기 A · 구글 캘린더 읽어 보기 (8분)

입력창의 + 버튼, Add connectors에서 Google Calendar를 개인 구글 계정으로 연결해요. 메뉴가 Connectors로 보이면 Connectors, Browse connectors로 가요. 입력창에 `/mcp`를 쳐서 `claude.ai Google Calendar`가 보이면 보내요.

```text
이번 주 내 구글 캘린더 일정 중 회의만 10개까지 표로 보여 줘. 일정은 만들거나 고치지 마.
```

일정이 비어 있으면 같은 메뉴에서 Google Drive도 연결하고 이 문장을 보내요.

```text
구글 드라이브에서 제목에 '회의록'이 들어간 문서 5개를 찾아 제목과 수정일을 표로 보여 줘. 파일은 만들거나 고치거나 공유하지 마.
```

더 해 보기로 Gmail도 연결하고 이 문장을 보내 봐요.

```text
지난 7일 동안 받은 메일 중 제목에 '교육'이 들어간 것 5개만 보낸 사람과 제목을 표로 보여 줘. 메일은 보내거나 지우거나 라벨을 바꾸지 마.
```

문장에 적은 "10개까지"는 Claude에게 하는 부탁이에요. 확실한 한도는 도구 안이나 권한 규칙에 둬요. 세 문장 모두 리허설 때 확인해요. 아직 실제로 받은 답의 기록은 없어요.

## 따라 하기 B · 화면 뒤 요청 표 받기 (7분)

브라우저로 `http://127.0.0.1:8010`을 열고 minji, roombook1로 로그인한 뒤 보내요.

```text
app.py와 static 폴더를 읽고, 화면이 부르는 API를 주소·방법·주고받는 값 표로 정리해 줘. 고치지는 마.
```

강사가 해 봤을 때 20초 걸렸어요. 수업 툴이라 서버 코드(`app.py`)도 읽어요. 실제 사내 툴에는 서버 코드가 없어서 화면 코드와 F12 Network만 보고 찾아요. 시간이 남으면 F12, Network, Fetch/XHR을 고르고 메뉴를 눌러 `/api/...` 요청을 봐요.

## 따라 하기 C · Plan 모드로 화면 규칙 찾기 (7분)

사이드바의 + New로 새 세션을 열고 모드를 Plan으로 바꾼 뒤 보내요.

```text
화면 코드에서 막고 있는 규칙을 모두 찾아서, 서버도 막는지 표로 보여 줘.
```

강사가 해 봤을 때 35초 걸렸고, "화면 규칙 14개 중 서버가 막는 건 2개뿐입니다."라는 답이 왔어요. 실제 사내 툴에서는 서버가 막는지 모르니 화면 규칙을 모두 CLI가 지켜요.

## 실습 1 · 회의실 예약 CLI 만들기 (18분)

모드를 Accept edits로 바꾸고 보내요. 명령 카드가 뜨면 읽고 허락해요.

```text
이 회의실 예약 화면을 쓰는 CLI를 만들어 줘. 로그인은 Edge나 Chrome 창을 띄워 내가 ID와 비밀번호를 직접 넣게 하고 쿠키만 저장해. 화면이 막는 규칙과 읽기 한도는 CLI도 똑같이 지켜.
```

다 되면 로그인해요. Edge 창이 뜨면 그 창에 아이디와 비밀번호를 직접 넣어요. 채팅에는 쓰지 않아요.

```text
로그인 명령을 실행해 줘. 창이 뜨면 내가 넣을게.
```

로그인한 뒤 "내 예약 보여 줘"라고 보내서 목록이 오면 끝이에요. 빨리 끝나면 이것도 보내요.

```text
3시간 예약과 다른 사람 예약 취소를 해 보고, CLI가 보내기 전에 막는지 보여 줘.
```

읽기 한도도 해 봐요. 먼저 이 문장을 보내고 Claude가 검색어를 나눠 여러 번 부르는지 봐요.

```text
CLI로 영업팀 직원을 모두 찾아 줘. 막히면 왜 막혔는지 알려 줘.
```

나눠 불러서 다 모았다면 하루 상한을 넣어요.

```text
직원 찾기는 여러 번 불러도 하루에 30명까지만 보여 주게 홈 폴더에 센 값을 남겨 줘.
```

Windows에서 Claude가 `python3`로 실행해서 `Python was not found`가 나오면 "Windows라서 py로 실행해 줘"라고 말해요.

강사가 첫 문장을 보냈을 때 2분 53초 만에 CLI가 나왔고, 강사 검사 16개를 모두 통과했어요. 로그인 문장과 더 해 보기 문장은 리허설 때 확인해요.

## 선택 · 같은 CLI를 MCP로 등록하기 (5분)

실습 1이 빨리 끝난 사람만 해요.

```text
이 CLI를 MCP 도구로도 쓸 수 있게 .mcp.json에 등록해 줘.
```

`.mcp.json` 파일 카드가 뜨면 Accept를 눌러요. 채팅에 "허락할게요"라고 써도 권한은 바뀌지 않아요. 같은 폴더에서 + New로 새 세션을 열고 `/mcp`에서 roombook을 확인한 뒤 "roombook 도구로 오늘 회의실 현황을 보여 줘"라고 물어요. 더 해 보기로 "roombook 도구로 영업팀 사람을 모두 찾아서 전화번호까지 보여 줘."를 보내고 Claude가 몇 번 나눠 부르는지 봐요. Windows에서 서버가 안 보이면 `.mcp.json`의 `"command"`를 `.venv\Scripts\python.exe`로 고쳐 달라고 해요.

## 실습 2 · 권한 규칙 걸기 (7분)

실습 1에서 쓴 폴더를 그대로 쓰고, 아래 문장을 그대로 보내요.

```text
방금 만든 CLI의 회의실 현황과 목록 보기는 묻지 말고, 예약과 취소와 직원 찾기는 매번 묻게 권한 규칙을 걸어 줘.
```

`.claude/settings.json` 파일 카드가 뜨면 `allow`와 `ask` 칸이 있는지 읽고 Accept를 눌러요. 빨리 끝나면 새 세션을 열고 이렇게 보내서, 현황은 카드 없이 돌고 예약에는 카드가 뜨는지 봐요.

```text
CLI로 오늘 회의실 현황을 보여 줘. 그다음 다음 평일 10시에 한라 회의실을 30분 예약해 줘.
```

이 문장은 리허설 때 확인해요. 아직 실제로 받은 답의 기록은 없어요.

예전 판에서 쓰던 방명록 MCP·CLI 실습은 수업에서 뺐어요. 수업 뒤에 해 보고 싶으면 참고 방명록(`labs/guestbook`)을 열고 보내요. 강사가 해 본 기록은 [cli/examples](../../cli/examples/check-output.txt)에 있어요.

어제 만든 방명록을 Claude가 쓸 수 있게 MCP로 연결해 줘. 다 되면 목록을 물어볼게.

```text

```

## 수업 뒤에 해 볼 것

`labs/day2` 폴더에는 가상 사내 시스템이 있어요. 서비스 이벤트 기록을 MCP 서버(`server.py`)로 내놓아요. 이 폴더를 Code 탭에서 열고 해 봐요. 처음 연결한 툴에는 "만들거나 고치지 마"를 붙여요.

가상환경과 `.mcp.json`을 만들어요. 명령 카드와 파일 카드를 읽고 허락해요.

```text
이 폴더에 .venv 가상환경을 만들고 requirements.txt를 설치해 줘.
그다음 server.py를 dbinc-training-events라는 MCP 서버로 등록하는 .mcp.json을 만들어 줘.
```

같은 폴더로 새 세션을 열고 물어요.

```text
dbinc-training-events 도구로 billing 서비스의 오류율을 알려 줘.
어떤 도구를 몇 번 불렀는지도 같이 보여 줘. 파일은 만들거나 고치지 마.
```

실제로 받은 답은 [billing-answer.md](billing-answer.md)에 있어요. "3건 중 2건, 66.7%"가 나와요.

같은 일을 SDK로도 해 봐요. Accept edits 모드로 보내요.

```text
tools/smoke_mcp.py를 참고해서 MCP 파이썬 SDK로 server.py에 연결하는 스크립트를 work/sdk_report.py로 만들어 줘.
query_events를 next_offset이 null이 될 때까지 읽고, 서비스별 요청 수와 오류율(상태 500 이상)을 표로 출력해 줘.
.venv 안의 python으로 실행해서 결과를 보여 줘. integration/reference 폴더는 열지 마.
```

실제로 받은 답은 [sdk-answer.md](sdk-answer.md), 그때 만든 스크립트는 [sdk_report.py](sdk_report.py)예요.

`gh`가 로그인돼 있으면 CLI 길도 해 봐요.

```text
gh로 GitHub 저장소 flam-ing/cafe-points-oncall의 최근 이슈 5개를 표로 보여 줘(번호, 제목, 상태).
gh가 없거나 로그인이 안 돼 있으면 설치나 로그인을 하지 말고 나에게 알려 줘. 이슈를 만들거나 닫지 마.
```
