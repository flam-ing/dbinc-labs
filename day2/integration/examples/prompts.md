# 2일차 5교시에 보내는 문장

[사내 시스템 연동](../../../../docs/day2-integration.md)의 따라 하기 세 개와 실습 세 개에서 보내는 문장이에요. 데스크톱 앱 Code 탭으로 해요. 바꿀 곳은 "방명록" 한 단어예요. 3교시 게임을 만들었으면 "게임"으로 바꿔요.

어제 만든 방명록 폴더를 열어요. 없거나 안 켜지면 강의 자료의 참고 방명록 폴더를 열어요. macOS는 `~/dbinc-ai-course/labs/guestbook`, Windows는 `C:\Users\<내 이름>\dbinc-ai-course\labs\guestbook`이에요. 참고 방명록은 설치할 것이 없고 8000번 포트에서 돌아요. 서버는 Claude에게 "방명록 서버를 켜 줘"라고 맡겨도 돼요.

## 따라 하기 A · 커넥터와 /mcp 보기 (3분)

입력창의 + 버튼, Connectors를 열어 보고, 입력창에 `/mcp`를 친 뒤 보내요.

```text
지금 이 세션에서 쓸 수 있는 커넥터와 MCP 도구를 표로 정리해 줘. 아무것도 만들거나 고치지 마.
```

커넥터가 켜진 사람은 이것도 해 봐요.

```text
구글 드라이브에서 제목에 '회의록'이 들어간 문서 5개를 찾아 제목과 수정일을 표로 보여 줘. 파일은 만들거나 고치거나 공유하지 마.
```

두 문장 모두 리허설 때 확인해요. 아직 실제로 받은 답의 기록은 없어요.

## 실습 1 · 방명록을 MCP로 연결 (15분)

```text
어제 만든 방명록을 Claude가 쓸 수 있게 MCP로 연결해 줘. 다 되면 목록을 물어볼게.
```

명령 카드와 파일 카드가 뜨면 읽고 허락해요. 패키지를 내려받아야 해서 인터넷이 필요해요. 다 되면 같은 폴더로 New session을 열고 "방명록 목록 보여 줘"라고 물어요. 처음 쓰는 서버라 허락을 묻는 창이 뜨면 허락해요. 목록이 오면 끝이에요.

이 문장은 리허설 때 확인해요. 아직 실제로 받은 답의 기록은 없어요.

## 따라 하기 B · 화면 뒤 요청 찾기 (5분)

```text
방명록 서버를 켜 줘. 켜지면 브라우저로 열 주소를 알려 줘.
```

Claude가 알려 준 주소를 브라우저로 열고 F12, Network, Fetch/XHR을 고른 뒤 글을 하나 남겨요. `entries`가 두 줄(200, 201) 보이면 끝이에요.

## 따라 하기 C · Plan 모드로 화면 규칙 찾기 (7분)

New session을 열고 모드를 Plan으로 바꾼 뒤 보내요.

```text
이 폴더의 방명록 화면 코드를 읽고 표 두 개로 정리해 줘. 1) 화면이 부르는 API 2) 화면이 막는 것과 그 코드 위치. 파일은 고치지 마.
```

강사가 CLI 계획까지 부탁한 긴 문장으로 해 본 답은 [cli/examples/plan-answer.md](../../cli/examples/plan-answer.md)에 있어요. 긴 문장은 [cli/examples/prompts.md](../../cli/examples/prompts.md)의 1번이에요. 이 짧은 문장은 리허설 때 확인해요.

## 실습 2 · 방명록을 CLI로 (12분)

따라 하기 C의 세션에서 모드를 Accept edits로 바꾸고 보내요. 새 세션에서 해도 돼요.

```text
어제 만든 방명록을 CLI로 만들어 줘. 화면이 막는 것은 CLI도 막아 줘. 다 되면 그 CLI로 목록을 보여 줘.
```

명령 카드가 뜨면 명령을 읽고 허락해요. Claude가 만든 CLI로 목록을 보여 주면 끝이에요. 빨리 끝나면 이것도 보내요.

```text
이름을 41자로 해서 글을 남겨 보고, CLI가 보내기 전에 막는지 보여 줘.
```

서버가 꺼져 있어서 실패하면 "서버를 켜고 다시 해 줘"라고 말해요. Claude가 영어로 답하면 "한국어로 다시 정리해 줘"라고 말해요.

강사가 참고 방명록으로 미리 해 봤을 때는 Claude가 `tools/gb.py`를 만들었어요. 너무 긴 이름과 공백만 넣은 이름은 보내기 전에 막았고, 맞는 값만 저장했어요. 전체 출력은 [check-output.txt](../../cli/examples/check-output.txt)에 있어요. 그때 보낸 문장은 더 길어서 내 결과와 파일 이름이 달라도 괜찮아요. 이 짧은 문장은 리허설 때 확인해요.

## 실습 3 · 권한 규칙 걸기 (7분)

실습 2에서 쓴 폴더를 그대로 쓰고, 아래 문장을 그대로 보내요.

```text
방금 만든 CLI의 목록은 묻지 말고, 쓰기는 매번 묻게 권한 규칙을 걸어 줘.
```

`.claude/settings.json` 파일 카드가 뜨면 `allow`와 `ask` 칸이 있는지 읽고 Accept를 눌러요. `.claude` 폴더는 Claude Code가 따로 지키는 곳이라 Accept edits 모드여도 카드가 떠요. 빨리 끝나면 새 세션을 열고 이렇게 보내서, 목록은 카드 없이 돌고 쓰기에는 카드가 뜨는지 봐요.

```text
CLI로 방명록 최신 글 3개를 보여 줘. 그다음 이름은 실습자, 내용은 '규칙 확인'으로 한 줄 남겨 줘.
```

강사가 `tools/gb.py`로 미리 해 봤을 때는 `allow`에 목록 명령이, `ask`에 쓰기 명령이 들어갔어요. 이 짧은 문장은 리허설 때 확인해요.

## 만든 CLI를 나누는 문장

수업에서는 해 보지 않고 교안에서 소개만 해요. 실제로 돌려 보지 않은 예시예요.

```text
이 CLI를 언제, 어떻게 쓰는지 .claude/skills/guestbook-cli/SKILL.md로 정리해 줘. description에는 '방명록 글을 읽거나 남길 때'를 넣어 줘.
```

```text
이 CLI의 목록과 쓰기를 MCP 도구로 등록해 줘. 쓰기는 확인 없이는 보내지 않게 해 줘.
```

## 수업 뒤에 해 볼 것

`labs/day2` 폴더에는 가상 사내 시스템이 있어요. 서비스 이벤트 기록을 MCP 서버(`server.py`)로 내놓아요. 이 폴더를 Code 탭에서 열고 해 봐요. 처음 연결한 툴에는 "만들거나 고치지 마"를 붙여요.

가상환경과 `.mcp.json`을 만들어요. 명령 카드와 파일 카드를 읽고 허락해요.

```text
이 폴더에 .venv 가상환경을 만들고 requirements.txt를 설치해 줘.
그다음 server.py를 dbinc-training-events라는 MCP 서버로 등록하는 .mcp.json을 만들어 줘.
```

같은 폴더로 새 세션을 열고 물어요.

```text
dbinc-training-events 도구로 billing 서비스의 오류율을 알려 줘.
어떤 도구를 몇 번 불렀는지도 같이 보여 줘. 파일은 만들거나 고치지 마.
```

실제로 받은 답은 [billing-answer.md](billing-answer.md)에 있어요. "3건 중 2건, 66.7%"가 나와요.

같은 일을 SDK로도 해 봐요. Accept edits 모드로 보내요.

```text
tools/smoke_mcp.py를 참고해서 MCP 파이썬 SDK로 server.py에 연결하는 스크립트를 work/sdk_report.py로 만들어 줘.
query_events를 next_offset이 null이 될 때까지 읽고, 서비스별 요청 수와 오류율(상태 500 이상)을 표로 출력해 줘.
.venv 안의 python으로 실행해서 결과를 보여 줘. integration/reference 폴더는 열지 마.
```

실제로 받은 답은 [sdk-answer.md](sdk-answer.md), 그때 만든 스크립트는 [sdk_report.py](sdk_report.py)예요.

`gh`가 로그인돼 있으면 CLI 길도 해 봐요.

```text
gh로 GitHub 저장소 <강사아이디>/guestbook-oncall의 최근 이슈 5개를 표로 보여 줘(번호, 제목, 상태).
gh가 없거나 로그인이 안 돼 있으면 설치나 로그인을 하지 말고 나에게 알려 줘. 이슈를 만들거나 닫지 마.
```
