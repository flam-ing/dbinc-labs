# 재고 발주 배치 (reorder)

물류팀 재고 발주 자동화 프로그램이에요. 매일 아침 창고별 재고와 최근 판매를 보고, 공급처에 보낼 발주 파일(EDI 업로드용 CSV)을 만들어요.

## 실행

파이썬 2.7이 필요해요.

```
cd D:\nuri\reorder
python reorder.py D:\nuri\data\stock.csv D:\nuri\data\sales.csv D:\nuri\data\supplier.csv 2012-03-05
```

결과 파일은 `D:\nuri\edi\out\PO_날짜.csv`에 생겨요. 화면에 나오는 리포트는 복사해서 구매팀에 메일로 보내요.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| reorder.py | 메인이에요. 창고별로 계산해요 |
| invlib.py | 파일 읽기와 공통 자료예요 |
| po_writer.py | 발주 파일을 써요 |
| config.py | 경로와 계수를 모아 뒀어요 |
| forecast.py | 수요 예측이에요(작업 중) |

## 계산

- 하루 평균은 최근 30일 판매를 30으로 나누고 소수점은 버려요.
- 안전재고는 하루 평균에 리드타임과 계수 1.5를 곱해요.
- 재고가 발주점 아래로 내려가면 주문해요.
- 단종 상품은 빼요.

자세한 기준은 위키의 "발주 기준 정리"를 봐요.

## 2015-09 추가 (이하은)
