# INV-78 안 팔리는 상품도 재고가 0이면 MOQ만큼 주문해요

| 항목 | 내용 |
| --- | --- |
| 키 | INV-78 |
| 유형 | 문의 |
| 상태 | 열림 |
| 우선순위 | 낮음 |
| 담당 | 박준서 (전산팀) |
| 보고 | 김서윤 (구매팀) |
| 만든 날 | 2018-08-20 |
| 레이블 | reorder, 이천 |

> 교육용 가상 자료예요.

## 설명

이천 물티슈 100매(D-4001)는 한 달에 20개쯤 팔려요. 재고가 0이 된 날 40개가 주문됐어요. 리포트에는 하루 평균이 0.00으로 나오는데 왜 주문이 나가는지 모르겠어요. 이천 창고는 자리가 부족해서 안 팔리는 상품이 쌓이면 곤란해요.

## 댓글

**박준서** · 2018-08-22

원인은 두 가지예요. 첫째, 이천은 하루 평균을 버림해서 30일에 30개 미만으로 팔리면 0이 돼요(INV-63). 둘째, 그러면 발주점도 0이에요. 재고 0은 발주점과 같으니 주문 대상이 되고, 필요한 수량이 0개여도 MOQ(40개)까지 올려서 주문해요.

**정민호 (구매팀장)** · 2018-08-27

매장 진열용으로 최소 수량은 있어야 하니 일부러 막지는 마세요. 다만 이렇게 나간 상품은 단종 검토 대상으로 따로 목록을 받고 싶어요.
