> 교육용 가상 자료예요. 회사, 사람, 상품, 금액은 모두 지어낸 것이에요.

배치 서버를 윈도우 서버 2012로 바꾸면서 재고 발주 배치를 파이썬 2.7에서 3.4로 옮겼어요. 새 서버의 회사 표준 파이썬이 3.4예요. 처음 만든 최지훈 대리님은 다른 팀으로 옮기셔서, 코드는 제가 읽으면서 옮겼어요.

## 바꾼 것

| 항목 | 파이썬 2에서 | 파이썬 3에서 |
| --- | --- | --- |
| 화면 출력 | `print "..."` 문장 | `print(...)` 함수. 맨 위에 `from __future__ import print_function`을 남겨 뒀어요. |
| 딕셔너리 | `has_key`, `iteritems` | `in`, `items` |
| 한글 문자열 | `unicode` | `str`. invlib.py 맨 위에 `unicode = str`을 넣어서 예전 코드가 그대로 돌게 했어요. |
| 파일 읽기 | `open` 후 `decode('utf-8')` | `io.open(..., encoding='utf-8')` |
| 발주 파일 쓰기 | `'wb'`로 열고 CP949로 인코딩 | UTF-8, `newline=''`. 새 서버에서 줄바꿈이 두 번 들어가는 문제가 있었어요. |
| 화면 한글 | `sys.setdefaultencoding` | 서버 콘솔에서 한글이 깨져서 표준 출력을 UTF-8로 감쌌어요. |

## 나눗셈이 달라진 문제

파이썬 2에서는 정수끼리 나누면 몫만 남아요. 그래서 예전 배치는 30일 판매 합을 30으로 나눌 때 소수점이 자동으로 버려졌어요. 파이썬 3에서는 `/`가 소수점까지 계산해요.

9월 한 달 치 자료를 파이썬 2와 3으로 돌려 비교해 보니 이천, 부산, 제주 모두 발주 수량이 0~3개씩 달라졌어요. 구매팀장님께 여쭤보니 이천 리포트는 담당자들이 매일 보는 숫자라 예전과 같아야 한다고 하셨어요. 그래서 이천만 `//`(몫 나눗셈)로 바꿨어요. 부산과 제주는 비교할 예전 리포트가 없어서 소수점을 그대로 두기로 했어요. 나중에 통일하기로 했고 INV-63에 적어 뒀어요.
