# 번외 2 예시 파일

1일차 번외 2(지식베이스, LLM 위키, 옵시디언) 실습에서 옆에 띄워 두고 보는 예시예요. 발표 화면의 "예시" 문장과 "끝났을 때 모습" 장면이 모두 여기에 파일로 있어요.

> **주의** 이 폴더는 내 레거시 폴더(`~/legacy/<내 레거시>`)에 복사하지 않아요. Claude가 kb를 만들 때 견본까지 읽어서 내 kb에 섞여요. 탐색기나 VS Code로 따로 열어서 봐요.

| 파일 | 무엇 | 언제 |
| --- | --- | --- |
| [`prompts.md`](prompts.md) | 실습 셋과 "더 해 보기"에서 보낼 문장의 예시, 레거시마다 바꿀 곳(실습 2의 질문, 실습 3의 새 소식) | 실습 내내 |
| [`결과-견본/1-kb-세-쪽.md`](결과-견본/1-kb-세-쪽.md) | 실습 1 문장을 회의실 예약과 재고·발주에 보낸 실제 답 | 실습 1 |
| [`결과-견본/kb-room-java/`](결과-견본/kb-room-java/) | 그때 회의실 예약에 생긴 kb 원문(목차와 세 쪽) | 실습 1 |
| [`결과-견본/kb-inventory-py/`](결과-견본/kb-inventory-py/) | 그때 재고·발주에 생긴 kb 원문(목차와 세 쪽) | 실습 1 |
| [`결과-견본/2-같은-질문-두-번-room-java.md`](결과-견본/2-같은-질문-두-번-room-java.md) | "R05는 왜 7시부터?"를 코드만 보고 한 번, kb를 읽고 한 번 물은 실제 답 두 개 | 실습 2 |
| [`결과-견본/3-새-소식-넣기.md`](결과-견본/3-새-소식-넣기.md) | 지어낸 메일 한 통을 kb에 넣은 실제 답과 `log.md`에 쌓인 줄(회의실 예약, 재고·발주) | 실습 3 |

견본은 강사가 2026년 10월에 Claude Code로 실제로 돌려서 나온 그대로예요. Claude가 한 말과 만든 파일은 고치지 않았어요. 같은 문장을 보내도 답은 매번 조금씩 달라요. 쪽 이름이나 표 모양이 견본과 달라도, 바뀐 값마다 이유와 출처 파일이 적혀 있으면 잘 된 거예요.

회의실 예약(`room-java`)이나 재고·발주(`inventory-py`)를 맡았다면 견본을 먼저 보지 말고 직접 해 본 뒤에 견줘 봐요.
