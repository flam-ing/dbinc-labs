## 어느 문서가 최신인가요

1. **코드**가 가장 최신이에요.
2. **이슈 댓글, 시설관리 페이지, 운영 메모, 규정 댓글**이 그다음이에요. PRD 8절이 그렇게 안내해요(`wiki/room-booking-prd-2010.md:108`).
3. `wiki/cleaning-contract.md:13`은 총무팀 규정 페이지보다 자기가 맞다고 적어요.
4. `wiki/employee-number.md`는 2012년 이후 임원에 대해 틀려요(`issues/ROOM-31.md:24`).
5. **README, PRD 1~7절, 규정 본문, `Const.java`** 에는 예전 값이 남아 있어요.
