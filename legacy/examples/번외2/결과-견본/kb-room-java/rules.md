# 지금 맞는 규칙

[← 목차](README.md)

코드(`src/com/nuri/room/`)에 들어 있는 값이 지금 규칙이에요. 문서에 다른 값이 있으면 아래 "예전 값"과 "바뀐 이유"를 보세요.

- 코드는 숫자를 그 자리에 직접 써요(`180`, `14`, `700`, `+2`, `"10001"`). `Const.java`의 값은 아무 데서도 쓰지 않아요.
- RSV와 CHG는 같은 검사를 따로따로 갖고 있어요(`doChange`는 `doReserve`를 복사한 것). 규칙을 고칠 때는 두 곳을 같이 고쳐야 해요. 줄 번호는 `RSV / CHG` 순서로 적었어요.

## 4. 입력 형식 (코드 기준)

| 명령 | 칸 순서 | 코드 |
| --- | --- | --- |
| RSV | 명령, 요청시각, 사번, 이름, 회의실, 날짜, 시작, 종료, 인원, 제목 | `RsvManager.java:70-85` |
