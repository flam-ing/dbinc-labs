# RoomBatch 지식베이스

총무팀 회의실 예약 배치(RoomBatch)를 맡은 사람이 같이 보는 문서예요. 코드, `wiki/`, `issues/`를 읽고 정리했어요.

※ 교육용 가상 자료예요. 회사, 사람, 규정은 모두 지어낸 것이에요.

## 먼저 알아 둘 것

- **코드가 가장 최신이에요.** README, `wiki/room-booking-prd-2010.md`(2010-01 기획), `wiki/booking-rules.md` 본문, `Const.java`에는 예전 값이 남아 있어요.
- **예약번호는 매일 밤 다시 매겨져요.** 앞쪽 RSV 하나의 성공/실패가 뒤집히면 뒤 번호가 모두 밀리고, 이미 쌓인 CXL/CHG가 다른 사람의 예약을 가리켜요. 검사 규칙을 바꾸기 전에 꼭 [위험한 곳](risks.md) 1번을 읽어 주세요.
- **버그처럼 보여도 일부러 둔 것이 있어요.** 고치기 전에 [위키·이슈 요약](sources.md)에서 해당 이슈를 찾아 보세요.

## 출처 표기

- 근거는 `파일:줄`로 달았어요. 경로는 저장소 루트 기준이에요(예: `src/com/nuri/room/RsvManager.java:107`).
- 이 지식베이스는 파일을 읽어서만 만들었어요. 프로그램은 돌리지 않았어요. 실행 결과가 필요한 내용은 `인수인계-보고서.md`의 실행 결과를 인용하고 그렇다고 적었어요.
- 원본(`wiki/`, `issues/`, `src/`, README)은 고치지 않았어요. 원본과 이 문서가 다르면 코드를 먼저 확인하고 이 문서를 고쳐 주세요.
