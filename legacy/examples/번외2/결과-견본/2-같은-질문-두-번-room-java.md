# 실습 2 결과 견본: 같은 질문 두 번(room-java)

> 강사가 2026년 10월에 학생 자리와 같은 폴더(5교시를 마친 레거시 폴더)에서 Claude Code로 실제로 보내서 받은 답이에요. Claude가 한 말은 고치지 않았어요. 같은 문장을 보내도 답은 매번 조금씩 달라요.

실습 1을 마친 폴더에서 새 세션을 열고, 같은 세션에서 두 번 물었어요. 첫 번째 답은 "이유를 알 수 없어요"로 끝나고, 두 번째 답은 kb를 근거로 이유를 말해요.

## 첫 번째: 코드만 보고

- 모드: Manual
- 걸린 시간: 19초, Claude와 도구가 4번 주고받았어요.

보낸 말:

```text
wiki/, issues/, docs/kb/는 열지 말고 코드와 README만 보고 답해 줘. 화상회의실(R05)만 왜 아침 7시부터 예약돼요? 출처와 함께 알려 줘.
```

Claude의 답(원문 그대로):

````markdown
코드와 README만으로는 **이유를 알 수 없어요.** 코드에는 R05만 7시부터 예약된다는 동작만 있고, 왜 그런지는 어디에도 적혀 있지 않아요.

**동작 (코드에 있음)**
- `src/com/nuri/room/RsvManager.java:100-101` (`doReserve`): 기본 운영 시작 시각이 `iOpen = 900`인데, `if (strRoom.equals("R05")) iOpen = 700;`으로 R05만 07:00으로 앞당겨요. 이 줄에는 주석이 없어요.
- `src/com/nuri/room/RsvManager.java:245-246` (`doChange`): 같은 코드가 한 번 더 있어요. 예약 변경에도 똑같이 적용돼요.
- `src/com/nuri/room/RoomInfo.java:16`: R05는 `{"R05", "화상회의실", "6", "9"}`예요. 정원 6명에 9층이고, 운영 시간 정보는 없어요.
- 클래스 머리 주석의 변경 이력에도 이 규칙 이야기는 없어요.

**README**
- README "규칙" 절에는 운영 시간 이야기가 아예 없어요. 그래서 7시 예외도 없어요. 다른 규칙도 2시간 제한, 청소 시간 12:30~13:30처럼 지금 코드와 다른 예전 내용이 남아 있어요. README는 근거로 쓰기 어려워요.

**이유를 확인할 수 있는 곳**
CLAUDE.md에는 이 규칙의 근거가 `wiki/cleaning-contract.md` 4절이라고 적혀 있어요. 하지만 wiki/는 열지 말라고 하셔서 그 문서는 읽지 않았어요. 실제 이유를 확인하려면 그 문서를 열어도 될지 알려 주세요. git 이력에서 이 줄이 언제 들어왔는지 찾아보는 방법도 있어요.
````

## 두 번째: 같은 세션에서 kb를 읽고

- 모드: Manual
- 걸린 시간: 11초, Claude와 도구가 3번 주고받았어요.

보낸 말:

```text
이번에는 docs/kb/를 읽고 다시 답해 줘. 앞 답과 무엇이 달라졌는지 한 줄로 알려 줘.
```

Claude의 답(원문 그대로):

````markdown
**답:** LA 지사(가상)와 정기 화상 회의를 하기 때문이에요. 서울 아침 7시가 LA로는 전날 오후예요. 두 곳의 근무 시간이 겹치는 때가 이때뿐이라서 화상회의실(R05)만 7시부터 열어요. 시설관리팀이 06:50에 장비를 켜 둬요.

**출처**
- 이유: `docs/kb/rules.md:42`. 이 문서는 원래 출처로 `wiki/cleaning-contract.md:25`(4절, 시설관리 배정호, 2010-11)를 들어요(`docs/kb/rules.md:43`, `docs/kb/sources.md:20`). 이번에는 wiki 원문을 열지 않고 KB 문서만 봤어요. 그래서 원문에 실제로 그렇게 적혀 있는지는 확인하지 않았어요.
- 동작: `src/com/nuri/room/RsvManager.java:100-102`(예약), `:245-247`(변경). 이 코드에서 R05의 여는 시각이 `700`이에요.
- 예전 규칙: 원래는 모든 회의실이 9시에 열었어요. `Const.java:12`의 `OPEN_TIME=900`에 그 값이 남아 있지만 실제로 쓰이지는 않아요.

**앞 답과 달라진 점:** 앞에서는 코드와 README에 이유가 없어서 "알 수 없다"고 답했어요. 이번에는 KB에서 이유(LA 지사와 화상 회의 시간을 맞추려고)와 그 원래 출처를 찾았어요.
````
