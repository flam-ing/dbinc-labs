# 5교시 예시 파일

1일차 5교시(레거시 분석) 실습에서 옆에 띄워 두고 보는 예시예요. 발표 화면의 "예시" 문장과 "끝나면 이렇게" 장면이 모두 여기에 파일로 있어요.

> **주의** 이 폴더는 내 레거시 폴더(`~/legacy/<내 레거시>`)에 복사하지 않아요. Claude가 `/init`이나 분석을 할 때 견본까지 읽어서 내 답에 섞여요. 탐색기나 VS Code로 따로 열어서 봐요.

견본은 강사가 2026년 10월에 Claude Code로 실제로 돌려서 나온 그대로예요. Claude가 한 말과 만든 파일은 고치지 않았어요. 같은 문장을 보내도 답은 매번 조금씩 달라요. 내 결과가 견본과 똑같을 필요는 없고, 비슷한 모양이면 잘 된 거예요.

견본과 같은 레거시를 맡았다면 견본을 먼저 보지 말고 직접 해 본 뒤에 견줘 봐요.
