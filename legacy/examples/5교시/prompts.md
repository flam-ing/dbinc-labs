# 5교시 예시 프롬프트 모음

1일차 5교시(레거시 분석) 실습에서 Code 탭에 보낼 문장의 **예시**예요. 강사가 회의실 예약(`room-java`)으로 실제로 보내 보고 통한 문장이에요. 그대로 써도 되지만, `<꺾쇠>` 안은 내 레거시에 맞게 바꿔요. 같은 레거시를 맡은 사람끼리 서로 다르게 물어보면 끝에 비교할 거리가 많아져요.

모든 실습은 내 레거시 폴더(`~/legacy/<내 레거시>`)를 Code 탭에서 연 세션 하나에서 차례로 해요. 이 `examples` 폴더는 내 레거시 폴더에 복사하지 않아요. 복사하면 Claude가 견본을 읽어서 내 답에 섞여요.

## 실습 1. 열고, 묻고, 돌려 보기 (모드: Manual)

첫 질문이에요. "아직 아무것도 고치지 마"는 꼭 남겨요.

```text
이 폴더가 어떤 시스템인지 파악해서 알려 줘. 무엇을 하는 프로그램이고, 입력과 출력은 무엇이고, <문서와 코드가 다른 곳>이 있는지 봐 줘. 아직 아무것도 고치지 마.
```

- 바꿀 곳: 더 궁금한 것을 한두 개 넣어요. 예: "누가 언제 돌리는 프로그램인지", "가장 위험해 보이는 곳".

받은 그대로 커밋해요. 명령 승인 카드가 뜨면 명령을 읽고 눌러요.

```text
이 폴더를 git 저장소로 만들고, 받은 그대로 커밋해 줘.
```

- 강사가 실제로 보냈을 때 Claude는 커밋 메시지를 영어(`Initial commit: import project as received`)로 지었어요. 한국어가 좋으면 뒤에 `커밋 메시지는 "받은 그대로"로 해 줘.`를 붙여요.

원본을 한 번 돌려 봐요. 그 언어의 런타임이 PC에 없으면 건너뛰어요.

```text
원본 프로그램을 <data/의 입력>으로 한 번 실행해서 결과를 보여 줘. 실행 방법도 알려 줘. 코드는 고치지 마.
```

- 바꿀 곳: 입력 파일 이름. 모르면 `data/의 입력`을 그대로 둬요. Claude가 위키의 기획서에서 찾아요.

더 해 보기(입력 파일 바꿔 보기):

- `room-java`를 맡았다면 이 폴더의 [`room-java-my-requests.txt`](room-java-my-requests.txt)를 내 레거시 폴더의 `data/`에 복사하고 "data/my-requests.txt로 원본을 돌려 줘"라고 해요. 줄마다 정원, 청소 시간, 임원 사번, 변경을 시험해요. 강사가 돌린 결과는 [`room-java-my-requests-결과.txt`](room-java-my-requests-결과.txt)예요.
- 다른 레거시는 Claude에게 입력 파일을 만들게 해요.

```text
data/의 <입력 파일>을 본떠서 <시험해 보고 싶은 규칙>을 시험하는 입력 파일을 하나 만들어서 원본을 돌려 줘. 원본 코드는 고치지 마.
```

- 강사가 inventory-py에 "data/의 stock.csv를 본떠서 재고가 0인 품목과 쓰지 않는 품목(use_yn이 N)을 시험하는 입력 파일을 하나 만들어서 원본을 돌려 줘. 원본 코드는 고치지 마."라고 보냈더니 46초 만에 시험 파일 하나를 만들어 돌리고, 부산 창고만 쓰지 않는 품목을 발주에 넣는다는 것을 표로 보여 줬어요. 견본은 [`결과-견본/1-더-해-보기-입력-파일-inventory-py.md`](결과-견본/1-더-해-보기-입력-파일-inventory-py.md)예요.

## 따라 하기. 잘 묻는 법으로 하나 묻기 (모드: Manual)

네 가지를 넣어요. **범위**(볼 파일과 볼 곳), **근거**(파일과 줄), **아직 고치지 마**, **확인 방법**(원본을 돌려서 맞는지).

```text
<RsvManager.java>의 <예약 검사>만 봐 줘. 규칙마다 파일과 줄을 대 줘. 아직 고치지 마. 원본을 돌려서 맞는지 확인해 줘. 답은 한국어로 해 줘.
```

- 강사가 처음에 "답은 한국어로 해 줘."를 빼고 보냈더니 답이 영어로 왔어요. 그래서 붙였어요.
- 다 되면 입력창 옆 사용량 링을 눌러 맥락이 얼마나 찼는지 보고, `/compact`를 한 번 보내 봐요.

레거시마다 바꿀 곳의 예예요. 첫 질문의 답에서 다른 파일을 골라도 돼요.

| 레거시 | 파일 | 볼 곳 |
| --- | --- | --- |
| settle-cs | `src/DailySettle.cs` | 주문 읽기 반복문(마감 시간, 취소 처리) |
| claim-cs | `src/ClaimJudge.cs` | 심사 규칙(단종, 중복, 청구 기한) |
| room-java | `src/com/nuri/room/RsvManager.java` | 예약 검사 |
| points-java | `src/com/nuri/mall/point/PointService.java` | 적립률 계산 |

## 실습 2. CLAUDE.md 만들기 (모드: Accept edits)

```text
/init CLAUDE.md는 한국어로 써 줘.
```

Code 탭에서 `/init`이 그대로 되지 않으면 문장으로 부탁해요. 강사가 문장으로 해 봤을 때도 87줄짜리 CLAUDE.md가 나오고 커밋까지 됐어요.

```text
이 저장소를 살펴보고 CLAUDE.md를 만들어 줘. 한국어로 써 줘. 다 쓰면 몇 줄인지 알려 주고 커밋해 줘.
```

다 되면 읽어 보고 고쳐요.

```text
CLAUDE.md의 <틀린 줄>은 틀렸어. <맞는 내용>으로 고쳐 줘. 200줄이 넘으면 줄여 줘.
```

- 새로 만든 CLAUDE.md는 다음 세션부터 처음에 읽어요. 지금 세션에는 바로 들어가지 않아요.

## 따라 하기. "왜?" 하나 묻기 (모드: 바꾸지 않아도 돼요)

코드만 보면 이유를 모르는 값을 하나 골라 물어요. "근거가 없으면 모른다고 해 줘"를 넣으면 Claude가 찾은 근거와 못 찾은 것을 나눠서 말해요.

```text
<사번이 9로 시작하면 왜 3시간 제한이 없어요?> 답할 때 근거가 된 파일 이름과 줄(또는 절)을 같이 적어 줘. 근거가 없으면 모른다고 해 줘. 아직 아무것도 고치지 마.
```

레거시마다 질문의 예예요. 답은 그 폴더의 `wiki/`와 `issues/`에 있어요. 강사가 claim-cs 질문으로 바꿔 보냈을 때도 27초 만에 근거 파일과 줄, "자료에 없어서 모르는 것"을 나눠 답했어요([`결과-견본/4-왜-질문-claim-cs.md`](결과-견본/4-왜-질문-claim-cs.md)).

| 레거시 | 질문 예 |
| --- | --- |
| settle-cs | 33줄은 왜 한국어(ko-KR)로 고정해요? 지워도 돼요? |
| claim-cs | 지급 예정액 500만 원 이상이면 왜 사람 심사예요? 위키에는 300만 원인데요. |
| room-java | 사번이 9로 시작하면 왜 3시간 제한이 없어요? / 정원이 20명인데 왜 22명까지 받아요? |
| points-java | 소멸일이 왜 "적립일로부터 1년"이 아니라 "1년 뒤 같은 달 말일"이에요? |
| payroll-java | 규정 계산과 10원 다른 것을 알면서 왜 안 고쳐요? |
| inventory-py | 안전재고 계수가 코드에는 1.65, config.py에는 1.5예요. 어느 쪽이 맞고 왜요? |
| expense-py | 해외 영수증은 왜 출발일 환율로 바꿔요? |
| notice-js | 9시 전과 18시 뒤에는 왜 안 보내고, 긴급만 예외예요? |
| triage-js | 화면과 아침 리포트(배치)의 결과가 다르면 어느 쪽이 맞아요? |
| library-php | 연체료를 왜 현금으로 받지 않고 donation.csv에 적어요? |

## 실습 3. 인수인계 보고서 (모드: Plan, 그다음 Accept edits)

먼저 Plan으로 바꾸고 계획을 받아요.

```text
이 시스템을 인수인계 받는 <사람>을 위한 보고서를 쓰려고 해. 필요하면 서브에이전트로 나눠 읽고, 시스템 한 장 요약, 위험한 곳, 코드와 문서가 어긋난 곳, 위키·이슈에만 있는 이유, 6교시에 고칠 후보를 담은 계획을 세워 줘. 아직 파일은 만들지 마.
```

- 바꿀 곳: 읽을 사람(다음 담당자, 팀장)과 담을 내용.

계획이 괜찮으면 승인하고 Accept edits로 바꿔서 쓰게 해요.

```text
좋아, 그 계획대로 <인수인계-보고서.md> 한 파일로 써 줘. 원본 코드는 고치지 마.
```

- HTML 한 장이 좋으면 `인수인계-보고서.html`로 바꿔 말해요.
- 다 되면 "보고서를 커밋해 줘"라고 해요. "git 로그를 보여 줘"라고 하면 커밋이 셋 보여요(받은 그대로, CLAUDE.md, 보고서).

## 끝났을 때 모습

강사가 실제로 돌려서 나온 답과 파일을 [`결과-견본/`](결과-견본/)에 두었어요. Claude가 한 말과 만든 파일은 고치지 않았어요. 내 결과가 이 견본과 똑같을 필요는 없어요. 비슷한 모양이면 잘 된 거예요.
