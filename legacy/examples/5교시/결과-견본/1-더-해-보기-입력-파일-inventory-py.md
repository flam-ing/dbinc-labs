# 실습 1 더 해 보기 견본: 내 입력 파일로 돌려 보기 (inventory-py)

room-java가 아닌 레거시에서 "더 해 보기"를 할 때 쓰는 예시 문장을 inventory-py에 보낸 결과예요. 꺾쇠 두 칸(입력 파일, 시험할 규칙)만 바꿨어요. 46초 걸렸어요.

보낸 말:

```text
data/의 stock.csv를 본떠서 재고가 0인 품목과 쓰지 않는 품목(use_yn이 N)을 시험하는 입력 파일을 하나 만들어서 원본을 돌려 줘. 원본 코드는 고치지 마.
```

강사는 명령 실행을 미리 허락하고 돌렸어요. 학생 화면에서는 파일을 만들 때와 명령을 실행할 때마다 승인 카드가 떠요. 명령을 읽고 Allow once를 눌러요.

Claude가 만든 입력 파일 `data/stock_zero_unused.csv`(원문 그대로예요):

```csv
wh,sku,item_name,on_hand,use_yn
W01,D-4001,물티슈 100매,0,Y
W01,B-2009,수정테이프 5mm,0,N
W01,A-1002,A3 복사용지 80g 250매,15,N
W01,B-2002,"형광펜 5색, 세트",9,n
W02,D-4001,물티슈 100매,0,Y
W02,B-2009,수정테이프 5mm,0,N
W02,A-1002,A3 복사용지 80g 250매,15,N
W02,B-2002,"형광펜 5색, 세트",9,n
W03,D-4001,물티슈 100매,0,Y
W03,D-4002,핸드타월 5000매,0,N
W03,A-1002,A3 복사용지 80g 250매,15,N
W03,B-2002,"형광펜 5색, 세트",9,n
```

Claude가 한 말(원문 그대로예요):

````markdown
시험 파일 `data/stock_zero_unused.csv`를 만들어 원본을 그대로 돌렸어요. 원본 코드는 고치지 않았어요. 정상 종료(exit 0)했지만, **부산(W02)에서 쓰지 않는 품목이 발주에 들어갔어요.**

**시험 파일 구성.** 창고 W01·W02·W03마다 같은 네 가지 경우를 넣었어요.
- 재고 0, 사용(Y): D-4001
- 재고 0, 미사용(N): B-2009 (제주는 B-2009 공급 정보가 없어서 D-4002)
- 재고 15, 미사용(N): A-1002
- 재고 9, 소문자 `n`: B-2002

**실행 명령**
```
python3 src/reorder.py data/stock_zero_unused.csv data/sales.csv data/suppliers.csv 2015-11-08 out
```
판매 자료가 2015-11-07까지 있어서 기준일은 2015-11-08로 했어요. 출력 폴더는 `.gitignore`에 들어 있는 `out/`이에요.

**결과**

| 경우 | 이천 W01 | 부산 W02 | 제주 W03 |
|---|---|---|---|
| 재고 0, 사용 | 40개 발주 | 40개 발주 | 40개 발주 |
| 재고 0, 미사용 | 제외 | **30개 발주** | 제외 |
| 미사용, 재고 있음 | 제외 | **리포트에 나옴(발주 없음)** | 제외 |
| 소문자 `n` | 제외 | **리포트에 나옴(발주 없음)** | 제외 |

- **부산은 `use_yn`을 보지 않아요.** `src/reorder.py:89`에 "단종 제외"라는 주석만 있고, 이천·제주에 있는 `if row['use_yn'] == 'N'` 검사가 빠져 있어요. 그래서 미사용 품목 B-2009가 수정테이프 30개, 84,000원으로 발주 파일에 들어갔어요. 요약 줄의 "단종 6"도 부산 3건이 빠진 숫자예요.
- **재고 0인 품목은 세 창고 모두 발주돼요.** 판매가 없거나 적어도 최소 주문 수량(moq)인 40개로 주문해요.
- **이천은 일평균이 0으로 떨어져요.** D-4001은 30일 동안 17개가 팔렸는데, 이천만 `total // 30`으로 소수점을 버려서 일평균이 0이 돼요. 부산·제주처럼 나누면 0.57이에요. 안전재고와 발주점도 0이 되고, 결국 최소 주문 수량대로 발주됐어요.
- 소문자 `n`은 읽을 때 대문자로 바꿔서 이천·제주에서는 제대로 빠졌어요.

**발주 파일** `out/PO_20151108.csv`에는 4건, 150개, 360,000원이 담겼어요. 그중 부산 B-2009는 들어가면 안 되는 줄이에요.

새로 생긴 건 시험 파일 하나뿐이고 아직 커밋하지 않았어요. 부산 누락을 고칠지는 정해 주세요.
````
