## 2. "9로 시작하면 임원"인 근거

- `wiki/employee-number.md` 1절 표(17줄): 첫 자리가 `9`면 임원이에요.
- 같은 파일 2절(23줄): 임원이 되면 9로 시작하는 새 사번을 받아요. 회의실 예약 같은 다른 시스템은 사번 첫 자리가 9인지로 임원을 알아봐요.

## 3. "임원은 시간 제한 없음"인 근거

- `wiki/booking-rules.md` 2절(27줄): "임원 회의는 시간 제한을 두지 않아요. 임원인지는 인사팀 사번 체계를 따라요."
- `wiki/room-booking-prd-2010.md`, "예약할 때 보는 것" 5번(42줄): "임원(사번 첫 자리가 9)은 시간 제한이 없어요."
- `README.md:31`에도 같은 내용이 있어요.
- 시간 상한이 2시간에서 3시간으로 바뀐 건 `wiki/booking-rules.md` 댓글(53·57줄, 2010-05-17/18)에 나와요. 임원 예외는 그때 바뀌지 않았어요.

## 4. 근거를 못 찾은 것

**임원에게 왜 시간 제한을 두지 않기로 했는지, 그 정책상 이유는 몰라요.** 규정, 기획서, README 모두 "제한이 없다"고만 적혀 있어요. 이유가 적힌 곳은 없어요. 2주 기한(booking-rules 3절)이나 정원 +2(4절)는 이유가 적혀 있는 것과 달라요. 이유를 알려면 총무팀(규정 작성자 송미경)에게 물어봐야 해요.
