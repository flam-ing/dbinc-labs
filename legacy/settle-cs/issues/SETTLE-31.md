## 설명

배치서버 1호기를 2024년 하반기에 바꿔요. 새 서버에는 .NET Framework 2.0을 깔 수 없어요. 사내 배치 표준이 Java 17이라서 DailySettle을 Java로 옮기기로 했어요.

## 완료 기준

1. 같은 입력이면 출력(정산표, LOW STOCK 목록, INSERT 문)이 글자 하나까지 같아야 해요. DBA가 INSERT 문을 그대로 실행하고, 정산팀 매크로가 정산표를 글자 위치로 읽어요(SETTLE-11).
2. 종료 코드(0, 1, 2, 9)도 같아야 해요. 스케줄러가 0이 아니면 정산팀에 메일을 보내요.
3. 수수료율(SETTLE-14)과 9호점(SETTLE-16) 같은 동작 변경은 옮긴 뒤에 따로 해요. 옮기면서 같이 고치면 결과가 달라졌을 때 어느 쪽 때문인지 알 수 없어요.
