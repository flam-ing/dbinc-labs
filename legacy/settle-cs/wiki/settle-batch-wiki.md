= 일일 정산 배치 (DailySettle) =
최종 수정: 2008-02-14 박 대리   [[분류:정산]] [[분류:배치]]
※ 교육용 가상 자료입니다. 회사·매장·사람은 모두 가상입니다.

== 개요 ==
매장별 하루 매출을 모아 정산팀에 보내는 배치. 매일 아침 6시.
결과물 2가지
 1) 정산표 → 정산팀 메일
 2) ERP 업로드용 INSERT 문 (출력 맨 아래) → DBA가 아침에 실행

== 실행 ==
서버: 배치서버 1호기  D:\batch\settle\
작업 스케줄러 이름 DAILY_SETTLE
명령 예) DailySettle.exe D:\pos\orders_20080213.csv D:\pos\products.csv 2008-02-13
* 날짜 인자는 반드시 yyyy-MM-dd !!! 2008/02/13 으로 주면 표가 텅 빈 채로 나옴 (에러도 안 남)

== 입력 파일 ==
주문 : POS가 밤에 떨구는 CSV. 열 순서 바꾸면 안 됨
  order_id,order_dt,store,pay,sku,qty,unit_price,status,memo
  status  OK=판매 / RTN=반품 / CXL=취소(취소는 정산 안 함)
  pay     CARD / CASH / POINT
상품 : 물류팀이 주는 products.csv (sku,name,stock)  stock = 전날 마감 재고

== 정산 규칙 ==
* 마감 시각: 22시 이후 주문은 다음날 매출로 (택배사 마감 때문)
* 카드 수수료 2.5% (2006년 카드사 계약)
* 포인트는 수수료 없음. 포인트로 산 것도 매출에 들어감
* 반품은 "반품 처리한 날" 매출에서 뺌. 원래 주문 날짜랑 상관없음
* 메모에 TEST 들어간 주문 = 매장 직원 교육용. 정산에서 뺌
* 재고 5개 미만 → LOW STOCK 에 나옴 → 물류팀이 보고 발주

새 매장 생기면 소스에 추가해야 함 (설정 파일 아님!!)
