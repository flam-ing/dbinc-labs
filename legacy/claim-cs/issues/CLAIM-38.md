# CLAIM-38 근골격계(M 코드) 지급액이 심사 화면 계산과 1원 달라요

## 설명

청구 금액 452,315원, 자기부담금 10,000원, 진단 M51인 실손 청구예요. 심사 화면은 지급액을 309,621원으로 보여 주는데 배치 결과는 309,620원이에요. 9월에 M 코드 청구 가운데 이런 건이 11건 있었어요.

그리고 M 코드 건만 지급액이 1원 단위로 나와요. 다른 실손 건은 10원 미만을 버려서 언제나 10원 단위예요.

검증용 자료의 C1303007이 같은 경우예요.

## 댓글

**이서연 · 2013-09-11**

원인을 찾았어요. 8월에 M 코드 분기를 넣을 때 `Math.Round`를 썼어요. C#의 `Math.Round`는 딱 .5일 때 짝수 쪽으로 반올림해요. 그래서 309,620.5가 309,620이 돼요. 심사 화면(VB6)은 엑셀처럼 .5를 올려서 309,621이에요. 또 이 분기만 10원 미만을 버리지 않아요. 약관대로라면 309,620원(10원 미만 버림)이 맞아요. 이번 건은 우연히 같지만 다른 금액에서는 약관보다 몇 원씩, 많게는 10원까지 더 나가요. 검증용 자료의 C1303039는 약관대로면 121,410원인데 배치는 121,419원이에요.

**박지훈 · 2013-09-13**

9월 지급분이 이미 나갔고 재보험 정산도 배치 값으로 했어요. 지금 고치면 같은 진단인데 달마다 금액이 달라져요. 고객에게 덜 주는 방향으로 바뀌는 것이라 민원도 걱정돼요. 상품팀이 약관 별표를 다시 고칠 때 같이 정하기로 하고, 그때까지는 그대로 둬요.

**이서연 · 2013-09-13**

그대로 두고 닫아요. 심사 화면에 "지급액은 배치 값이 기준"이라는 안내를 넣었어요.
