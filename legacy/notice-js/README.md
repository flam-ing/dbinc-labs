# 누리 공지봇

총무팀 공지를 직원들에게 메일로 보내 주는 봇이에요. 총무팀 서버의 크론이 10분마다 실행해요.

## 실행

```
node bot.js notices.json employees.json 2016-04-20T09:00
```

결과는 `/home/notice/outbox` 폴더에 쌓여요. 발송 게이트웨이가 이 폴더를 읽어서 실제로 보내요.

## 설정

설정은 `config.js`에 있어요. 운영 서버의 `config.js`는 서버에서 직접 고쳐서 쓰니까 배포할 때 덮어쓰지 마세요.

## 채널

- 메일: 기본 채널이에요. 직원 정보에 채널이 없으면 메일로 보내요.
- 쪽지: 2019년 3월에 추가했어요.
- 문자: 2019년 3월에 추가했어요. 긴급 공지만 보내요.

## 공휴일 (2019.03 추가)

휴일 파일을 같이 넘겨야 해요. 휴일 파일은 총무팀이 해마다 12월에 만들어 줘요. 자세한 규칙은 위키 "공지봇 발송 규칙"을 보세요.
