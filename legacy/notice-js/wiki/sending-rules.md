# 공지봇 발송 규칙

| 항목 | 내용 |
| --- | --- |
| 공간 | 총무팀 시스템 (GA) |
| 경로 | 총무팀 시스템 / 공지봇 / 발송 규칙 |
| 작성자 | 이서연 |
| 처음 만든 날 | 2019-03-20 |
| 마지막 수정 | 2019-07-15 (이서연) |
| 레이블 | 공지봇, 규칙, 노사협의회 |

> 공지봇이 언제, 어떤 채널로 보내는지 정한 규칙이에요. 규칙이 바뀌면 코드보다 이 페이지를 먼저 고쳐 주세요.

## 1. 업무시간에만 보내요

공지는 평일 9시부터 18시 전까지만 보내요. 18시 정각은 업무시간 밖으로 봐요. 업무시간 밖에 예약된 공지는 다음 영업일 아침 9시에 보내요.

이 규칙은 2019년 7월 노사협의회에서 정한 "근무시간 외 업무 연락 자제 지침"에서 나왔어요. 퇴근한 직원에게 회사 알림이 울리지 않게 하려는 지침이에요. 공지봇도 회사가 보내는 연락이라서 이 지침을 따라요.

## 2. 긴급 공지는 예외예요

긴급 공지는 업무시간과 상관없이 예약한 시각에 바로 보내요. 긴급으로 올릴 수 있는 공지는 아래 네 가지뿐이에요.

- 재난이나 건물 안전 문제
- 보안 사고
- 전산 전체 장애나 정전
- 그 밖에 총무팀장이 승인한 일

긴급은 총무팀장 승인을 받아야 올릴 수 있어요. 제목에 `[긴급]`을 직접 쓰지 마세요. 공지봇이 메일 제목에 알아서 붙여요.

## 3. 공휴일과 주말에는 보내지 않아요

공휴일과 주말에는 메일도 쪽지도 보내지 않아요. 다음 영업일 아침 9시에 보내요. 공휴일은 총무팀이 만드는 휴일 파일을 따라요("휴일 파일 관리" 페이지).

## 4. 문자는 긴급 공지에만 써요

문자 비용은 총무팀 예산에서 나가요. 한 달 한도는 30만 원이에요. 2019년 3월에 건강검진 안내(일반 공지)를 전 직원에게 문자로 보냈다가 한 달 예산을 하루 만에 다 썼어요. 그 뒤로 문자는 긴급 공지에만 쓰기로 했어요.

문자 채널을 고른 직원이라도 일반 공지는 문자로 받지 않아요. 메일이나 쪽지로만 받아요.

## 5. 문자는 제목만 45자까지 보내요

문자에는 본문 없이 "[누리상사] 제목"만 보내요. 45자를 넘으면 44자에서 자르고 말줄임표(…)를 붙여요.

통신사 단문 문자는 90바이트까지 보낼 수 있어요. 문자 게이트웨이는 한글 한 글자를 2바이트로 세서 45자가 한도예요. 45자를 넘으면 장문 문자로 바뀌고 요금이 세 배가 돼요.

## 6. 중요 공지

중요도가 `high`인 공지는 메일 제목 앞에 `[중요]`를 붙여요.

## 7. 공지 파일 양식

2019년 3월부터 새 등록 화면은 아래 양식으로 내보내요.

| 칸 | 뜻 | 예 |
| --- | --- | --- |
| id | 공지 번호 | N-2019-012 |
| title | 제목 | 4월 소방 점검 안내 |
| body | 본문 | |
| depts | 받는 부서 목록. 전 직원이면 `["ALL"]` | `["영업1팀", "재무팀"]` |
| sendAt | 예약 시각. 비우면 바로 보내요 | 2019-04-01 10:00 |
| level | `normal`, `high`, `urgent` 중 하나 | normal |

시설팀은 아직 옛 등록 화면(2016년 양식)을 써요. 옛 양식은 `target`(쉼표로 나눈 부서 이름), `send_at`, `urgent`(true, false)를 써요. 공지봇은 두 양식을 다 읽어요. 옛 양식은 "공지 등록 안내(2016)" 페이지를 보세요.

옛 양식의 `target`은 쉼표 뒤에 띄어쓰기를 넣으면 안 돼요. `영업1팀, 재무팀`처럼 쓰면 공지봇이 " 재무팀"(앞에 빈칸이 있는 이름)을 찾다가 못 찾아서 재무팀은 공지를 받지 못해요. 시설팀에 여러 번 안내했어요.
