> 공지봇이 쓰는 휴일 파일을 총무팀이 만드는 방법이에요. 해마다 12월에 이 페이지를 보고 다음 해 파일을 만들어요.

## 언제 만드나요

해마다 12월 셋째 주에 다음 해 휴일 파일을 만들어서 IT팀에 넘겨요. 정부가 임시공휴일을 새로 정하면 그때마다 고쳐서 다시 넘겨요.

## 양식

```
[
  { "date": "2022-03-01", "name": "삼일절" },
  { "date": "2022-03-15", "name": "창립기념일(회사 휴무)" }
]
```

- 날짜는 꼭 네 자리 연도, 두 자리 월, 두 자리 일로 써 주세요. `2022-3-15`처럼 쓰면 안 돼요.
- 2021년에 창립기념일을 `2021-3-15`로 써서 쉬는 날 아침에 쪽지 알림이 나간 일이 있었어요. 공지봇은 날짜를 글자 그대로 맞춰 봐서 형식이 다르면 휴일로 알아보지 못해요.
- 회사 휴무일(3월 15일 창립기념일)도 같이 넣어요.
- 날짜가 아직 안 정해진 임시공휴일은 이름만 적어 두고, 날짜가 정해지면 넣어요.
- 같은 날이 두 번 들어가도 괜찮아요.

## 파일 이름과 경로

파일 이름은 `holidays.json` 하나로 계속 써요. 해마다 이름을 바꾸지 마세요. 2020년 1월에 `holidays-2020.json`으로 이름을 바꿨다가 크론 설정은 옛 이름 그대로여서 하루 종일 공지가 나가지 않았어요(NOTI-49). 공지봇은 휴일 파일을 못 읽어도 오류 없이 끝나서 아무도 몰랐어요.
