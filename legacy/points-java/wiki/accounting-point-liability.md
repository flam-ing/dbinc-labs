# 포인트 부채와 소멸 기준

| 재무회계팀 › 결산 | 박상철 | 2016-08-22 | 2016-08-30 |

※ 교육용 가상 자료예요. 회사, 사람, 회계 처리는 모두 지어낸 것이에요. 실제 회계 기준이나 세법과는 관계가 없어요.

## 1. 포인트는 회사의 빚이에요

회원이 가진 포인트는 언젠가 회사가 돈처럼 내줘야 하는 것이라서, 장부에는 "부채"로 잡아요. 매달 말일에 회원들이 가진 포인트 합계를 부채로 잡고, 그달에 쓰이거나 소멸된 포인트만큼 부채를 줄여요.

## 2. 소멸일은 "1년 뒤 같은 달 말일"이에요

예전에는 적립한 날로부터 정확히 1년 뒤에 소멸했어요. 그러면 날마다 조금씩 소멸이 생겨서, 월말 결산 때 그달 소멸 금액을 맞추느라 매달 이틀씩 걸렸어요.

그래서 2016년 9월 1일부터 같은 달에 적립한 포인트는 모두 같은 날에 소멸하게 바꿨어요. 소멸일은 적립한 달의 1년 뒤 같은 달 말일이에요.

| 적립일 | 소멸일 |
| --- | --- |
| 2016-03-15 | 2017-03-31 |
| 2016-02-29 | 2017-02-28 |
| 2016-12-01 | 2017-12-31 |

- 소멸일 당일까지는 쓸 수 있어요. 소멸일 다음 날에 소멸해요.
- 이 기준은 9월 1일 전에 적립한 포인트에도 똑같이 적용해요. 포인트 배치가 날마다 모든 거래를 처음부터 다시 계산하기 때문에 따로 옮기는 작업은 필요 없었어요.

## 3. 적립 기준 금액은 공급가액이에요

포인트는 부가세를 뺀 공급가액(결제 금액을 1.1로 나눈 금액)을 기준으로 적립해요. 세무 검토(가상)에서, 부가세까지 포함해서 적립하면 매출 할인과 세금 처리가 맞지 않는다는 의견이 있었어요.

## 4. 계산 방식을 바꿀 때

배치가 계산한 숫자로 이미 달마다 결산을 했어요. 계산 방식을 바꾸면 지난달 장부와 숫자가 달라져요. 바꿔야 할 때는 재무회계팀과 적용 날짜를 먼저 정하고, 차액은 그 날짜에 한 번에 조정해요. 날짜를 정하기 전에는 배치의 숫자를 바꾸지 마세요(PNT-52 참고).
