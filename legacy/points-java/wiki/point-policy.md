※ 교육용 가상 자료예요. 회사, 사람, 정책은 모두 지어낸 것이에요.

## 1. 적립

| 등급 | 적립률 | 비고 |
| --- | --- | --- |
| NORMAL(일반) | 결제 금액의 1% | |
| VIP | 결제 금액의 2% | 직전 1년 구매 100만 원 이상 |
| STAFF(임직원) | 적립 없음 | 아래 설명 |

- 등급 코드는 회원 파일에 대문자로 적어요(NORMAL, VIP, STAFF). 등급이 비어 있으면 일반으로 봐요.
- 임직원 회원은 포인트를 적립하지 않아요. 임직원은 이미 임직원 할인(30%)을 받고 있고, 인사팀 복리후생 규정(가상)에 "임직원 할인과 다른 구매 혜택을 겹쳐 받지 않는다"는 조항이 있어요. 행사 상품이나 이벤트로 포인트를 줄 때는 CS팀이 수동으로 넣어 줘요.

## 2. 사용

- 100점부터 쓸 수 있어요.
- 소멸일이 빠른 포인트부터 먼저 빠져요.
- 가진 포인트보다 많이 쓸 수는 없어요.

## 3. 소멸

포인트는 적립일로부터 1년이 지나면 소멸해요.

## 4. 구매 취소

구매를 취소하면 그 구매로 적립한 포인트를 회수해요. 이미 쓴 포인트라면 남은 다른 포인트에서 회수해요.
