# PNT-58 등급이 오른 회원은 지난 구매까지 VIP 적립률로 다시 계산돼요

## 설명

9월에 VIP가 된 회원의 적립 합계가 8월보다 크게 늘었어요. 9월 구매만 2%여야 하는데, 작년 구매까지 2%로 다시 계산된 것 같아요.

## 댓글

**한동욱** · 2016-09-21

맞아요. 배치는 날마다 모든 거래를 처음부터 다시 계산하고, 적립률은 회원 파일에 있는 지금 등급으로 정해요. 그래서 등급이 바뀌면 지난 구매도 새 등급으로 계산돼요. 반대로 VIP에서 일반으로 내려가면 지난 적립이 줄어들어요.

**윤채원(마케팅팀)** · 2016-09-22

올라가는 쪽은 고객에게 유리해서 급하지 않아요. 내려가는 경우는 아직 없었어요(등급 하향은 내년부터 시작).

**한동욱** · 2016-09-22

제대로 고치려면 적립 내역을 저장하는 원장 표가 있어야 해요. 원장 표를 만드는 프로젝트 때 같이 고칠게요. 그때까지 보류해요.
