## 설명

배치 서버를 리눅스로 옮겨요. 코드에 `C:\points\data\`가 박혀 있어서 그대로는 돌지 않아요. 경로를 설정으로 빼 주세요.

## 댓글

**서예진** · 2017-03-03

코드를 보니 인자를 네 개 주면 박힌 경로를 쓰지 않아요. 순서는 거래 CSV, 회원 CSV, 기준일, 알림 폴더예요. 이번에는 코드를 고치지 않고 `run.sh`에서 인자를 넘기게 했어요.

    java -Dfile.encoding=UTF-8 -cp bin com.nuri.mall.point.PointBatch /data/points/transactions.csv /data/points/members.csv $(date +%F) /data/points/outbox

**최승우** · 2017-03-06

새 서버에서 사흘 동안 결과가 옛 서버와 같은 것을 확인했어요. 닫아요. 인자 없이 실행하면 아직도 `C:\points\data\`를 찾으니 주의해요. 기준일을 빼면 서버의 오늘 날짜를 써요.
