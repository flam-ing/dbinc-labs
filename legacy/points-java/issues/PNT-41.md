# PNT-41 창립 기념 주간 마지막 날(10/7) 구매가 두 배로 적립되지 않아요

| 항목 | 내용 |
| --- | --- |
| 키 | PNT-41 |
| 유형 | 버그 |
| 상태 | 해결 안 함 |
| 우선순위 | 높음 |
| 담당 | 한동욱 |
| 보고 | 이수빈(CS팀) |
| 만든 날 | 2016-10-10 |
| 고친 날 | 없음 |

※ 교육용 가상 자료예요.

## 설명

10월 7일에 구매한 고객들이 "두 배 적립이 안 됐다"고 문의하고 있어요. 주말 동안 30건이 넘었어요. 6일까지 구매한 건은 두 배로 들어갔어요.

## 댓글

**한동욱** · 2016-10-10

원인을 찾았어요. 거래 시각("2016-10-07 14:20:00")을 끝 날짜 글자("2016-10-07")와 글자 순서로 비교하고 있어요. 글자로 비교하면 시각이 붙은 쪽이 더 크다고 나와서, 7일 0시부터 들어온 구매가 모두 기간 밖으로 빠졌어요.

**윤채원(마케팅팀)** · 2016-10-11

고객 안내문에는 "7일 23시 59분까지 두 배"라고 나갔어요. 7일 구매 고객에게 차액을 꼭 보상해 주세요.

**이수빈(CS팀)** · 2016-11-02

7일 구매 고객 41명에게 차액을 수동 조정(ADJ)으로 모두 넣었어요.

**한동욱** · 2016-11-03

이제 코드는 고치지 않을게요. 배치는 날마다 모든 거래를 처음부터 다시 계산해요. 지금 코드를 고치면 7일 구매에 두 배가 다시 계산되고, CS팀이 넣은 수동 조정과 겹쳐서 41명이 차액을 두 번 받게 돼요. 다음 프로모션부터는 날짜로 비교하도록 새로 짤게요.

**서예진** · 2017-01-24

설 연휴 프로모션은 날짜로 비교해서 마지막 날도 들어가게 따로 넣었어요. 창립 기념 주간 코드는 위 이유로 그대로 뒀어요. 두 코드가 모양이 달라도 합치지 마세요.
