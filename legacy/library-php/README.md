# 사내 도서관 프로그램

총무팀이 운영하는 사내 도서관의 대출과 반납을 관리하는 프로그램이에요. 2011년 3월에 만들었어요.

## 설치

1. APM_Setup(PHP 5.2)을 설치해요.
2. 이 폴더를 `D:\APM_Setup\htdocs\library\`에 복사해요.
3. 브라우저에서 `http://서버주소/library/list.php`를 열어요.

데이터베이스는 쓰지 않아요. `data` 폴더의 CSV 파일에 저장해요. 책을 한꺼번에 넣을 때는 엑셀로 열어서 고쳐도 돼요.

## 화면

- `list.php`: 도서 목록과 검색
- `loan.php`: 대출
- `return.php`: 반납

## 일괄 처리와 보고

- `php batch.php 요청.csv 2011-04-01`: 총무팀이 모은 신청서를 한꺼번에 처리해요.
- `php overdue_report.php 2011-06-01`: 연체 현황을 찍어요. 매일 아침 8시에 작업 스케줄러가 돌려서 결과를 총무팀 메일로 보내요.

## 규칙

- 대출 기간은 14일이고, 한 사람이 3권까지 빌릴 수 있어요.
- 연체료는 하루 100원이에요.

문의는 총무팀 정민수(내선 2213)에게 해 주세요.
