# 일괄 처리와 크론 운영

> 공간: 총무팀 · 작성자: 정민수 · 만든 날: 2012-02-20
> 마지막 수정: 2021-03-15 한지원 · 라벨: 도서관, 운영, 장애

## 언제 무엇을 돌리나

- 일괄 처리: 총무팀이 종이 신청서와 반납함 책을 모아 엑셀에 적고 CSV로 저장해요. 매주 월요일과 목요일 오전에 `batch.php`로 처리해요.
- 연체 보고: 매일 아침 8시에 크론이 `overdue_report.php`를 돌리고 결과를 총무팀 메일로 보내요.

```
0 8 * * 1-5  php /var/www/library/overdue_report.php $(date +\%F) | mail -s "도서 연체 현황" library@nuri.local
```

## 꼭 지킬 것

- **`loans.csv`의 칸 순서를 바꾸지 않아요.** 총무팀 엑셀 매크로가 매달 말일에 `loans.csv`를 열 번호로 읽어서 연체자 명단을 만들어요. 명단은 인사팀에 참고 자료로 가요.
- 저장소 CSV를 엑셀로 열어서 저장하지 않아요. 엑셀이 저장하면서 날짜 모양을 바꾼 적이 있어요.
- 테스트할 때는 반드시 셋째 인자로 복사본 폴더를 줘요.

## 장애 이력

### 2012-02 테스트하다가 운영 대출 기록을 덮어씀

일괄 처리를 고치고 시험 삼아 돌렸는데, 운영 `data` 폴더의 `loans.csv`가 시험 데이터로 바뀌었어요. 전날 백업으로 되살렸고, 그날 반납한 12건은 손으로 다시 넣었어요. 그 뒤로 `batch.php`와 `overdue_report.php`는 마지막 인자로 데이터 폴더를 받을 수 있어요. 테스트는 복사본 폴더로만 해요.

### 2012-02 크론에서 data 폴더를 못 찾음

크론은 다른 폴더에서 프로그램을 실행해서 `include 'config.php'`가 실패했어요. CLI로 도는 두 파일만 `dirname(__FILE__)`로 고쳤어요. 화면 파일은 웹 서버가 실행해서 그대로 뒀어요.

### 2012-03 요청 파일 이름 오타로 하루 처리가 빠짐

요청 파일 이름을 잘못 적었는데 크론 메일에는 문제가 없다고 왔어요. `batch.php`는 파일을 못 열면 안내 문구를 찍고 끝나는데, 종료 코드가 0이라서 크론은 성공으로 알아요. 그 뒤로 일괄 처리 결과의 "완료, 거부, 오류" 줄을 눈으로 확인해요. 종료 코드를 바꾸면 크론 메일 설정도 같이 바꿔야 해서 그대로 뒀어요.

### 2012-05 data 폴더가 웹에서 열려 있었음

`http://서버주소/library/data/members.csv`로 회원 명단이 보였어요. data 폴더를 웹 폴더 밖으로 옮기고 `config.php`의 경로를 바꿨어요.

### 2021-03 PHP 8로 올림

서버를 바꾸면서 PHP 8로 올렸어요. `get_magic_quotes_gpc()`가 없어져서 막았고, 화면에 Warning이 찍히는 곳은 `@`를 붙여서 가렸어요. 처리 기록 파일(`C:/APM_Setup/logs/library.log`)은 2012년 서버를 옮긴 뒤로 쌓이지 않아요. 아무도 보지 않아서 그대로 뒀어요.
