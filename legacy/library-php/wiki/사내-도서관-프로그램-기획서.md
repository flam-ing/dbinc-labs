# 사내 도서관 프로그램 기획서

> 공간: 총무팀 · 작성자: 정민수 · 만든 날: 2011-02-21
> 마지막 수정: 2012-02-27 정민수 · 라벨: 도서관, 기획서, PRD

사내 도서관 프로그램을 만들기 전에 총무팀장님께 올린 기획서예요. 2011년 2월 계획을 그대로 남겨 뒀어요. 지금 규칙은 "사내 도서관 운영 규칙", 운영 방법은 "일괄 처리와 크론 운영" 페이지를 봐 주세요.

## 목적

지금 사내 도서관은 종이 대출 장부로 운영해요. 누가 어떤 책을 빌렸는지 찾으려면 장부를 처음부터 넘겨 봐야 해요. 반납 예정일을 넘긴 책도 장부를 다 읽기 전에는 알 수 없어요. 2010년 연말 점검에서는 장부에 "대출 중"으로 적힌 책 가운데 9권이 어디 있는지 몰랐어요.

도서관 프로그램은 책, 회원, 대출 기록을 파일로 관리해요. 직원은 어떤 책이 있는지 화면에서 찾아보고, 총무팀은 대출과 반납을 화면이나 신청서로 처리해요. 연체된 책은 매일 아침 보고서로 받아요.

## 쓰는 사람

| 누구 | 무엇을 하나요 |
| --- | --- |
| 직원 | 도서 목록 화면에서 책을 찾아보고, 빌릴 수 있는지 확인해요. |
| 총무팀 도서관 담당 | 대출과 반납 화면을 쓰고, 신청서를 모아서 일괄 처리해요. 연체 보고서를 보고 연락해요. |
| 총무팀장 | 대출 기간, 권수, 연체료 같은 규칙을 정해요. |

## 주요 기능

1. **도서 목록 화면** (`list.php`): 제목, 저자, 분류로 책을 찾아요. 책마다 상태(빌릴 수 있음, 대출 중, 분실)와 반납 예정일이 나와요.
2. **대출 화면** (`loan.php`): 총무팀이 사번과 도서번호를 넣어서 대출해요.
   - 대출 기간은 14일이에요.
   - 한 사람이 3권까지 빌릴 수 있어요.
   - 연체 때문에 대출 정지 중인 사람은 빌릴 수 없어요.
   - 다른 사람이 예약한 책은 예약한 사람만 빌릴 수 있어요. 예약한 사람이 빌리면 예약은 없어져요.
3. **반납 화면** (`return.php`): 도서번호를 넣어서 반납해요.
   - 반납 예정일 다음 날부터 하루 100원씩 연체료를 매겨요. 한 권에 3,000원까지만 받아요.
   - 연체가 세 번 쌓이면 30일 동안 대출을 정지해요.
4. **연장**: 한 번만, 7일 연장할 수 있어요. 다른 사람이 예약한 책과 반납 예정일이 지난 책은 연장할 수 없어요. 연장은 신청서로만 받아요.
5. **분실**: 책을 잃어버리면 분실로 처리하고 정가만큼 변상받아요. 분실된 책은 목록에 "분실"로 나와요.
6. **일괄 처리** (`batch.php`): 총무팀이 종이 신청서와 반납함에 들어온 책을 엑셀에 적고 CSV로 저장해요. 이 파일을 한꺼번에 처리해요. 신청서의 구분은 대출, 반납, 연장, 분실 네 가지예요. 줄마다 처리 결과(완료, 거부, 오류)와 이유를 찍어요.
7. **연체 보고** (`overdue_report.php`): 매일 아침 부서별로 연체한 사람, 책 제목, 반납 예정일, 연체일, 예상 연체료를 찍어요. 연체 60일이 넘은 대출은 "분실 처리 검토"로 따로 모아요. 지금 대출 정지 중인 사람도 보여요.
8. **반납 안내 메일**: 대출할 때 반납 예정일을 메일로 알려 줘요.
9. **관리자 화면** (`admin.php`): 총무팀만 들어가는 화면이에요. 새 책을 등록하고, 퇴사한 회원을 정리해요.
10. 대출, 반납, 연장, 분실을 처리할 때마다 처리 기록 파일에 한 줄씩 남겨요.

## 입력 파일

데이터베이스 서버를 따로 둘 수 없어서 CSV 파일에 저장해요. 총무팀이 엑셀로 열어 볼 수 있는 장점도 있어요. 모든 파일은 첫 줄이 칸 이름이고, 칸은 쉼표로 나눠요.

| 파일 | 내용 | 칸 |
| --- | --- | --- |
| `books.csv` | 도서 목록 | 도서번호, 제목, 저자, 분류, 정가, 상태(IN은 서가에 있음, OUT은 대출 중, LOST는 분실) |
| `members.csv` | 회원 목록 | 사번, 이름, 부서, 직급, 연체 횟수, 대출 정지 끝나는 날 |
| `loans.csv` | 대출 기록 | 대출번호, 도서번호, 사번, 대출일, 반납 예정일, 반납일(아직 안 했으면 빈칸), 연장 횟수, 연체료 |
| `reservations.csv` | 예약 목록 | 도서번호, 사번, 예약한 날 |
| 신청서 CSV | 총무팀이 모은 신청서 | 구분, 사번, 도서번호, 처리일(비우면 기준일), 메모 |

- 책 제목에 쉼표를 넣지 않아요. 쉼표가 있으면 칸이 밀려요.
- 예약은 신청서로 받지 않아요. 총무팀 자리에서 받아서 `reservations.csv`에 바로 적어요.

### 시험 자료 (`data/` 폴더)

2012-02 정민수 추가: 시험하다가 운영 대출 기록을 덮어쓴 일 뒤로 시험용 복사본을 따로 뒀어요. `data/store/`는 운영 저장소를 2011년 12월 말 모습으로 줄인 복사본이고, `data/requests/`는 시험용 신청서예요. 시험할 때는 `data/store/`를 다른 폴더로 복사하고 그 폴더를 마지막 인자로 줘요. 예를 들면 `php src/batch.php data/requests/2011-12-26.csv 2011-12-26 <복사본 폴더>`예요.

| 파일 | 무엇인가요 | 한 줄 예 | 이 줄의 뜻 |
| --- | --- | --- | --- |
| `data/store/books.csv` | 도서 20권 | `B0001,자바 웹 개발 입문,문지성,IT,28000,IN` | 도서번호 B0001은 문지성이 쓴 IT 책 "자바 웹 개발 입문"이에요. 정가는 28,000원이고 지금 서가에 있어요. |
| `data/store/members.csv` | 회원 12명 | `E0811,노은지,인사팀,대리,2,` | 인사팀 노은지 대리는 지금까지 연체가 두 번이에요. 마지막 칸이 비어 있어서 대출 정지는 아니에요. |
| `data/store/loans.csv` | 대출 기록 16건 | `L0001,B0003,E0902,2011-10-03,2011-10-17,2011-10-20,0,300` | E0902가 B0003을 10월 3일에 빌렸어요. 반납 예정일은 10월 17일인데 10월 20일에 반납해서 연체료 300원이 붙었어요. 연장은 안 했어요. |
| `data/store/reservations.csv` | 예약 3건 | `B0007,E0902,2011-12-20` | E0902가 12월 20일에 B0007을 예약했어요. |
| `data/store/donation.csv` | 연체료 기부금 장부 3줄 | `2011-10-20,E0902,300,연체료 L0001` | 10월 20일에 E0902의 연체료 300원을 기금에 적었어요. 메모의 L0001은 대출번호예요. |
| `data/requests/2011-12-26.csv` | 12월 26일에 처리할 신청서 17건 | `반납,E0811,B0009,,반납함` | 반납함에 들어온 B0009를 반납 처리해요. 처리일이 비어 있어서 기준일(12월 26일)로 처리해요. |
| `data/requests/2012-01-05.csv` | 1월 5일에 처리할 신청서 10건 | `연장,E1012,B0013,,` | E1012가 B0013의 연장을 신청했어요. |

신청서에는 실제로 자주 나온 실수도 넣어 뒀어요. 없는 날짜, 없는 사번, 빈 줄, 신청서로 받지 않는 예약 같은 것이에요.

## 출력

| 결과 | 내용 |
| --- | --- |
| 화면 | 목록, 대출, 반납 화면에 결과 문구가 나와요. |
| 저장 파일 | 대출, 반납, 연장, 분실을 처리하면 `books.csv`, `members.csv`, `loans.csv`, `reservations.csv`를 다시 써요. |
| 일괄 처리 결과 | 신청서 줄마다 "[번호] 구분 사번 도서번호 : 완료"처럼 한 줄씩 찍어요. 끝에 완료, 거부, 오류 건수와 연체료, 변상금 합계가 나와요. |
| 연체 보고서 | 부서별 연체 목록, 분실 처리 검토, 대출 정지 회원이에요. 메일로 총무팀에 보내요. |

## 운영

- 총무팀 서버에 APM_Setup(PHP 5.2)을 깔고 `D:\APM_Setup\htdocs\library\`에 둬요. 브라우저로 `http://서버주소/library/list.php`를 열어요.
- 저장 파일은 같은 폴더의 `data` 폴더에 둬요.
- 일괄 처리는 신청서를 모아서 일주일에 두 번 돌려요. 실행 명령은 `php batch.php <신청서 CSV> <기준일>`이에요.
- 연체 보고는 매일 아침 8시에 작업 스케줄러가 `php overdue_report.php <오늘 날짜>`를 돌리고, 결과를 총무팀 메일로 보내요.
- 연체료는 반납할 때 총무팀이 현금으로 받아요.
- 대출 기간(14일), 권수(3권), 하루 연체료(100원)는 `config.php` 한곳에 적어 둬요.
- 문의는 총무팀 정민수(내선 2213)에게 해요.

## 하지 않는 것

- 직원이 직접 대출하거나 반납하지 않아요. 대출과 반납은 총무팀이 처리해요.
- 로그인은 만들지 않아요. 사내망에서만 열려요. 관리자 화면만 비밀번호를 걸어요.
- 바코드는 쓰지 않아요. 도서번호를 손으로 넣어요.
- 책 구입 신청은 받지 않아요. 지금처럼 총무팀 메일로 받아요.
- 본사 말고 다른 사업장의 책은 다루지 않아요.
- 데이터베이스는 쓰지 않아요.
