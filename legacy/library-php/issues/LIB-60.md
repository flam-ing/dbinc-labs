## 설명

2014년 상반기 사내 웹 보안 점검에서 지적된 내용이에요. `lib_find()`는 조건 글자를 PHP 코드로 실행(`eval`)해요. 검색어가 그 글자에 그대로 들어가서, 따옴표를 넣으면 서버에서 아무 PHP 코드나 실행할 수 있어요.

## 댓글

**정민수** 2014-06-10
화면에서 받은 값은 모두 `addslashes()`를 거치게 고쳤어요(`list.php`, `loan.php`, `return.php`). 점검팀 재확인에서 통과했어요.

**정민수** 2014-06-10
`lib_find()`를 없애려면 조건을 쓰는 곳을 모두 바꿔야 해요. 일괄 처리는 총무팀이 만든 신청서 파일만 읽어서 위험이 낮다고 보고, 근본 수정은 나중에 하기로 했어요.

**정보보안팀** 2014-06-12
조치 확인했어요. 일괄 처리 쪽은 다음 점검 때 다시 볼게요.

**한지원** 2021-03-22
