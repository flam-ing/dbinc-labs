# 상담 분류 도우미

상담원이 티켓 내용을 넣으면 카테고리, 긴급도, 담당 팀, 마감 시각을 알려 주는 화면이에요.

## 쓰는 법

`web/index.html`을 크롬으로 열어요. 서버는 필요 없어요. 제목과 내용을 넣고 [분류]를 누르면 아래 표에 한 줄씩 붙어요. [엑셀로 복사]를 누르면 표를 엑셀에 붙여 넣을 수 있어요.

## 분류 기준

위키 "상담 분류 기준"을 보세요. 기준이 바뀌면 `web/app.js`의 `onClassify` 함수를 고쳐요.

## 야간 배치 (2020.06 추가, 정우진)

티켓 시스템이 밤마다 내보내는 파일을 한꺼번에 분류해요.

```
node cli/triage.js tickets.json
```

`--json`을 붙이면 JSON으로 나와요. 아침 리포트는 이 결과로 만들어요.
