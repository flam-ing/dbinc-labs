## 1. 카테고리

제목과 내용에 아래 단어가 있으면 그 카테고리로 봐요. 위에서부터 차례로 보고, 먼저 걸린 카테고리로 정해요.

| 순서 | 카테고리 | 단어 |
| --- | --- | --- |
| 1 | 장애 | 오류, 에러, 접속, 500, 안 돼요 |
| 2 | 결제 | 결제, 카드, 청구 |
| 3 | 배송 | 배송, 택배, 송장 |
| 4 | 계정 | 로그인, 비밀번호, 계정 |
| 5 | 기타 | 위 단어가 하나도 없을 때 |

장애를 맨 먼저 보는 이유가 있어요. 장애는 고객 한 명의 문제가 아니라 같은 문제를 겪는 고객이 뒤에 수백 명 있을 수 있어요. "결제가 안 돼요"도 결제 시스템 장애일 수 있어서 IT운영팀이 먼저 봐야 해요. "500"은 서버 오류 화면에 나오는 숫자예요.

## 2. 긴급도 점수

| 조건 | 점수 | 정한 이유 |
| --- | --- | --- |
| 장애 | 3 | 한 건 뒤에 같은 문제를 겪는 고객이 많아요 |
| 결제 | 2 | 돈 문제는 민원으로 번지기 쉬워요 |
| 배송, 계정 | 1 | |
| VIP 고객 | 3 | VIP 고객이 매출의 40%예요. 한 분이 떠나면 손실이 커요 |
| 우수 고객 | 1 | |
| 전화로 접수 | 2 | 2017년 만족도 조사에서 전화로 다시 문의한 고객의 70%가 이미 한 번 이상 문의했던 고객이었어요 |
| 채팅으로 접수 | 1 | |
| "긴급", "급해요", "당장" | 2 | |

점수를 더해서 7점 이상은 P1, 5점 이상은 P2, 3점 이상은 P3, 그 밖에는 P4예요. 7점은 VIP 고객이 채팅이나 전화로 알린 장애가 P1이 되게 맞춘 숫자예요(장애 3, VIP 3, 채팅 1 또는 전화 2). 웹이나 이메일로 들어온 VIP 장애는 6점이라 P2예요. 워크숍에서 "글로 남긴 장애는 조금 기다려도 된다"고 정했어요.

## 3. 담당 팀

| 카테고리 | 담당 팀 |
| --- | --- |
| 장애 | IT운영팀 |
| 결제 | 결제지원팀 |
| 배송 | 물류CS팀 |
| 계정 | 회원지원팀 |
| 기타 | 고객상담1팀 |

VIP 고객 티켓은 카테고리와 상관없이 VIP전담팀이 받아요.

## 4. 처리 기한(SLA)

| 긴급도 | 기한 |
| --- | --- |
| P1 | 접수 후 2시간 |
| P2 | 접수 후 4시간 |
| P3 | 접수 후 24시간 |
| P4 | 접수 후 72시간 |

기한은 접수 시각부터 그냥 시간을 더해서 계산해요.
