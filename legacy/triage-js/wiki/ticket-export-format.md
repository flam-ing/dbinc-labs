| --- | --- |

| 경로 | IT 연동 / 고객센터 / 티켓 내보내기 |
| 작성자 | 정우진 |
| 처음 만든 날 | 2020-06-08 |

| 레이블 | 티켓, 내보내기, 야간 배치 |

> 티켓 시스템이 매일 밤 11시에 내보내는 JSON 파일의 형식이에요. 야간 분류 배치가 이 파일을 읽어요.

## 파일

`/data/cs/export/tickets-YYYYMMDD.json` 하나에 그날 열려 있는 티켓이 모두 들어 있어요. 티켓 하나가 JSON 객체 하나예요.

## 칸

| 칸 | 뜻 | 비고 |
| --- | --- | --- |
| id | 티켓 번호 | T-로 시작해요 |
| title | 제목 | 옛 게시판에서 옮겨 온 티켓은 비어 있을(null) 수 있어요 |
| body | 내용 | 첨부만 있는 티켓은 null이에요 |
| grade | 고객 등급 | 일반, 우수, VIP. 2019년 이전 고객은 소문자 vip로 들어 있기도 해요 |
| channel | 접수 채널 | 웹, 이메일, 채팅, 전화, 앱. 옛 게시판에서 옮겨 온 티켓은 비어 있을 수 있어요 |
| receivedAt | 접수 시각 | 채널마다 형식이 달라요. 아래를 보세요 |

## 접수 시각 형식

채널마다 접수 시각을 만드는 시스템이 달라서 형식도 달라요.

| 채널 | 형식 | 예 |
| --- | --- | --- |
| 웹, 이메일 | 한국 시각 글자 | `2020-09-28 09:12` |
| 채팅 | ISO 형식, 한국 시각(+09:00) | `2020-09-28T09:12:00+09:00` |
| 전화 | 숫자(1970년부터 센 밀리초, UTC 기준) | `1601252520000` |
| 앱 | ISO 형식, UTC(Z) | `2020-09-28T00:12:00Z` |

앱은 9월 배포부터 한국 시각(+09:00)으로 보내기로 앱팀과 정했어요(CS-205). 그 뒤로는 채팅과 같은 형식이 돼요.

## 알아 둘 것

- 상태가 바뀐 티켓은 같은 파일에 두 번 들어갈 때가 있어요. 뒤에 있는 것이 최신이에요.
- 날짜를 글로 적은 이상한 값("어제 오후 3시" 같은 것)이 옛 게시판 티켓에 섞여 있어요.
- 이 파일은 고객 정보를 담고 있어요. 서버 밖으로 복사하지 마세요.
