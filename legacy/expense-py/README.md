# 출장비 정산 배치 (expense_batch)

전자결재에서 내려받은 출장 신청서(JSON)를 읽어서 출장비를 정산하는 배치예요. 일비, 숙박비 상한, 영수증 없는 지출 한도, 결재선을 계산하고, 신청한 사람에게 결과 메일을 보내요. 재무팀 출장비 담당이 결과 CSV를 엑셀로 열어 확인한 뒤 지급해요.

## 실행

파이썬 3.6 이상이 필요해요. 외부 패키지는 쓰지 않아요.

```
python expense_batch.py D:\expense\requests D:\expense\fx\fx_rates.json 2019-05-15
```

- 매월 15일과 말일 18:00에 작업 스케줄러(EXP_SETTLE)가 실행해요.
- 결과 CSV는 `C:\expense\out\settlement_YYYYMMDD.csv`에 생겨요.
- 감사 로그는 `C:\expense\audit.log`에 이어서 써요.
- 메일은 SMTP 서버로 바로 보내요. 서버 주소와 계정은 settings.py에 있어요.

## 규칙 요약

- 일비는 직급별 정액이에요. 표는 settings.py에 있어요.
- 해외 영수증은 영수증 날짜의 환율로 원화로 바꿔요.
- 영수증 없는 지출은 출장 한 건에 2만 원까지 인정해요.
- 정산 금액에 따라 결재선이 팀장, 본부장, 재무이사로 늘어나요.

자세한 내용은 재무팀 위키의 "출장비 정산 기준"을 봐요.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| expense_batch.py | 메인이에요 |
