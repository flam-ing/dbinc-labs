> 교육용 가상 자료예요. 회사, 사람, 금액, 규정은 모두 지어낸 것이에요.

출장비 정산 배치(expense_batch)를 만들기 전에 쓴 기획서예요. 2019년 4월에 재무팀장님 승인을 받았어요. 규정 자체는 "출장비 정산 기준", 결재선은 "전결 규정 발췌", 운영 방법은 "출장비 정산 배치 운영 메모" 페이지를 봐요.

## 목적

지금은 재무팀 출장비 담당자가 전자결재의 출장 신청서를 하나씩 열어서 엑셀로 일비, 숙박비, 환율을 계산해요. 한 달에 200건쯤이라 매월 15일과 말일에는 하루를 다 써요. 2019년 3월 규정 4판으로 영수증 없는 지출 한도가 바뀌면서 계산 실수도 몇 건 나왔어요.

정산 배치는 승인된 신청서를 한꺼번에 읽어서 규정대로 인정 금액과 결재선을 계산해요. 신청한 사람에게는 결과 메일을 보내고, 재무팀에는 결과 파일을, 감사팀에는 감사 로그를 남겨요. 담당자는 결과 파일만 확인하고 지급하면 돼요.

## 쓰는 사람

| 누구 | 무엇을 하나요 |
| --- | --- |
| 출장 간 직원 | 전자결재로 신청하고, 정산 결과 메일을 받아요. |
| 재무팀 출장비 담당 | 결과 파일을 엑셀로 열어 확인한 뒤 지급해요. 반려된 신청은 직원에게 안내해요. |
| 결재자(팀장, 본부장, 재무이사, 대표이사) | 결과 파일의 결재선대로 승인해요. |
| 감사팀 | 분기마다 감사 로그를 가져가서 지급 금액을 다시 계산해 봐요. |
| 재무팀 자금 담당 | 매일 환율표를 만들어 올려요. |

## 주요 기능

1. 신청서 폴더의 JSON 파일을 파일 이름 순서대로 하나씩 읽어요. 읽을 수 없는 파일은 "읽기 실패"로 남기고 다음 파일로 넘어가요.
2. 신청서를 검사해요. 아래에 걸리면 반려해요.
   - 출발일이나 복귀일이 없어요.
   - 복귀일이 출발일보다 빨라요.
   - 정산일에 복귀일부터 30일이 지났어요.
   - 직급이 일비 표에 없어요. 임원은 일비를 따로 정해 두어서 여기에 걸리지 않아요.
   - 같은 사번, 같은 출발일인 신청이 앞에 있었어요(중복 신청).
   - 출장 일수가 15일 이상인데 사전 승인 번호가 없어요.
3. 일비를 계산해요. 직급별 정액에 출장 일수를 곱해요. 출장 일수는 출발일과 복귀일을 모두 셈해요. 국내 당일 출장은 하루 일비의 절반이에요. 해외 일비는 달러로 정해져 있어서 원화로 바꿔요.
4. 영수증을 숙박, 교통(항공, 기차, 버스, 택시, 차량), 기타로 나눠서 더해요. 영수증 없이 쓴 돈은 따로 모아요.
5. 한도를 적용해요. 숙박비는 도시 등급별 1박 상한에 박수를 곱한 금액까지 인정해요. 임원은 상한 없이 실비예요. 영수증 없는 지출은 출장 한 건에 3만 원까지 인정해요.
6. 해외 금액을 원화로 바꿔요. 영수증은 영수증 날짜의 매매기준율로 바꾸고, 해외 일비와 숙박 상한은 출발일 환율로 바꿔요. 환율이 없는 날(주말, 공휴일)은 앞 날짜로 5일까지 거슬러 찾아요. 원 미만은 모두 버려요. 환율표에 없는 통화가 있으면 반려해요.
7. 결재선을 정해요. 인정 금액이 100만 원 이하이면 팀장, 300만 원 이하이면 본부장까지, 그보다 크면 재무이사까지예요. 해외 출장은 금액이 적어도 본부장까지 받아요. 임원 본인의 출장은 대표이사가 결재해요. 금액 기준은 경영지원팀에서 받은 전결 표를 따랐어요.
8. 신청서마다 결과 메일을 보내요. 받는 사람은 신청한 직원이고, 재무팀 출장비 담당이 참조로 들어가요.
9. 감사 로그와 결과 파일을 남겨요.

## 입력 파일

| 파일 | 누가, 언제 만드나요 | 위치 |
| --- | --- | --- |
| 출장 신청서 (`<신청번호>.json`) | 전자결재 시스템이 매일 밤 승인된 신청서를 하나에 한 파일씩 내보내요. | `D:\expense\requests\` |
| 환율표 (`fx_rates.json`) | 자금 담당이 매일 오전 은행 고시 환율을 엑셀 매크로로 바꿔서 올려요. | `D:\expense\fx\` |

신청서에 들어 있는 칸이에요.

| 칸 | 뜻 |
| --- | --- |
| req_id | 신청번호예요. BT-연도-번호 모양이에요. |
| emp_no, name, dept, grade | 사번, 이름, 부서, 직급이에요. |
| trip_type | 국내는 DOMESTIC, 해외는 OVERSEAS예요. |
| city | 출장 간 도시예요. 숙박 상한 등급을 정할 때 써요. |
| purpose | 출장 목적이에요. 배치는 읽지 않아요. |
| depart, return | 출발일과 복귀일이에요. |
| submitted | 신청한 날이에요. 배치는 읽지 않아요. |
| receipts | 영수증 목록이에요. 영수증마다 종류(type), 날짜(date), 금액(amount), 통화(currency), 영수증 유무(receipt), 설명(desc)이 있어요. receipt가 false이면 영수증 없이 쓴 돈이에요. |
| memo | 신청한 사람이 남긴 말이에요. 결과 메일에 그대로 넣어 줘요. |

환율표는 날짜마다 통화 네 개(USD, JPY, EUR, CNY)의 매매기준율을 적은 파일이에요. 엔화만 100엔당 값이에요.

## 출력

| 결과 | 내용 | 누가 쓰나요 |
| --- | --- | --- |
| 결과 파일 (`settlement_YYYYMMDD.csv`) | 신청서마다 한 줄이에요. 신청번호, 사번, 이름, 직급, 국내·해외, 일수, 일비, 숙박, 교통, 기타, 영수증 없는 지출, 인정 금액, 불인정 금액, 결재선, 결과(정산완료나 반려), 반려 이유가 들어가요. | 재무팀 출장비 담당 |
| 결과 메일 | 신청서마다 한 통이에요. 정산완료면 항목별 금액과 결재선을, 반려면 반려 이유를 알려 줘요. | 신청한 직원 |
| 감사 로그 (`audit.log`) | 신청서마다 한 줄씩 이어 써요. 칸은 정산일, 신청번호, 사번, 결과, 금액, 결재선이나 반려 이유이고 `\|`로 나눠요. 실행을 시작할 때와 끝날 때도 한 줄씩 남겨요. | 감사팀 |
| 화면 요약 | 신청서마다 한 줄과, 끝에 읽은 건수, 정산 건수와 지급 합계, 반려 건수, 결재선별 건수가 나와요. | 배치를 돌린 사람 |

감사 로그의 칸 순서와 구분 문자는 감사팀 스크립트와 맞춘 것이라 바꾸지 않아요.

## 운영

- 매월 15일과 말일 18:00에 재무팀 배치 서버의 작업 스케줄러(EXP_SETTLE)가 실행해요.
- 실행 명령은 `python expense_batch.py <신청서 폴더> <환율표> <정산일>`이에요. 파이썬 3.6 이상이고 외부 패키지는 쓰지 않아요.
- 결과 파일과 감사 로그는 `C:\expense\out\`에 써요.
- 메일은 사내 메일 서버에 SMTP로 바로 보내요. 보내는 주소는 출장비 봇 계정이에요.
- 일비, 숙박 상한, 도시 등급 같은 규정 표와 서버 주소는 `settings.py` 한곳에 모아요. 규정이 바뀌면 그 파일만 고쳐요.
- 규칙마다 단위 테스트를 만들어 두고, 규정 표를 고칠 때 먼저 돌려요.
- 문의는 재무팀 김도윤에게 해요.

## 하지 않는 것

- 돈을 보내지 않아요. 지급은 재무팀 담당자가 결과 파일을 확인한 뒤에 해요.
- 전자결재에 결과를 되돌려 쓰지 않아요. 결재는 결재자가 직접 해요.
- 환율표를 만들지 않아요. 자금 담당이 올린 표를 읽기만 해요.
- 영수증 사진이나 카드 사용 내역은 보지 않아요. 신청서에 적힌 금액만 계산해요.
- 법인카드로 회사가 바로 낸 비용은 정산하지 않아요. 카드 정산으로 따로 처리해요.
- 지난 실행에서 정산한 신청서는 기억하지 않아요. 중복 신청은 한 번 실행하는 동안에만 걸러요.
- 환율표에 없는 통화의 신청서는 반려만 하고, 재무팀이 손으로 정산해요.
