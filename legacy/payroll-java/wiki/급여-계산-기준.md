# 급여 계산 기준

> 공간: 인사팀(HR) · 작성자: 문태호(전산실) · 만든 날: 2008-04-21
> 마지막 수정: 2012-01-09 문태호 · 라벨: 급여, 계산기준, 공식

이 페이지는 급여 프로그램이 따르는 계산 기준이에요. 급여 규정 개정이 있으면 인사팀이 알려 주고, 전산실이 이 페이지와 프로그램을 같이 고쳐요.

## 1. 계산 순서

1. 기본급을 정해요. 입사하거나 퇴사한 달은 일할 계산을 해요.
2. 근태 수당(연장, 야간, 휴일)을 더해요.
3. 지급 합계로 공제를 계산해요. 연금만 기본급으로 계산해요.
4. 지급 합계에서 공제 합계를 빼서 실지급을 정해요.

## 2. 일할 계산

입사한 달과 퇴사한 달은 일한 날만큼만 기본급을 줘요. 일한 날은 입사일이나 그 달 1일부터 퇴사일이나 그 달 말일까지 세고, 양 끝 날을 모두 넣어요.

나누는 수는 **30일로 정해져 있어요.** 31일까지 있는 달도 30으로 나누고, 일한 날이 30일을 넘으면 30일로 봐요. 2008년 노사협의회에서 정한 내용이에요.

## 3. 원 단위 처리 (공식)

- 지급 항목(기본급, 수당, 상여)은 원 미만을 버려요.
- 공제 항목은 10원 미만을 버려요.
- 실지급은 마지막에 한 번 더 10원 미만을 버려요.

반올림은 하지 않아요. 누가 계산해도 같은 금액이 나오게 하려고 정한 원칙이에요. 이 원칙을 바꾸려면 노사협의회 승인이 필요해요.

## 4. 공제 요율 (2012년 1월 개정, 수업용 가상 요율)

| 항목 | 요율 | 기준 금액 |
| --- | --- | --- |
| 연금 | 4.5% (2011년까지 4%) | 기본급(일할 계산 뒤) |
| 건강보험 | 3.5% | 지급 합계 |
| 고용보험 | 0.9% | 지급 합계 |
| 소득세 | 아래 간이 구간표 | 지급 합계 |
| 사우회비 | 10,000원 | 사우회 가입자만 |

소득세 간이 구간표예요.

| 지급 합계 | 세율 |
| --- | --- |
| 150만 원 미만 | 0% |
| 150만 원 이상 300만 원 미만 | 2% |
| 300만 원 이상 450만 원 미만 | 4% |
| 450만 원 이상 700만 원 미만 | 6% |
| 700만 원 이상 | 8% |

## 5. 근태 수당

근태 수당은 인사팀이 엑셀 매크로로 계산해서 금액으로 넘겨줘요. 급여 프로그램은 받은 금액을 그대로 더해요.

관리직(부장, 이사, 상무)은 연장근무 수당이 없어요. 연봉 계약에 포함되어 있기 때문이에요.

## 6. 식대

식대 10만 원은 2009년 3월부터 기본급에 들어갔어요. 따로 빼서 계산하지 않아요.
