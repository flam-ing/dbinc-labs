# 급여 계산 프로그램 기획서 (2008)

> 공간: 정보시스템팀(옛 전산실) · 작성자: 문태호(전산실) · 만든 날: 2008-03-17
> 마지막 수정: 2022-02-15 이도윤 · 라벨: 급여, 기획서

전산실이 2008년 3월에 쓴 기획서예요. 프로그램은 2008년 4월 급여부터 썼어요. 맨 아래 8절은 2022년 2월에 이도윤이 덧붙였어요.

## 1. 왜 만드나요

지금은 인사팀이 매달 엑셀 파일 하나로 급여를 계산해요. 직원이 늘면서 계산하는 사람마다 수식이 조금씩 달라졌고, 같은 사람의 공제가 달마다 1원, 10원씩 다르게 나온 적도 있어요.

계산을 프로그램 하나로 모아서 누가 돌려도 같은 금액이 나오게 해요. 계산 기준은 인사팀과 함께 "급여 계산 기준" 페이지로 정리해요.

## 2. 쓰는 사람

| 누구 | 하는 일 |
| --- | --- |
| 인사팀 급여 담당 | 직원 파일과 근태 파일을 주고, 급여 대장을 받아 검토해요. 대장으로 은행 이체 파일과 급여 명세서를 만들어요 |
| 전산실 | 프로그램을 돌리고 급여 대장 파일을 인사팀에 보내요. 요율이 바뀌면 프로그램을 고쳐요 |

직원은 이 프로그램을 직접 쓰지 않아요.

## 3. 주요 기능

1. **그달 재직자 고르기**: 입사일이 그달 말일보다 뒤인 사람과 퇴사일이 그달 1일보다 앞인 사람은 빼요.
2. **기본급**: 입사한 달과 퇴사한 달은 일한 날만큼만 줘요(일할 계산). 일한 날은 양 끝 날을 모두 넣어 세고, **30으로 나눠요.** 일한 날이 30일을 넘으면 30일로 봐요. 2008년 노사협의회에서 정한 내용이에요.
3. **근태 수당**: 연장, 야간, 휴일 수당은 인사팀 엑셀 매크로가 사람별 금액으로 계산해서 넘겨줘요. 프로그램은 받은 금액을 그대로 더해요. 관리직(부장, 이사, 상무)의 연장근무 수당은 매크로에서 빼고 넘겨줘요.
4. **지급 합계**: 기본급과 근태 수당을 더해요.
5. **공제**: 아래 표대로 계산해요(수업용 가상 요율).

| 항목 | 요율 | 기준 금액 |
| --- | --- | --- |
| 연금 | 4% | 기본급(일할 계산 뒤) |
| 건강보험 | 3.5% | 지급 합계 |
| 고용보험 | 0.9% | 지급 합계 |
| 소득세 | 아래 간이 구간표 | 지급 합계에서 식대 10만 원을 뺀 금액 |
| 사우회비 | 10,000원 | 사우회 가입자만 |

소득세 간이 구간표예요.

| 기준 금액 | 세율 |
| --- | --- |
| 150만 원 미만 | 0% |
| 150만 원 이상 300만 원 미만 | 2% |
| 300만 원 이상 450만 원 미만 | 4% |
| 450만 원 이상 700만 원 미만 | 6% |
| 700만 원 이상 | 8% |

- 식대 10만 원은 기본급 안에 들어 있어요. 비과세라서 소득세를 계산할 때만 빼요.
- 지급 합계가 1,000만 원을 넘으면 소득세에 5만 원을 더해요(고액 가산).

6. **원 단위**: 지급 항목은 원 미만을 버리고, 공제 항목은 10원 미만을 버려요. 실지급은 지급 합계에서 공제 합계를 뺀 다음 한 번 더 10원 미만을 버려요. 반올림은 하지 않아요. 누가 계산해도 같은 금액이 나오게 하려는 원칙이에요.

## 4. 입력 파일

인사팀이 매달 두 파일을 `D:\PAY\IN\`에 올려요. 두 파일 모두 첫 줄은 칸 이름이에요.

### 직원 파일 (`EMP.CSV`)

인사 시스템에서 내려받은 CSV예요. 인코딩은 MS949예요.

| 칸 | 뜻 |
| --- | --- |
| 사번 | 직원 번호 |
| 성명 | 이름 |
| 부서 | 부서 이름. 대장 끝의 부서별 합계에 써요 |
| 직급 | 사원, 대리, 과장, 차장, 부장, 이사, 상무 |
| 입사일 | `yyyy-MM-dd` |
| 퇴사일 | `yyyy-MM-dd`. 다니는 사람은 비어 있어요 |
| 기본급 | 한 달 기본급(원) |
| 사우회 | 사우회 가입이면 Y, 아니면 N |

예) `E0801,김민준,영업1팀,사원,2008-03-03,,2400000,Y`
영업1팀 사원 김민준(E0801)은 2008-03-03에 입사했고, 아직 다니고 있고, 기본급은 240만 원이고, 사우회에 가입했어요. 입사한 달(3월)의 기본급은 일한 29일(3일부터 31일까지)을 30으로 나눠 계산해요.

### 근태 파일 (`ATT.CSV`)

인사팀 엑셀 매크로가 만든 연장근무 집계 CSV예요. 사람마다 한 줄이에요.

| 칸 | 뜻 |
| --- | --- |
| 사번 | 직원 번호 |
| 근태수당 | 그달 연장, 야간, 휴일 수당을 모두 더한 금액(원) |

예) `E0702,125400`
사번 E0702의 그달 근태 수당이 125,400원이라는 뜻이에요.

### 대상월

실행할 때 `yyyy-MM`으로 넣어요. 예를 들어 4월 급여는 `2008-04`예요.

## 5. 출력: 급여 대장

결과는 화면에 찍어요. 전산실이 파일로 저장해서 인사팀에 메일로 보내요.

- 맨 위에 대상월을 찍어요.
- 사람마다 `[사번] 성명  부서 / 직급` 줄을 찍고, 그 아래에 항목 줄을 차례로 찍어요. 항목은 기본급, 근태수당, 지급계, 연금, 건강보험, 고용보험, 소득세, 사우회비, 공제계, 실지급 순서예요.
- **항목 순서와 줄 수는 늘 같아요.** 해당이 없는 항목도 0원으로 찍어요. 인사팀이 대장을 엑셀에 붙여 넣고, 사람마다 몇 번째 줄인지로 금액을 읽기 때문이에요.
- 입사하거나 퇴사한 달의 기본급 줄 끝에는 `(일할 일한날/30)`을 붙여요.
- 맨 아래에 인원, 지급계, 공제계, 실지급 합계와 부서별 실지급 합계를 찍어요.
- 기본급이 0원인 사람처럼 이상한 자료가 있으면 그 사람 앞에 경고 줄을 찍어요. 인사팀이 확인해요.

## 6. 운영

- 근태 마감은 매달 말일 다음 날 오전 10시예요. 마감 뒤에 인사팀이 두 파일을 올리면 전산실이 바로 돌려요.
- 명령: `java -cp classes nuri.pay.PayMain D:\PAY\IN\EMP.CSV D:\PAY\IN\ATT.CSV 2008-04`
- 결과를 `급여대장.txt`로 저장해서 인사팀에 메일로 보내요.
- 요율이 바뀌면 인사팀이 알려 주고, 전산실이 `Deduct.java`와 "급여 계산 기준" 페이지를 같이 고쳐요.
- 개발 환경: JDK 1.5

## 7. 하지 않는 것

- 근태 수당을 출퇴근 기록으로 계산하지 않아요. 인사팀 엑셀 매크로가 계산한 금액을 받아요.
- 상여금은 넣지 않아요. 연말 성과급은 인사팀이 따로 계산해서 따로 줘요.
- 연말정산과 퇴직금은 하지 않아요.
- 은행 이체 파일과 급여 명세서는 만들지 않아요. 인사팀이 대장으로 만들어요.
- 지난달 급여를 고쳐야 할 때 차액을 자동으로 계산하지 않아요. 인사팀이 다음 달에 손으로 넣어요.

## 8. 검증용 파일 (data 폴더) — 2022-02-15 이도윤 덧붙임

PAY-241(스타일 맞추기)을 하기 전에 지금 출력을 기록해 두려고 만든 파일이에요. 위 1~7절은 2008년 기획 그대로라서 지금 프로그램과 다른 곳이 있어요. 특히 근태 파일은 2015년부터 날마다 한 줄인 출퇴근 기록으로 바뀌었어요("연장·야간·휴일 수당 계산" 페이지). 그 밖에 바뀐 것은 다른 위키 페이지와 이슈를 같이 봐요.

2021년 9월과 10월 자료로 만들었어요. 운영에서 실제로 나왔던 이상한 줄(빈 칸, 없는 날짜, 같은 사번 두 줄 같은 것)도 남겼어요. 이렇게 돌려요.

    java -cp classes nuri.pay.PayMain data/employees.csv data/attendance-2021-10.csv 2021-10

같은 직원 파일로 대상월만 바꿔서도 돌려요. `2021-09`는 9월 근태 파일로 돌리고, `2021-11`과 `2022-01`은 10월 근태 파일로 돌려서 상여와 사우회비가 어떻게 나오는지 봐요.

| 파일 | 무엇 |
| --- | --- |
| `employees.csv` | 2021년 직원 파일이에요. 직원 16명이에요. 2017년부터 UTF-8로 오고, 2021년에 성과등급 칸이 더해져 칸이 9개예요 |
| `attendance-2021-09.csv` | 2021년 9월 근태 기록 12줄이에요. 추석 연휴 휴일근무와 물류센터 야간조가 있어요 |
| `attendance-2021-10.csv` | 2021년 10월 근태 기록 33줄이에요. 휴가, 같은 날 정정본, 퇴근 시각이 빈 줄이 섞여 있어요 |

`employees.csv` 예) `E0801,김민준,영업1팀,과장,2008-03-03,,3850000,Y,A`
칸은 사번, 성명, 부서, 직급, 입사일, 퇴사일, 기본급, 사우회, 성과등급이에요. 영업1팀 과장 김민준(E0801)은 2008-03-03에 입사했고, 퇴사일이 비어 있으니 다니고 있어요. 기본급은 385만 원, 사우회 가입, 직전 분기 성과등급은 A예요. 성과등급은 S, A, B, C 가운데 하나이고 비어 있으면 등급이 없는 거예요.

`attendance-2021-09.csv` 예) `E1102,2021-09-20,22:00,07:00,휴일`
칸은 사번, 일자, 출근, 퇴근, 구분이에요. 물류센터 박현우(E1102)가 9월 20일 22시에 출근해서 다음 날 7시에 퇴근했어요. 퇴근이 출근보다 이르면 다음 날 퇴근으로 봐요. 추석 연휴라 근태팀이 구분 칸에 `휴일`이라고 넣었어요. 구분은 근무, 휴일, 휴가 가운데 하나예요.

`attendance-2021-10.csv` 예) `E0905,2021-10-14,09:00,20:00,근무`
이서연(E0905)의 10월 14일 기록이에요. 바로 위에 같은 날 줄(`09:00,18:00`)이 하나 더 있어요. 근태 시스템이 고친 줄을 아래에 다시 붙이기 때문에 뒤의 줄이 정정본이에요.
