# 급여 계산 배치 (PAYROLL)

누리상사의 월 급여를 계산하는 배치 프로그램이에요. 2008년 4월에 전산실에서 만들었어요.
직원 파일과 근태 파일을 읽어서 사람마다 지급, 공제, 실지급을 계산하고 급여 대장을 화면에 찍어요.

## 실행 방법

JDK 1.5 이상이 필요해요.

```
javac -d classes src/nuri/pay/*.java
java -cp classes nuri.pay.PayMain D:\PAY\IN\EMP.CSV D:\PAY\IN\ATT.CSV 2008-04
```

결과는 화면에 나와요. 인사팀에 보낼 때는 `> 급여대장.txt`로 저장해서 메일로 보내요.

## 입력 파일

- 직원 파일: 인사 시스템에서 내려받은 CSV예요. 인코딩은 MS949예요.
- 근태 파일: 인사팀 엑셀 매크로가 만든 연장근무 집계 CSV예요.
- 대상월: `yyyy-MM` 모양으로 넣어요.

## 계산 기준

계산 기준은 사내 위키의 "급여 계산 기준" 페이지를 따라요. 요율이 바뀌면 `Deduct.java`를 고쳐요.

## 바뀐 내용

- 2008년 4월에 처음 만들었어요(문태호).
- 2012년 1월에 공제 요율을 바꿨어요(문태호).
- 2015년 7월부터 연장, 야간, 휴일 수당을 프로그램이 계산해요. 이제 엑셀 매크로는 쓰지 않아요(김수진).
- 2021년 10월에 성과상여를 넣었어요. 이제 JDK 17 이상이 필요해요(이도윤).
