# PAY-198 한글날 근무가 평일로 계산돼서 휴일 수당이 빠졌어요

| 항목 | 내용 |
| --- | --- |
| 키 | PAY-198 |
| 유형 | 버그 |
| 상태 | 해결됨(우회) |
| 담당 | 김수진 |
| 보고 | 박은정(인사팀) |
| 만든 날 | 2018-10-29 |
| 라벨 | 휴일, 근태 |

## 설명

2018년 10월 급여에서 10월 9일(한글날, 화요일)에 출근한 물류센터 직원 4명의 휴일 수당이 빠졌어요. 연장 수당으로 계산됐어요.

`PayUtil`의 공휴일 표(`arrHoliday`)는 2008년에 만든 것이라서 10월 9일이 없어요. 한글날은 2013년에 다시 공휴일이 됐어요.

## 댓글

**김수진** 2018-10-30
공휴일 표에 `1009`를 넣으면 고쳐지지만, `PayUtil`은 2008년 코드라서 손대면 인사팀 검수를 다시 받아야 해요. 근태 파일의 구분 칸이 `휴일`이면 휴일로 계산하는 기능이 이미 있어요. 근태팀에 한글날도 `휴일`로 넣어 달라고 요청할게요.

**박은정(인사팀)** 2018-10-31
4명은 11월 급여에 수기로 차액을 넣었어요. 근태팀이 앞으로 공휴일 표에 없는 휴일(설, 추석, 대체공휴일, 한글날)은 모두 `휴일`로 넣기로 했어요.

**김수진** 2018-10-31
근태팀 약속으로 우회해서 닫아요. 공휴일 표는 고치지 않았어요.
