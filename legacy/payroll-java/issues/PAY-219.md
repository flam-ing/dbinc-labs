## 설명

10월 급여에서 한상철 상무(E1808)에게 휴일 수당 347,368원이 나갔어요. 10월 3일(일요일) 행사 출근 기록이 근태 파일에 올라왔기 때문이에요.

위키 "급여 계산 기준"에는 관리직이 부장, 이사, 상무라고 되어 있어요. 그런데 연장 수당 코드(`OvertimeCalc`)의 관리직 목록은 부장, 이사, 임원이에요. 인사 시스템 직급에는 "임원"이 없고 "상무"가 있어서, 상무는 관리직으로 걸러지지 않아요.
