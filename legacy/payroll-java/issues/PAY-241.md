## 설명

급여 배치는 2008년, 2015년, 2021년에 세 사람이 만들어서 스타일이 모두 달라요.

- 2008년 코드: `Vector`, `Hashtable`, 헝가리안 이름(`strEmpNo`, `nBasePay`), `int`로 금액 계산
- 2015년 코드: Java 8 스트림과 `Optional`, 영어 주석, `double`로 금액 계산
- 2021년 코드: `record`, `var`, `switch` 식, `BigDecimal`

날짜도 `SimpleDateFormat`과 `LocalDate`를 섞어 써요. 새로 온 사람이 읽기 어렵고, 고칠 때마다 실수가 나요.
