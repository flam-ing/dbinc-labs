## 설명

1월 12일 대회의실에 9시~10시 30분 예약이 있는데, 9시 30분~10시 예약이 또 들어갔어요. 예약표에는 시각이 "93:0~10:00"처럼 이상하게 찍혀요. 두 팀이 같은 시간에 회의실 앞에서 만났어요.
